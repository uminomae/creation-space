# 5段階モデル解説（Five Stages Guide）

**正本参照**: knowledge/schema/five-stages.md
**用途**: LLM および人間が5段階モデルの全体像を把握するための解説文書。スキーマ定義の補足として、各段階の読み方・遷移条件・よくある誤解を記述する。
**用語**: knowledge/glossary.md

---

## 1. モデルの性格

5段階モデルは、創造や変化の過程を「場→波→縁→渦→束」の5段階で記述する。このモデルには以下の性格がある。

- **現象記述モデルである**: 特定の理論から演繹されたものではなく、複数領域の現象に共通して見出される構造パターンを記述したもの。
- **循環モデルである**: 束（Stage 5）は終点ではなく、次のサイクルの場（Stage 1）を支える足場になる。直線的な進歩図ではない。
- **段階数の一致を求めない**: 各学術領域の理論が5段階と一対一で対応する必要はない。重視するのは、段階数ではなく移行のメカニズムと界面の性質。
- **証明を目的としない**: 5段階モデルが「正しい」ことの証明ではなく、各領域の現象がこの構造パターンで読めるかどうかを確かめる探索。
- **「存在そのものの創造」を記述する**: 創造プロセスモデルではなく、量子から宇宙まで、物質も現象も心も含めた存在の生成を記述する仮説。物理的/生命的/心的個体化の区別はスペクトラム上のラベルにすぎない。
- **指月的態度を取る**: 先行研究との対応は、理論の優劣比較ではなく、異なる理論（指）が同じ構造（月）を指しているかを見る営み。

## 2. 各段階の定義と特徴

### Stage 1: 場（Field）

| 項目 | 内容 |
|------|------|
| 構造 | 無 |
| プロセス | 漂う |
| 一言 | まだ何も分かれていない海 |

場は、構造も方向もまだ存在しない状態を指す。「何もない」のではなく、すべてが溶けていて区別がつかない状態。前サイクルの束が背景として存在する場合もあるが、場そのものは未分化である。

**観察上の手がかり**: 課題や目的がまだ定まっていない状態。明確な問いが立つ前の漠然とした状態。

**対応概念の例**: QFTの真空状態、仏教の空、国産みの混沌、野中郁次郎の「場（Ba）」。

### Stage 2: 波（Wave）

| 項目 | 内容 |
|------|------|
| 構造 | ゆれ・対立 |
| プロセス | 分離 |
| 一言 | 差異が揺れとして立ち上がる |

場の中に差が生まれ、方向が揺れとして立ち上がる。まだ安定した形はなく、対立や分離が生じている段階。

**観察上の手がかり**: 違和感の感知、既存の枠組みとの不整合の認知、「何かがおかしい」という感覚。予測誤差の検知がこの段階の契機となることが多い。

**注記（回転の遍在）**: 波を「小さな回転から押されて生じる向き」と記すことがあるが、回転は渦に固有のものではなく**全段階に遍在する**。波も回転であり、「位相」もまた回転の一種である。波と渦の境界が滲むのは欠陥ではなく、回転が遍在することの現れ。あえて一般的・曖昧な語を当てている（pjdhiro 2026-06-01、pd#103）。

**対応概念の例**: 真空ゆらぎ、陰陽の対極生成、Hopf分岐における定常からの逸脱、ガロア理論における体の拡大。

### Stage 3: 縁（Relation）

| 項目 | 内容 |
|------|------|
| 構造 | 境界・関係 |
| プロセス | 繋がり |
| 一言 | 接し合い、関係が生まれる界面 |

複数の要素が接触し、影響し合い、関係や制約が生まれる場所。5段階モデルの中で最も重要かつ複雑な局面。縁は単なる通過点ではなく、関係の中で新しい秩序が生成される場所である。

**観察上の手がかり**: 異なる視点・要素が交差する場面。協働・対話・葛藤が同時に起きている状態。

**注意**: 縁の記述は領域によって形が異なる。二者関係として現れる場合（愛着理論）、三項関係として現れる場合（共同注意）、多要素システムとして現れる場合（生態学）がある。これらを同じ「縁」で括ることの妥当性は、未解決の問いとして保持されている。

**縁の多様性**: 30領域の構造類似探索により、縁には少なくとも以下のタイプが確認されている。閾値型（分岐点・浸透閾値: D29複雑系）、競合型（モード間競合: D29）、界面型（食物集合界面・境界自己産出: D29）、伝播型（近傍相互作用の連鎖: D29）、帯域型・調停型・曖昧型・侵犯型・持続型・交換型（D25人類学）、構成型・規定型・媒介型・居場所型・物質型・認知型（D27建築）。横断的知見として「境界は線ではなく帯域である」ことが4領域（人類学・建築・複雑系・化学）で独立に確認されている。

**対応概念の例**: Julia集合の境界（収束も発散もしない準安定状態）、般若心経の空即是色、分岐理論の分岐点（複数解が共存する臨界値）、特異摂動の境界層、van Eyckの「in-between」の設計。

### Stage 4: 渦（Vortex）

| 項目 | 内容 |
|------|------|
| 構造 | 個・立ち上がり |
| プロセス | 包摂・融合 |
| 一言 | まとまりとして立ち上がる |

ばらばらだった要素が一つのまとまりとして立ち上がる。個体化・自己組織化が起きる局面。

**観察上の手がかり**: 新しいアイデアや構造が「見えた」瞬間。散在していた要素に一貫性が生まれる場面。

**対応概念の例**: Simondonの個体化、自己組織化、Milnorファイブレーションにおけるモノドロミー、BZ反応のスパイラル波。

### Stage 5: 束（Bundle）

| 項目 | 内容 |
|------|------|
| 構造 | 方向 |
| プロセス | 集合 |
| 一言 | 構造として残り、次の場を支える |

渦どうしが影響し合い、持ち運び可能な構造として残る集まり。束は成果物としての固定ではなく、次のサイクルの場を開く保持形式である。

**観察上の手がかり**: 再利用可能な知識・技法・制度として定着した状態。ただし束が固定化すると次の場が開けないため、束の自己言及性（自らを構造として認識すること）が重要になる。

**束の二種**: 構造類似探索により、束には少なくとも2タイプが確認されている。統計構造型（パワー則、普遍性クラスなど、イベント群が統計的構造として残るもの）と、維持構造型（フラックス維持、構造的カップリングなど、継続的入力のもとで構造が保たれるもの）。

**対応概念の例**: ファイバー束（数学）、文化的慣行、Milnorファイブレーションの定理としてのファイバー束、層/Cechコホモロジーによる大域的対象。

## 3. 段階間の遷移

5段階の遷移は自動的に起きるものではない。以下に各遷移の条件と特徴を記述する。

### 場 → 波

- **条件**: 場の中に差異が生じること。外部からの刺激、内部の揺らぎ、予測誤差の検知などが契機になる。
- **特徴**: この遷移は意図的に起こせるとは限らない。場が十分に「溶けている」ことが前提。

### 波 → 縁

- **条件**: 揺れている要素どうしが接触し、相互作用が始まること。
- **特徴**: 波の状態が長引くと、対立が固定化して縁に至らない場合がある。抱持（誤差を問いとして保持する機能）がこの遷移を支える。

### 縁 → 渦

- **条件**: 関係の中から新しいまとまりが立ち上がること。
- **特徴**: 縁で起きていることが十分に展開された後に渦が生じる。縁を早く通過しようとすると、表面的なまとまりにしかならない。

### 渦 → 束

- **条件**: まとまりが安定し、持ち運び可能な形式になること。
- **特徴**: 渦のすべてが束になるわけではない。まとまりが維持されない場合、波や場に戻ることがある。

### 束 → 場（次サイクルへの循環）

- **条件**: 束が次の探索の背景として機能し、新しい未分化状態を開くこと。
- **特徴**: 束が固定的であるほど次の場が開きにくい。束の自己言及性（構造が自分自身を構造として認識すること）が循環を可能にする。回帰は必ずしも可逆的ではなく、場→束→場'→束'→... と螺旋的に展開する場合がある（天文学 D06 の恒星進化で確認）。

## 4. よくある誤読

| 誤読 | 修正 |
|------|------|
| 5段階は直線的な進歩を表す | 循環モデルであり、束は次の場に接続する |
| 各段階は明確に区切られている | 段階間にはグラデーションがあり、一対一の厳密な写像は前提としない |
| 5段階は特定の理論から演繹された | 複数領域の現象に共通するパターンの記述であり、演繹ではない |
| 束が最終目標である | 束は保持形式であり、目標ではない。固定化した束は次の場を閉じる |
| すべての現象が5段階で説明できる | 構造対応が弱い領域・理論もある。そのずれ自体が調査対象 |
| 縁は「関係する段階」という一般的な意味である | 縁は新しい秩序が生成される界面であり、単なる関わりを指さない |
| 5段階は意識的な創造のみに適用される | 「存在そのものの創造」を記述しており、BZ反応（化学）のような意識以前の物質過程にも構造対応が見られる |
| 5段階は先行研究よりも優れたモデルである | 指月的態度を取る。異なる理論が同じ構造を指しているかを見る営みであり、理論の優劣比較ではない |

## 5. 横断的知見（構造類似探索から）

30学術領域の構造類似探索により、5段階モデルに関する以下の横断的知見が得られている。

### 縁の中心性

30領域中、構造対応が最も濃密に現れるのは「縁」（Stage 3）である。複雑系科学（D29: 7/7エントリ）、人類学（D25: 6/6）、建築（D27: 6/6）では全エントリが縁に対応概念を持つ。「縁の学問」と呼べる領域が複数存在する。

### 境界の厚み

「境界は線ではなく帯域である」という知見が4領域で独立に確認されている。人類学（移行期は帯域）、建築（境界は厚みのある輪郭）、複雑系（非平衡の帯域）、化学（反応拡散前線の拡散長）。化学は拡散長という物理量で「厚み」を定量化できる点で特に強い。

### 予測符号化クラスタ

音楽学（D26: Meyer期待理論）、舞台芸術（D28: Fischer-Lichte autopoietic feedback loop）、神経科学（D08: 予測符号化）の3領域が独立に「期待→誤差→再評価」ループを記述する。「予測誤差を創造資源とする」テーゼの強力な傍証群。

### 遅延負帰還と抱持

activator/inhibitor + 遅延負帰還がパターン形成の必要条件であることは、化学・発生生物・神経・心臓・生態・細胞生物学の6領域以上で確認済み。抱持 が意識の特殊機能ではなく、存在の創造の普遍的構造であることを示唆する。

## 6. スピノルとの類似（補足）

スピノルの「360度で符号反転、720度で復元」は、5段階モデルの変換構造を眺めるための比喩的着想として参照される。モデルの導出根拠ではなく、構造の視覚的理解を助ける補助線である。

- 1回転（360度）: 見かけ上は戻るが、位相が反転している
- 2回転（720度）: ようやく復元する

この性質は、束から場への回帰が単純な反復ではないことを示唆する。

## 7. この文書の使い方

- **レポート生成時**: 各段階の定義と対応概念を参照し、reader-rules に従って読者向けに変換する。
- **構造対応の評価時**: 各段階の定義と遷移条件を基準にする。段階数の一致ではなく、移行メカニズムの同型性を見る。
- **用語の確認時**: knowledge/glossary.md と併用する。
- **LLM が creation-space の全体像を把握するとき**: この文書と knowledge/glossary.md を読めば、5段階モデルの定義・性格・評価方法・横断的知見の概要に到達できる。

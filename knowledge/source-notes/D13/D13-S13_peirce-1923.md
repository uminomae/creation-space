## 2. 要旨（読んだ内容に基づく）

Cohen が Peirce 没後に編集した論文集で、Peirce の形而上学・宇宙論の主要論文を集める。Cohen の Introduction は、Peirce 哲学を 3 つの核概念 — **tychism (偶然主義)**, **synechism (連続主義)**, **agapism (愛主義)** — に整理して紹介する。tychism は絶対的決定論を退け、自然には還元不能な irregularity (偶然) が本質的に存在すると主張する。これは実験室での測定経験 — "no two observers...get absolutely identical results" — から帰納された命題であり、偶然を測定誤差ではなく自然の本質とみなす点で先駆的。synechism は連続性を regulative logic として採用し、「あらゆるものが理解可能な形式は generality の形式であり、これは continuity と同じである」と定式化する。agapism (evolutionary love) は創造的進化の駆動力として「ideas literally spread themselves continuously and become more and more general」と定式化し、habit の累積的形成を通じて秩序が生成されると論じる。Cohen は Peirce のこれら 3 原理の統合が、現代物理学の indeterminism と中世 realism (普遍者の実在論) を橋渡しする独創的試みだと評価する。

## 3. 主要主張（原文引用付き、Cohen intro ベース）

### 主張 1: Tychism — 絶対的決定論の拒絶、偶然の本質性

> "laboratory work reveals that 'no two observers...get absolutely identical results,' suggesting that irregularity is fundamental to nature rather than merely observational error."

Peirce は決定論 (Laplace の demon) を退け、自然には「reducible ではない偶然の要素」があるとみなす。これは量子力学に先立つ 40 年前 (1891 年の論文 "The Doctrine of Necessity Examined") に提示された、哲学的 indeterminism の早期形態。

### 主張 2: Synechism — 連続性は regulative logic、metaphysics ではない

> "the form under which alone anything can be understood is the form of generality which is the same thing as continuity."

連続性を absolute metaphysical truth としてではなく、理解の形式 (regulative principle) として採用する。この点で Peirce は Kant 的 regulative idea を継承し、同時に現代 process philosophy (Whitehead) への橋渡しを作る。

### 主張 3: Agapism — 創造的進化は習慣の漸進的拡散として理解される

> "ideas literally spread themselves continuously and become more and more general, generating order through habitual patterns."

agapism は Darwin の natural selection とは異なる evolutionary driver を提案する。ideas (Peirce の意味では forms / habits) が「愛」によって拡散し、互いを include していく過程。これが自然の秩序を生成する。この概念は後年の Whitehead の "creative advance", Wheeler の "law without law", 複雑系の self-organization 理論と構造的に類似する。

### 主張 4: Peirce の 3 原理は現代物理学と中世 realism を統合する

> "Peirce's approach integrated modern physics with medieval realism about universals, avoiding both mechanical determinism and pure nominalism."

Peirce は「普遍者は実在する (realism)」と主張する点で中世 Scholastic と同列だが、19 世紀物理学の indeterminism を取り込む点で near-contemporary。この統合は James の pragmatism, Royce の idealism, neo-realism に影響を与えた。

### 主張 5: Peirce 哲学は断片的だが、米国哲学の foundational figure として位置づけられる

> "establishing him as a foundational figure in American philosophy despite his fragmentary publications and unconventional career."

Peirce は生前に単著を出版せず、雑誌論文と手稿に散在する形で思想を残した。Cohen の本書は、そうした散在を「哲学的宇宙論」という coherent な framework に再構成する初の試みのひとつ。

## 4. 方法論

Peirce の方法は「宇宙論的思弁 + 実験科学からの帰納 + 論理学の体系」の統合。具体的には (1) 論理学 (semeiotic) の厳密な分類から phaneroscopy (phenomenology) の 3 範疇 (Firstness / Secondness / Thirdness) を抽出、(2) 実験科学の empirical finding (観測の non-identity, thermodynamic irreversibility) を tychism の argument に投入、(3) 宇宙論的進化のモデルとして agapism を構築。Cohen の Introduction は Peirce の全体を「3 原理の統合」として再構成する解釈的方法を採る。本書本体は Peirce 自身の論文 (1877-1898) を essays として配列。

## 5. 5段階との対応候補

| 段階 | 対応候補 | 強度 | 原文引用 |
|------|---------|------|---------|
| 1 場 (Field) | Firstness (Peirce 3 範疇の第 1) / 連続的実在 (synechism) | 強 | synechism の定義 |
| 2 波 (Wave) | tychism の irregularity (偶然の波) | 強 | "irregularity is fundamental to nature" |
| 3 縁 (Relation) | Secondness (Peirce 3 範疇の第 2) / reaction の境界 | 中 | Cohen intro では触れられているが本読解は intro のみ |
| 4 渦 (Vortex) | agapism の「ideas spread themselves」 — 拡散的創造過程 | 強 | "ideas literally spread themselves continuously" |
| 5 束 (Bundle) | Thirdness (Peirce 3 範疇の第 3) / law / habit の累積的統合 | 強 | "generating order through habitual patterns" |

**判定基準についての注記**:
- Peirce の tychism / synechism / agapism は、5 段階モデルの「場 → 波 → 渦 → 束」の哲学的原型として強い構造類似性を示す。
- 特に Stage 2 (波 = tychism の偶然)、Stage 4 (渦 = agapism の拡散)、Stage 5 (束 = synechism/Thirdness の習慣的統合) は直接対応可能。
- Peirce の 3 範疇 (Firstness/Secondness/Thirdness) と 5 段階は段階数が異なるが、Thirdness が「habit, law, generality」として 5 段階の束に対応する点は強い。
- 本読解は Cohen の Introduction が中心で、Peirce 自身の論文 (特に "Evolutionary Love" と "The Architecture of Theories") の精読は今回は限定的。深い対応確認には論文精読が必要。

## 6. 限界・留意事項

- **本 source-note は Cohen の Introduction の精読に基づき、Peirce 自身の論文本文は djvu.txt stream での部分確認のみ**。Peirce の tychism / synechism / agapism の厳密な原典引用は含まれない。
- Peirce の全体系 (CP = Collected Papers, 8 巻) の断片のみを本書は含む。全体像には CP や Essential Peirce (Indiana UP) の参照が必要。
- Cohen の解釈は 1923 年当時のもので、後年の Peirce scholarship (Fisch, Hookway, Short, Nöth) による大幅な再解釈は反映されていない。
- 特に Peirce の semeiotic (記号論) と phenomenology (3 範疇論) の関係は Cohen intro では簡潔すぎる。この部分の深掘りは必要。
- agapism は 19 世紀末の宇宙論的 thought experiment であり、現代の進化生物学 (neo-Darwinism) とは philosophical status が異なる。Peirce 自身「scientific hypothesis」と呼ぶが、検証可能性は低い。
- 本 source-note の情報量は他の source-note に比べて少なめ。Peirce の論文原文から直接引用する形での補強が望ましい (将来的に CP volume V or Essential Peirce Vol. 1 から再精読する余地)。

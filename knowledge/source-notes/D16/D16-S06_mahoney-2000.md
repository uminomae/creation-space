## 2. 要旨（読んだ内容に基づく）

本論文は、歴史社会学で多用されながら「歴史が重要（history matters）」という曖昧な標語に堕していた **path dependence（経路依存）** 概念を、厳密に再定義する。Mahoney の中心主張は、経路依存とは単に過去が現在に影響することではなく、「**偶発的（contingent）な初期事象**が、それ自体は先行条件から説明できないにもかかわらず、**決定論的性質（deterministic properties）をもつ制度パターンや事象連鎖**を始動させる」歴史系列に限定されるべきだ、というものである。したがって経路依存の同定には、(1) 結果を特定の歴史的事象に遡って辿ること、(2) その始動事象が偶発的であることを示すこと、の両方が要る。Mahoney は経路依存系列を 2 類型に分ける——**自己強化系列（self-reinforcing sequences）**：制度パターンが形成され「収穫逓増（increasing returns）」によって長期再生産・ロックインされる過程と、**反応系列（reactive sequences）**：時間的に順序づけられ因果的に連結した事象連鎖で、各事象が先行事象への反応である過程。経済学が収穫逓増を効用計算で説明しがちなのに対し、歴史社会学は機能的・権力的・正統化的メカニズムを加えて再生産を説明できる、と論じる。

## 3. 主要主張（原文引用付き）

### 主張 1: 経路依存は「偶発的始動 → 決定論的展開」の系列に限定すべき

> "I argue that path dependence characterizes specifically those historical sequences in which contingent events set into motion institutional patterns or event chains that have deterministic properties." (p.507)

「history matters」という曖昧な用法への対抗として、偶発性と決定性の**両端**を要件化する。

### 主張 2: 同定には始動事象の偶発性の証明が不可欠である

> "The identification of path dependence therefore involves both tracing a given outcome back to a particular set of historical events, and showing how these events are themselves contingent occurrences that cannot be explained on the basis of prior historical conditions." (p.507-508)

偶発性が示せなければ、それは単なる因果連鎖であって経路依存ではない。

### 主張 3: 自己強化系列は収穫逓増によりロックインされ、非効率でも反転困難になる

> "With increasing returns, an institutional pattern - once adopted - delivers increasing benefits with its continued adoption, and thus over time it becomes more and more difficult to transform the pattern or select previously available options, even if these alternative options would have been more 'efficient.'" (p.508)

形成された構造は、より効率的な代替があってもなお自己保存する（ロックイン）。

### 主張 4: 反応系列は各事象が先行事象への反応である連鎖であり、始動の偶発性と「固有の連続性」を要する

> "Reactive sequences are chains of temporally ordered and causally connected events. These sequences are 'reactive' in the sense that each event within the sequence is in part a reaction to temporally antecedent events. ... the historical event that sets the chain into motion must have properties of contingency. Furthermore, the overall event chain itself must be marked by processes of 'inherent sequentiality.'" (p.509-510)

## 4. cs 5段階モデルとの対応

経路依存論は cs 5段階の **波→縁→渦→束** の連鎖に、歴史社会学からの**機構的裏づけと留保**を同時に与える。

| cs 段階 | 経路依存での対応 |
|---|---|
| **波 (Wave)** | 偶発的始動事象（contingent event）。先行条件から説明できない小さなゆれが系列を起こす |
| **縁 (Relation)** | critical juncture（分岐点）。偶発が決定論に転じる境界。反応系列の「各事象が先行への反応」という連結 |
| **渦 (Vortex)** | self-reinforcing process / increasing returns。採用された型が自己強化的に巻き込み増幅する自己組織化 |
| **束 (Bundle)** | lock-in した制度パターン。構造として長期再生産され残る |

**cross-check 知見**: Mahoney の「偶発的始動 → 決定論的展開」という二相構造は、cs の「波（偶発のゆれ）が縁（分岐点）を経て渦・束（自己強化・構造化）へ至る」連鎖と機構的に一致する。とりわけ **increasing returns / 自己強化**は cs「渦（自己組織化）」の社会制度版であり、小さな偶発が増幅して不可逆な構造になる過程を歴史学的に定式化している。

**留保（cs#244 / 束への警告を補強）**: Mahoney の核心的洞察は、ロックインした束（制度構造）が**より効率的な代替が存在してもなお自己保存する**——すなわち**束は最適でも必然でもなく、偶発の固着でありうる**——という点にある。これは cs「束（Stage 5）を創造の必然的・統合的終点として無条件に措定しない」留保（→ `knowledge/schema/five-stages.md` §束、Connell & Slatyer 1977 経由）に、社会科学側から強い具体例を加える。創造の結実（束）は「最良への収斂」ではなく「偶発の経路に固着した構造」でありうる。

**留保2**: 経路依存は偶発性の証明を理論依存とする（"the specification of path dependence is always a theory-laden process"）。cs が原典から独立に構造を読む際も、「どこからが偶発でどこからが必然か」の境界（縁）の措定が観察者の理論に依存することを忘れない。

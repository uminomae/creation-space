## 2. 要旨（読んだ内容に基づく）

Berkovich-Ohana と Glicksohn は、意識と自己性を統一的に扱う現象学的モデル「意識状態空間 (Consciousness State Space, CSS)」を提示する。CSS は 3 つの現象学的次元 (time, awareness, emotion) からなり、すべての体験はこの状態空間内の一点として位置づけられる。CSS は同心円的に二重構造をなし、内側の球 (CC/MS: core-consciousness/minimal-self) は身体に根ざした「今ここ」の最小自己を、外側の球 (EC/NS: extended-consciousness/narrative-self) は時間的連続性をもつ物語的自己を支える。各球はそれぞれ独自の dynamic system として軌道を描き、両軌道は通常拮抗する (DMN と task-positive network の逆相関に対応)。flow と meditation という 2 つの altered state を事例として、この拮抗が崩れて hierarchic integration が生じる様態を描く。Werner (1978) の orthogenetic principle「発達はあらゆる所で未分化なる大域性から、分化・分節化・階層的統合の状態へ進む」を組織原理として採用し、CSS 自体が発達とともにより複雑な構造を獲得すると論じる。

## 3. 主要主張（原文引用付き）

### 主張 1: 意識は 3 次元の現象学的状態空間内の軌道として記述できる

> "Briefly, it is suggested that all phenomenological states fall into two categories of consciousness, core and extended (CC and EC, respectively). CC supports minimal selfhood that is short of temporal extension, its scope being the here and now. EC supports narrative selfhood, which involves personal identity and continuity across time, as well as memory, imagination and conceptual thought. The CSS is a phenomenological space, created by three dimensions: time, awareness and emotion." (Abstract)

時間・気付き・感情の 3 次元が意識の現象学的空間を張る最小集合であり、他の認知機能 (言語、空間認知、注意など) はこの 3 次元の交絡として派生的に説明される。

### 主張 2: CSS は内球 (CC/MS) と外球 (EC/NS) の 2 つの同心球から成り、両者は拮抗する dynamic system として独立に進行する

> "The CSS contains two concentric spheres ... The inner sphere of CC/MS is phenomenologically related to the body, experiencing agency and momentary sensory experiences. It is embodied. The inner sphere is surrounded by the EC/NS sphere, which is phenomenologically further away from the body, in the realm of conceptual thought, language, memories and imagination." (p. 3)

> "These trajectories are usually antagonistic, and phenomenal awareness switches between them ... In the neural space, this is manifested by the collaboration, through synchronization, of the N_i with either N_ms or N_ns." (p. 10)

二重球構造は「身体から心的表象への距離」を軸とし、各球は独自の神経基盤 (内=N_ms, 外=N_ns) と独自のアクセス制御系 (N_i=FPN/DAN) をもつ。

### 主張 3: flow と meditation では典型的拮抗が崩れて hierarchic integration が生じる

> "The CSS model is a dynamic system, with rich self-organizing properties. One novel aspect of CSS is the suggestion that each sphere functions as a separate dynamic system, with its own trajectory over time ... We suggest that alterations in typical CSS dynamics occur when the regular sense of NS is modified. While the typically antagonistic behavior of the trajectories essentially indicates differentiation, here we discuss those conditions wherein hierarchic integration is achieved (in Werner's terms)." (p. 10)

flow では CC/MS 軌道が access awareness の閾値を超え、EC/NS 軌道は抑制される。meditation では両軌道間の同期が高まり、"no-self"/"transpersonal"/"transcendent" の体験状態として現れる。

### 主張 4: Werner の orthogenetic principle が CSS の発達原理を与える

> "we nevertheless outline in short its development, based on Heinz Werner's (1978, p. 108-109) orthogenetic principle of development, that 'wherever development occurs it proceeds from a state of relative globality and lack of differentiation to a state of increasing differentiation, articulation, and hierarchic integration.' This orthogenetic principle has been shown to be consistent with the genetic organization of the cortex." (p. 10)

発達初期は 2 軌道が未分化で区別できず、約 2 歳以降に拮抗行動が観察され始める (Gao et al. 2013 の fMRI 証拠)。成人での flow/meditation はこの分化をさらに進めた hierarchic integration の例とされる。

### 主張 5: 意識体験の任意の一瞬は CSS 内の 1 座標として位置づけられ、モデルは検証可能な予測を生む

> "given that an experience can fall into any coordinate in CSS, the model predicts some experiences which are still being debated. For example, albeit the controversy about the existence of unconscious emotions (e.g., Clore, 1994; Winkielman and Berridge, 2004), the model predicts that full-blown emotions (including hedonic feeling and appraisal) could be experienced without access awareness." (p. 13)

3 次元 × 2 球の組合せから論理的に可能なすべての状態が原理的に発生しうると予測し、一部は実験的に検証可能と主張する。

## 4. 方法論

理論論文 (Hypothesis and Theory article)。著者らは既存の神経現象学的文献 (Varela, Thompson, Damasio, Tononi, Dehaene, Edelman, Csikszentmihalyi) を統合し、3 次元 × 2 球の幾何学的図式 (Figure 1-4) で意識状態を可視化する枠組みを構築する。独自データは提示されず、既存 fMRI 研究 (DMN, FPN, DAN の拮抗)・EEG 瞑想研究 (Berkovich-Ohana et al. 2011-2013)・flow 研究 (Ulrich et al. 2013, Dietrich 2004) を枠組みへマッピングする。Werner の発達原理、Damasio の proto/core/autobiographical self、Tononi の IIT ("main complex") を借用し、それらを CSS 内の座標や軌道として再配置する。最終節で 4 つの予測 (CC/MS trajectory 優勢化、2 軌道の integration、EC/NS 活動低下、antagonistic network 同期) を提示。

## 5. 5段階との対応候補

| 段階 | 対応候補 | 強度 | 原文引用 |
|------|---------|------|---------|
| 1 場 (Field) | CSS 空間そのもの (すべての phenomenological state の repository) | 中 | "a repository of all potentially accessible phenomenological states" (p. 2) |
| 2 波 (Wave) | 2 つの trajectory が時間的に振動し、access awareness の閾値を挟んで上下する | 強 | "the brain alternates dynamically, shifting awareness from internal to external processing" (p. 7); Figure 4A の 2 軌道オシレーション |
| 3 縁 (Relation) | access awareness の threshold、CC/EC 球の境界、N_i による switching | 強 | "At t_1 there is a threat on the driving, resulting in a phase transition: the CC/MS trajectory arrives at the threshold for access awareness, and at the same time, the EC/NS trajectory shifts under the threshold for access awareness." (p. 8) |
| 4 渦 (Vortex) | flow 状態: 自己意識が消え、活動が自己目的化し、時間感覚が歪む (渦状の自己吸収) | 強 | "a merging of action and awareness ... distortion of temporal experience ... loss of reflective self-consciousness ... the experience of the activity as autotelic—containing its own meaning and purpose" (p. 11, Csikszentmihalyi 1990 引用) |
| 5 束 (Bundle) | 3 次元の統合 + 2 球の hierarchic integration。Werner の differentiation→integration 過程 | 強 | "proceeds from a state of relative globality and lack of differentiation to a state of increasing differentiation, articulation, and hierarchic integration" (p. 10) |

**判定基準についての注記**:
- 本論文は 5 段階モデルとの構造的類似度が高い。3 次元の状態空間という幾何学的 "場"、2 軌道の拮抗振動という "波"、閾値超えの位相転移という "縁"、flow という自己吸収的 "渦"、hierarchic integration という "束" が全て明示的に記述されている。
- 特に Stage 4 (渦) と Stage 5 (束) の対応は強い。flow は自己の一時的消失を伴う自己組織化現象として記述され、meditation は軌道間の同期化 (整列した束) として記述される。
- Werner の orthogenetic principle (未分化→分化→階層統合) は 5 段階モデルの progression と構造的に同型。
- Stage 1 (場) は中程度。CSS は状態空間だが、本質的に「すべての体験の入れ物」であり、創造の源泉として記述されているわけではない。

## 6. 限界・留意事項

- 著者自身が §Limitations で明記する限界: (1) 神経空間の解像度が現象学的空間に追いついていない、(2) emotion regulation や reward 等の高次機能が未組入、(3) altered state の CSS 内位置が不明。
- Werner 原理の援用は強いが、本論文では発達の具体的 mechanism (なぜ未分化→分化→統合か) には立ち入らない。
- flow と meditation のみを扱い、dreaming/psychedelic/pathological state (schizophrenia, depersonalization) は脇に置かれる。
- 理論モデルであり、CSS の 3 次元が実験的に orthogonal であるかは検証途上 (著者も "could be in principle accompanied" と控える)。

## 8. 構造類似性の評価（cs#226 新運用基準）

本論文は 5 段階モデルに対する構造類似性が **強** (Stage 2/3/4/5 で強対応)。採用根拠:
- 意識の dynamic system 記述が「creation の前段としての場の分化」と並行し、flow / meditation 事例が Stage 4 (渦) / Stage 5 (束) の神経現象学的裏付けを与える。
- Werner の orthogenetic principle は 5 段階の未分化→分化→階層統合と同型であり、D24 (変容・自己の再構成) の理論枠として有効。
- Tononi IIT, Damasio の proto/core/AS モデル, Csikszentmihalyi flow 理論を一つの状態空間に統合した点で、D24 領域の統合的 anchor として機能する。

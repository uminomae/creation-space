## 2. 要旨（abstract に基づく）

> **注記**: 本ノートは PubMed 掲載の abstract のみに基づく部分読解である。本文 pp.80-125（46頁）は未読。

VIMAP（Vienna Integrated Model of Art Perception）は、人が視覚芸術に対して反応する複数の経路を包括的に説明し、その実証研究のための仮説を提供することを目的とする大型理論レビューである。abstract によれば、本モデルは「ボトムアップ（artwork-derived）処理」と「トップダウン機構」を統合し、芸術経験の生起過程を体系化する。中核は **3つの processing checks（処理チェック）** であり、これらが美的経験の取りうる結果（outcomes）を分岐させる枠組みとして機能する。各段階は感情的・評価的・生理的反応と結び付けられ、さらに「チル（chills）・畏怖（awe）・スリル（thrills）・崇高（sublime）」といった強い反応や、美的感情と日常的感情の差異が論じられる。最終的に、処理段階は脳の機能領域および broader core networks（より広いコアネットワーク）に対応づけられる。

## 3. 主要主張（abstract からの抜粋）

> **注記**: 本文未読のため、原文引用は abstract のみに帰属。3つの processing checks の具体的名称・分岐ロジック・神経基盤の詳細は未確認。

### 主張 1: 芸術反応は bottom-up と top-down の統合として説明できる

> "to present a comprehensive theory explaining... the multiple ways by which people respond to art" — bottom-up, artwork-derived processes と top-down mechanisms の統合 (Abstract)

視覚芸術への反応を単一経路ではなく、複数の処理経路の統合として捉える点が本モデルの骨子。

### 主張 2: 3つの processing checks が美的経験の結果を体系化する

> "three processing checks" が aesthetic experience の possible outcomes を systematize する (Abstract)

美的経験の多様な帰結（快・不快、感動、当惑など）を、処理チェックの通過/失敗の組み合わせとして整理する枠組み。

### 主張 3: 処理段階は感情・評価・生理・脳領域に対応づけられる

> stages を "functional regions in the brain, as well as broader core networks" に結び付ける (Abstract)

各処理段階を神経生理学的相関（脳領域・コアネットワーク）と対応させ、感情的・評価的反応の生起を説明する。

## 5. cs 5段階モデルとの対応

> **注記**: abstract のみに基づく暫定判定。3つの processing checks と段階分岐の詳細を本文で読めば対応が変わりうる。manifest ヒント（美的知覚5段階モデル, Stage 1-5）からは独立に判定した。

| 段階 | 対応候補 | 強度 | 根拠（abstract） |
|------|---------|------|---------|
| 1 場 (Field) | 鑑賞者と作品が出会う前提状況（bottom-up の感覚入力が立ち上がる基盤） | 弱 | "bottom-up, artwork-derived processes" |
| 2 波 (Wave) | 作品由来のボトムアップ感覚刺激の入力・伝播 | 中 | "bottom-up... processes" の最初期段階 |
| 3 縁 (Relation) | bottom-up と top-down が出会い相互作用する界面。processing check が起きる境界 | 中 | "integrat[ing]... bottom-up... with top-down mechanisms"; "three processing checks" |
| 4 渦 (Vortex) | 強い美的反応（chills/awe/thrills/sublime）の立ち上がり——個別の美的体験が渦として成立する瞬間 | **中〜強** | "provocative reactions—chills, awe, thrills, sublime" |
| 5 束 (Bundle) | 処理段階・感情・評価・生理・脳ネットワークが一つの統合体系として束ねられる | 中 | "link processing stages to functional regions in the brain, as well as broader core networks" |

**判定基準の適用**:
- **Stage 4（渦）が相対的に強い**: VIMAP の特徴は、美的経験のうち「感動・畏怖・崇高」といった強い反応（通常の感情とは異なる美的感情）を明示的に扱う点。これは cs の「渦（個・立ち上がり、強度の集中）」と構造的に対応する。ただし本文未読のため強度は中〜強にとどめる。
- **processing checks = 縁の界面**: bottom-up と top-down が出会い、通過/失敗が分岐する「チェック」は、cs の「縁（境界で起きる出来事・分岐）」と照合できる。
- **5 段階モデルとしての性格**: manifest は「美的知覚5段階モデル」と注記するが、abstract では明示的な「5段階」ではなく「3つの processing checks ＋ 統合」として記述される。段階数の正確な対応は本文確認を要する。

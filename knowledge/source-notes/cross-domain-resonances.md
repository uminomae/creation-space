# クロス領域共鳴レジストリ（保留中の Filing 候補・正本）

> **目的**: source-note 精読の過程で見つかった**複数領域にまたがる概念的共鳴**（＝別々の原典が同型の構造・概念を示すこと）を、揮発する session log でなく**追跡される正本**として記録する。
>
> **`cross-domain-anchors.md` との違い**: anchors は「**同一 PDF を複数領域で再利用**」（同じ原典）。本レジストリは「**別々の原典が同型の構造モチーフを示す**」（異なる原典・同じ形）。両者は別事象。
>
> **ステータスの意味**: 各エントリは Q&A Filing（CLAUDE.md）の**候補**。CN 概念化・schema 補強への昇格は **pjdhiro 専権**。ここに載っているものは「正本に残したが、概念ファイル化は保留」の状態。pjdhiro が承認したら `knowledge/concepts/` の CN 化や five-stages schema 補強へ昇格し、本レジストリの該当行に昇格先を追記する。

## 凡例

| 列 | 意味 |
|---|---|
| ID | `R-NN` 連番 |
| 共鳴の主題 | 何が複数領域で同型に現れるか |
| 関与 source-note | 共鳴を示す原典群（領域跨ぎ） |
| 5段階対応 | 主にどの Stage の構造類似か |
| ステータス | `保留`（候補・未昇格）/ `昇格済→{先}` |

## レジストリ

### R-01: ネットワーク相転移／パーコレーション／凍結コードの同型モチーフ

- **共鳴の主題**: 「臨界協調数でのパーコレーション転移（giant component の生成）」と「恣意的だが固定された符号（frozen accident）」が、複雑系物理・生命起源・工学情報の各領域で**同型の構造**として現れる。
- **関与 source-note**:
  - **D02-S13 / D07-S13** Strogatz (2001) — ランダムグラフの相転移・巨大連結成分、複雑ネットワークの臨界
  - **D05-S15** Feistel (2024) — 生命起源のパーコレーション転移（協調数 c=K/N、臨界 c=1）＋遺伝コードが「凍結したコード」として固定
  - **D07-S15** Heylighen (2026) — 遺伝コード＝「frozen accident」型 emergent law、自己組織化による固定された恣意的制約
- **5段階対応**: Stage 3 縁（臨界での連結成立）〜 Stage 5 束（固定された不変則／凍結コード）
- **発見元**: 2026-06-26 #02 セッション（D05-S15/D06-S15/D07-S15 連続精読中）
- **ステータス**: **保留**（pjdhiro 判断待ち。昇格先候補: 新規 CN または five-stages schema の Stage 3-5 補強）

### R-02: ritualisation（構造情報→記号情報の相転移）＝ Stage 3「縁」の物理モデル

- **共鳴の主題**: Feistel の「儀式化（ritualisation）転移」＝構造情報から記号情報への第2種相転移は、「客体→主体」「最初の記号の出現＝生命の始まり」であり、5段階の **Stage 3「縁」（関係が恣意的に決まる臨界）** を記号論・生命起源の語彙で定式化したものと読める。Heylighen の「カップリング→制約→下方因果」や、より一般の「自己組織化＝局所相互作用からの大域秩序」とも接続する。
- **関与 source-note**:
  - **D05-S15** Feistel (2024) — ritualisation＝構造情報→記号情報の相転移、コード対称性の破れ
  - **D07-S15** Heylighen (2026) — カップリング→制約→アトラクタ→下方因果（emergent law）の流れ
  - （関連）行動生物学の儀式化概念（Huxley 1914 / Lorenz / Tembrock）— 原典は Feistel 経由の引用
- **5段階対応**: Stage 3 縁（記号-意味関係の恣意的確定＝symmetry-breaking step）が中核。Stage 4 渦（記号的個の立ち上がり）にも接続。
- **発見元**: 2026-06-26 #02 セッション（D05-S15 精読）
- **ステータス**: **保留**（pjdhiro 判断待ち。昇格先候補: five-stages schema の Stage 3 解説補強、または新規 CN）

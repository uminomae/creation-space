## 2. 要旨（読んだ内容に基づく）

計算能力・自然言語処理・テキストデジタル化の進展により、大量のテキストから文化進化を "big data" 的に研究することが可能になった。物語は人間の coherent な emotional 経験と結合しており、特徴的な感情軌跡・反復パターンを形成する。本論文は Project Gutenberg の fiction から filter した 1,327 ストーリーの emotional arc を分類し、複雑な情動軌跡の essential building blocks を構成する 6 つの core emotional arcs を発見した。3 つの独立な方法 — Matrix decomposition (SVD)、supervised learning (Ward's hierarchical clustering)、unsupervised learning (Self-Organizing Map) — で同じ結論を確認。各 arc について代表的ストーリーを同定し、現在ダウンロード数で測定された成功度との相関を調査。Icarus (rise-fall), Oedipus (fall-rise-fall), two "Man in a hole" (fall-rise sequential) の arc が最大の成功を示す。Vonnegut の rejected master's thesis (1965) の "Shapes of Stories" 講義で提起された "simple shapes of stories can be fed into computers" のアイデアを、現代の sentiment analysis と machine learning で実装したもの。

## 3. 主要主張（原文引用付き）

### 主張 1: Emotional arc ≠ plot — syuzhet vs fabula の区別

> "We emphasize that our method of mining emotional arcs from novels does not measure the popular notion of 'plot'. To make the distinction even clearer, using terms often employed in narratology we consider the common notion of 'plot' to be fabula whereas the emotional arc is an attempt to measure the emotional trajectory of the syuzhet, what could be commonly referred to as the 'structure'."

Booker の "Overcoming the Monster" と "Rags to Riches" は異なる plot だが同じ emotional arc を持つかもしれない。Emotional arc は narrative の syuzhet (物語る順序) に対応し、fabula (出来事の順序) とは独立した次元である。

### 主張 2: Vonnegut の先駆け — "Simple shapes can be fed into computers"

> "There is no reason why the simple shapes of stories can't be fed into computers, they are beautiful shapes."
> (Vonnegut, YouTube lecture "Shapes of stories")

Vonnegut は Chicago 大学の rejected master's thesis で emotional arc 分析を提案し、Cinderella と Christianity 原義物語の類似を指摘した (Appendix B で Vonnegut の *Palm Sunday* 引用を再掲)。本論文はその大規模計算実装。

### 主張 3: Hedonometer sentiment analysis — 方法論の基礎

> "To generate emotional arcs, we analyze the sentiment of 10,000 word windows, which we slide through the text. We rate the emotional content of each window using our Hedonometer with the labMT dataset, chosen for lexical coverage and its ability to generate meaningful word shift graphs, specifically using 10,000 words as a minimum necessary to generate meaningful sentiment scores."

labMT (Language Assessment by Mechanical Turk) ベースの Hedonometer を採用。10,000 単語 sliding window は 語彙 coverage と rolling average の trade-off で選択。dictionary-based methods は individual sentences では random 並だが、rolling average により robust になる。

### 主張 4: Project Gutenberg corpus — 1,327 books の選別

> "We start by selecting for only English books, with total words between 20,000 and 100,000, with more than 40 downloads from the Project Gutenberg website, and with Library of Congress Class corresponding to English fiction. To ensure the 40-download limit is not influencing the results here, we further test each method for 10, 20, 40, and 80 download thresholds."

約 50,000 books から filter した 1,327 books を解析。download threshold の sensitivity check で結果の robustness を確認。

### 主張 5: Three independent methods の convergence

> "For our analysis, we apply three independent tools: Matrix decomposition by Singular Value Decomposition (SVD), supervised learning by agglomerative (hierarchical) clustering with Ward's method, and unsupervised learning by a Self Organizing Map (SOM)."

> "We obtain these same six emotional arcs from all possible arcs by observing them as the result of three methods: as modes from a matrix decomposition by SVD, as clusters in a hierarchical clustering using Ward's algorithm, and as clusters using unsupervised machine learning."

3 方法の合意が結果の validity を保証。各 tool の strength:
- SVD: 全 emotional arcs の underlying basis を抽出
- Clustering: arcs を distinct groups に分類
- SOM: stochastic process からの noise 類似 arcs を generate して comparison

### 主張 6: 6 Core Emotional Arcs の同定

> "We find broad support for the following six emotional arcs:
> • 'Rags to riches' (rise).
> • 'Tragedy', or 'Riches to rags' (fall).
> • 'Man in a hole' (fall-rise).
> • 'Icarus' (rise-fall).
> • 'Cinderella' (rise-fall-rise).
> • 'Oedipus' (fall-rise-fall)."

Mode 1 (rise / tragedy) は全 variance の 30% を説明。"Man in a hole" は clustering 結果で 30% の Gutenberg corpus を占める最大 cluster。"Tragedy" 32%, "Rags to riches" 5%, "Oedipus" 31% に分類される。

### 主張 7: Representative stories for each arc

> "The two stories that have the most support from the 'Rags to riches' mode are *The Winter's Tale* (1539) and *Oscar Wilde, Art and Morality: A Defence of 'The Picture of Dorian Gray'* (33689). Among the most categorical tragedies we find *Lady Susan* (946) and *Warlord of Kor* (17958). Number 8 in the sorted list of tragedies is perhaps the most famous tragedy: *Romeo and Juliet*. Mode 2 is the 'Man in a hole' emotional arc, and we find the stories which most closely follow this path to be *The Magic of Oz* (419) and *Children of the Frost* (10736). The negation of mode 2 most closely resembles the emotional arc of the 'Icarus' narrative."

各 mode の closest stories が narrative tradition の prototypical examples と一致する (e.g., Tragedy → Romeo and Juliet, Icarus → Shadowings)。これにより validity の external check を達成。

### 主張 8: Null comparison — word salad と 2-gram Markov nonsense

> "We chose to compare to 'word salad' and 'nonsense' versions as they are more representative of a null model: written stories that are without coherent plot or structure to generate a coherent emotional arc, which is not true of a stochastic process (e.g., a random walk model or noise)."

Random walk は stochastic だが coherent な shape を生むため null にならない。Word salad (shuffled words) と 2-gram Markov chain で生成した nonsense text と比較し、実際のストーリーの emotional arc が unique に coherent であることを確認。

### 主張 9: Success of stories — 特定 arc が download で成功

> "We find that the first four modes, which contain the greatest total number of books, are not the most popular. Along with the negative of mode 2, both polarities of modes 3 and 4 have markedly higher median downloads, while we discount the importance of the mean with the high variance. The success of the stories underlying these emotional arcs suggests that the emotional experience of readers strongly affects how stories are shared. We find 'Icarus' (-SV 2), 'Oedipus' (-SV 3), and two sequential 'Man in a hole' arcs (SV 4), are the three most successful emotional arcs."

Icarus, Oedipus, "Man in a hole" sequential が最も成功する — 単純な rise/fall より複雑な recovery/fall を含む arcs が読者の共感を生む、という仮説。

### 主張 10: Vonnegut/Cinderella/Christianity — Rags to riches 類似性

Appendix B で Vonnegut の *Palm Sunday* からの引用を掲載:
> "The sudden drop is the stroke of midnight at the ball. Cinderella is in rags again. All the presents have been repossessed. But then the prince finds her and marries her, and she is infinitely happy ever after."
> "those steps at the beginning look like the creation myth of virtually every society on earth. And then I saw that the stroke of midnight looked exactly like the unique creation myth in the Old Testament. And then I saw that the rise to bliss at the end was identical with the expectation of redemption as expressed in primitive Christianity."

Vonnegut の文化横断的観察 (Cinderella ≈ Creation/Fall/Redemption myth) を emotional arc 分析で形式化。

## 4. 方法論

- **Sentiment analysis**: Hedonometer (Dodds et al. 2011) + labMT (Dodds et al. 2015) lexicon で word-level happiness score を算出
- **Sliding window**: 10,000 words の rolling window を 10,000 word gap で N points 生成 (各 book の time series)
- **Corpus**: Project Gutenberg 1,327 books (English fiction, 20K-100K words, ≥40 downloads)
- **Matrix decomposition**: Books × time points 行列 A = UΣV^T の SVD。右特異ベクトル (V^T 行) が modes として機能
- **Hierarchical clustering**: Ward's method でツリー生成、silhouette coefficient で cluster number 最適化
- **Self-Organizing Map**: 8×8 Kohonen SOM (64 nodes)、winner-take-all、α = -0.15 decay
- **Null comparison**: "word salad" (shuffled) と "nonsense" (2-gram Markov) を baseline として検証
- **Visualizations**: hedonometer.org で各 book の interactive emotional arc visualization を公開

## 5. 5段階との対応候補

| 段階 | 対応候補 | 強度 | 原文引用 |
|------|---------|------|---------|
| 1 場 (Field) | Emotional sentiment space (labMT 10,000-word lexicon に基づく連続 happiness score 場) | 強 | "We rate the emotional content of each window using our Hedonometer with the labMT dataset" |
| 2 波 (Wave) | Emotional arc — 各 book の time-series 上の happiness wave、12 SVD modes に分解される波形パターン | 強 | "Top 12 modes from the Singular Value Decomposition of 1,327 Project Gutenberg books" |
| 3 縁 (Relation) | SVD modes の orthogonal decomposition、3 methods 間の結果合意、cluster 間の distance matrix | 強 | "We obtain these same six emotional arcs from all possible arcs by observing them as the result of three methods" |
| 4 渦 (Vortex) | "Man in a hole" (fall-rise), "Icarus" (rise-fall), "Cinderella" (rise-fall-rise), "Oedipus" (fall-rise-fall) の cyclic recovery dynamics | 強 | "'Man in a hole' (fall-rise). 'Icarus' (rise-fall). 'Cinderella' (rise-fall-rise). 'Oedipus' (fall-rise-fall)." |
| 5 束 (Bundle) | 6 basic arcs が narrative space 全体の essential building blocks として複雑な感情軌跡を構成 | 強 | "a set of six core emotional arcs which form the essential building blocks of complex emotional trajectories" |

**判定基準**:
- Stage 1 (強): labMT lexicon + Hedonometer という明示的 sentiment field を定義
- Stage 2 (強): Time-series の wave pattern (mode 1-12) を明示的に SVD で分解する
- Stage 3 (強): SVD, clustering, SOM の 3 独立法の orthogonal relation が結果の validity を保証
- Stage 4 (強): Rise-fall の周期的パターン、特に Cinderella の "rise-fall-rise" や Oedipus の "fall-rise-fall" は self-referential recovery の「渦」的動態
- Stage 5 (強): 6 arcs が narrative 全体の building blocks である主張は、複雑な物語を単純な要素の「束ね」として理解する立場

## 6. 限界・留意事項

- **Emotional arc ≠ plot**: 6 arcs は syuzhet の emotional pattern を捉えるが、物語の意味・テーマ・登場人物配置などの fabula 次元は捉えない
- **Dictionary-based sentiment の限界**: 著者自身が "individual sentences では random 並" と認める。文脈・皮肉・比喩は 10K window でも完全には処理できない
- **Project Gutenberg の偏り**: Public domain fiction (主に 19-20 世紀前半) に限定、現代文学は含まれない。文化横断性の主張には慎重を要す
- **Download を success 指標とすることの妥当性**: ダウンロード数は popularity の rough proxy であり、cultural influence や literary merit の測定ではない
- **6 の決定性**: SVD modes 5-6 以降の higher-order modes は variance 寄与が小さく、6 modes で停止したことは経験的決定
- **Plot theories の 3/7/20/36 との対応**: Appendix A で既存 plot theories を紹介するが、それらとの系統的な mapping は本論文では行われない
- **Causal inference の欠如**: なぜ特定 arc が成功するかの因果機構 (cognitive/cultural) は speculative に留まる

## §A: D22 のどの理論が 5段階の理解を押し広げるか

### 1. タックマンは D22 における最も素直な全段階アンカーである

- `EV-D22-003` は `場→波→縁→渦→束` を最も切れ目なく記述する。`Forming / Storming / Norming / Performing / Adjourning` は、D22 の中で唯一に近い全段階の基準線になる。
- とくに `Norming` は、縁を「関係があること」ではなく「役割・規範・信頼が編まれること」として具体化する。D22 で縁が強い理論は、関係網だけでなく、境界のルール化まで書いている。
- `Adjourning` の再読も重要で、束は単なる成果ではなく、解散後に残る役割、学習、手順の持ち越しとして見える。D22 では束が「残る構造」に寄って記述されやすい。
- 限界: `Forming` はすでに目的や役割探索を含むため、5段階の最も素朴な `場` よりは構造化されている。D22 の場は、完全な未分化ではなく、すでに組織目的に触れている。

### 2. ワイクとエフェクチュエーションは `縁→渦` の厚みを最も押し上げる

- `EV-D22-007` と `EV-D22-009` は、D22 の強みが `縁→渦` にあることをはっきり示す。前者では enactment、後者では crazy quilt が、関係の網の中で次のまとまりを駆動する。
- この2件を並べると、縁は「接触」ではなく「結果がまだ決まらないまま、関係と実践が同時に編まれる局面」として見える。D22 の縁は、未決定性の維持と関係形成の同時進行に厚みがある。
- その結果、渦も単なる完成形ではなく、もっともらしい物語や事業の足場が立ち上がる局面として読める。D22 では渦が、個体内のまとまりより共同実践のまとまりとして出やすい。
- 限界: どちらも前半または中盤に強く、`場` の入口や `束→場回帰` までは十分に書かない。強縁理論がそのまま全段階理論になるわけではない。

### 3. 野中・竹内と TPS/アジャイルは、渦と束が「実装された構造」として残ることを示す

- `EV-D22-001` と `EV-D22-008` は、D22 における渦と束の像を最も具体化する。前者では原型化と cross-leveling、後者では prototype / MVP / 標準作業が、まとまりと残存構造の橋になる。
- この並びから見えるのは、D22 の束が「安定した理解」ではなく、手順、標準、共有知、再利用可能な作業構造として残ることだ。束は制度や運用に沈殿したとき最も見えやすい。
- 同時に、渦はプロトタイプや実装単位のような可触的なまとまりとして現れる。D22 は渦を抽象的な統合より、試作物・運用単位・チーム実践として描く。
- 限界: この2件では `場` と `縁` が圧縮されやすい。とくに TPS は波の検出と束の安定化が強く、その中間で何が関係的に編まれるかは補助的にしか出てこない。

### 4. U理論は、場を「起点」より「再到達点」として読ませる

- `EV-D22-011` の価値は、5段階にきれいに並ぶことではなく、既存の束からどう離れて場へ入り直すかを可視化する点にある。
- D22 の他理論では場が前提扱いになりやすいが、U理論は、観察、下降、presencing を通じて「場に入ること自体が仕事」であると示す。D22 における場は、しばしば自然な出発点ではない。
- この読みは `束→場回帰` を考える上で重要である。場は最初からある海ではなく、既存のまとまりを緩めてはじめて回復される状態かもしれない。
- 限界: `Crystallizing` は縁としては弱い。集団意図の収束は見えるが、関係網と未決定性の描写は `EV-D22-003` や `007` ほど強くない。

### 5. 弱い対応や部分対応を弱いまま残すこと自体が、5段階モデルの理解を守る

- `EV-D22-006` は縁が空白に近い理論として残す価値がある。探索/活用の二分法は有用だが、それだけでは `場→波→縁→渦→束` を通さない。
- `EV-D22-010` は応答特性の理論であり、生成プロセスそのものではない。波や境界接触は語れても、縁から渦へ何が立ち上がるかは弱い。
- `EV-D22-002` は表面的には5モードで扱いやすいが、その扱いやすさ自体が過適合の入口になる。手順の順序を入れ替えても対応できてしまう理論は、構造的対応の主証拠にしにくい。
- `EV-D22-004` も波と束には強いが、縁は市場境界での試行として薄く記述される。D22 では「変化が起きる」理論と「関係の界面で生成する」理論を分けて扱う必要がある。

## §B: 5段階モデル側に残る問い

### 問い1: D22 では、なぜ `場` がもっとも薄く、`縁→渦` がもっとも厚いのか

- Run1 の段階マップでも、D22 の厚みは `縁→渦` に集中していた。
- 経営理論は、すでに目標、役割、資源配分、組織課題が与えられたところから始まるため、未分化な場そのものを前提化しやすい。
- 5段階モデルにとっての問いは、場を単なる始点として置き続けてよいのか、それとも「すでに構造化された現場から場へ入り直す条件」を別に書くべきか、である。

### 問い2: D22 の `縁` は、どこまでを満たせば強い縁と呼べるのか

- `EV-D22-003` `007` `009` は強縁、`001` `004` `008` `011` は部分対応、`006` は空白に近い。
- この差を見ると、強縁には少なくとも「関係網」「未決定性」「そこから渦へ進む駆動」の3つが必要だと分かる。
- 5段階モデル側には、縁を広く言い過ぎると何でも入る、狭く言い過ぎると実践理論が落ちる、という校正問題が残る。

### 問い3: `束` は「終点」なのか、「運用可能な残存構造」なのか

- D22 では束が、標準作業、cross-leveling、共有学習、役割継承、制度として見える。
- つまり束は、落ち着いた状態というより「別の場面へ持ち運べる形で残ったもの」として記述されている。
- 5段階モデル側の問いは、束の定義を安定一般で済ませるのか、それとも移送・継承・制度化まで含めて捉えるのか、である。

### 問い4: `束→場回帰` は段階そのものなのか、別の解除機構なのか

- U理論、PDCA の予備候補、タックマンの Adjourning 再読は、既存の束をほどいて次の場へ移る問題を示す。
- しかし D22 の既存11件だけでは、この回帰は全段階の一部というより、既存構造を解除する補助手続きとして見えることが多い。
- 5段階モデル側には、回帰を正規の段階移行として書くのか、再起動条件として別に書くのかという未解決が残る。

## §C: 5段階モデルの限界や修正仮説

### 仮説1: D22 を通すと、場は「最初にあるもの」より「束から離れて再到達するもの」として見える

- D22 の多くの理論は、すでに制度、目標、役割が与えられた状況から始まる。
- そのため、場を最初のゼロ地点として読むより、「既存のまとまりから距離を取り直した結果として回復される状態」と読む方が整合的な場合がある。
- `[SPECULATIVE]`

### 仮説2: 束は「安定」ではなく「継承可能な残存構造」と定義した方が D22 に対して精度が高い

- D22 で束が強く見えるのは、制度、標準、共有知、再利用可能な実践として残るときである。
- この観点では、束の判定基準は「落ち着いたか」ではなく「別の人・別の場面・次のサイクルに持ち越せるか」に移る。
- `[SPECULATIVE]`

### 仮説3: 縁には強度差を導入し、「強縁 / 部分縁 / 空白」を明示した方がよい

- D22 は縁の記述が豊かな領域だが、その豊かさは同時に過適合の危険でもある。
- 既存の evidence にある強縁アンカーと空白アンカーを保ったまま、縁の強度差を表で持つ方が、5段階モデルの比較精度が上がる。
- `[WEAK_MAPPING]`

### 仮説4: 5段階比較では、過程理論と応答特性理論を同じ精度で扱わない方がよい

- D22 では、生成順序を語る理論と、ショックや不確実性への応答特性を語る理論が混在する。
- 後者を前者のように読むと、波や縁ばかりが膨らみ、渦や束の生成が空洞化しやすい。
- 5段階モデル側で理論型の区別を持つと、比較の基準がかなり安定する。
- `[SPECULATIVE]`

## §A: 横断パターン

### 1. D22 の主戦場は `縁→渦` であり、ここに11件の共通した厚みが集中する

- `EV-D22-003` `007` `009` は、D22 の中で `縁` を最も強く校正するアンカーである。`Norming`、`enactment`、`crazy quilt` はいずれも、関係が増えるだけでなく、結果がまだ決まらない界面から次のまとまりを立ち上げる。
- この3件を軸に11件を並べると、D22 の `縁` は「接触」ではなく、「関係網・未決定性・渦への駆動」が同時にある局面として見える。
- そのため D22 の `渦` も、内面的な統合より、共同実践として立ち上がる暫定構造として現れやすい。もっともらしい物語、プロトタイプ、事業の足場、機能するチームがここに入る。

### 2. D22 の `束` は「終わり」より「残る構造」として記述される

- `EV-D22-001` `003` `008` `011` を横断すると、D22 の `束` は安定一般ではなく、cross-leveling、役割継承、標準作業、新実践の制度化のように、次の場面へ持ち越せる残存構造として書かれている。
- ここでは `束` の判定基準が「落ち着いたか」より「別の人・別の局面でも再作動するか」に寄る。
- 5段階モデル定義の「構造化された成果」は、D22 を通すと、成果物そのものより運用可能な手順・慣行・共有知として具体化される。

### 3. D22 では `場` が薄く、しかもゼロ地点より「再到達点」に近い

- `EV-D22-011` は、既存の束や慣性から離れて `場` に入り直すプロセスを最もはっきり可視化する。
- `EV-D22-003` の `Adjourning`、`EV-D22-001` の cross-leveling、`EV-D22-008` の標準化も、束が残った後に次のサイクルの前提を作るという意味で、`束→場回帰` を示唆する。
- したがって D22 の `場` は、完全な未分化の始点としてより、既存構造をいったん緩めたときに再び開く状態として現れやすい。

### 4. 11件は「全段階理論」と「部分特化理論」にきれいに分かれる

- 全段階アンカーは `EV-D22-003` が中心で、`001` `007` `008` `011` が周辺から補強する。
- 部分特化理論としては、`007` `009` が `縁→渦`、`001` `008` が `渦→束`、`010` が波以後の応答特性、`006` が探索/活用の大枠、`004` が市場再編の後半構造を強く担う。
- ここから見える横断パターンは、D22 が5段階を均等に説明する領域ではなく、中盤から後半を高解像度で厚くする領域だということである。

## §B: 精度と限界

### 強い対応が成立する境界

- `縁` が強いのは、関係網、未決定性、そこから渦が立ち上がる駆動が理論内部で明示されるときである。`003` `007` `009` はこの条件を満たす。
- `束` が強いのは、成果や安定ではなく、継承・制度化・移送可能性まで書かれているときである。`001` `003` `008` はここが強い。
- `場` が有効なのは、前提化された組織文脈そのものではなく、構造化以前あるいは再開放された状態として読める場合に限られる。

### 破綻しやすい境界

- 段階数が近いこと自体は強い根拠にならない。`002` と `011` は有益だが、5ステップ/7ステップをそのまま圧縮すると恣意性が増える。
- 生成過程を語る理論と、応答特性や設計原理を語る理論は同じ精度で比較できない。`010` は有力な補助線だが、5段階そのものの全過程を記述してはいない。
- 二分法や大枠トレードオフは、`場→波→縁→渦→束` の全鎖を自動的には与えない。`006` はまさにその反例で、空白を空白のまま残すことが比較精度を守る。

### D22 横断から見えた比較原則

- D22 では「理論が何をうまく説明しないか」を残した方が、5段階モデルとの比較は安定する。
- 強い理論を全段階理論へ拡張し過ぎず、弱い理論を無理に救済しないことが、横断分析の最大の安全弁である。

## §C: 盲点

### 1. `場` を社会的に持続させる系譜が薄い

- 現在の11件は、チーム、起業、改善、制度化の理論が厚い一方で、未分化な共有実践がどう保たれ、どう次の生成条件になるかを扱う系譜が弱い。
- そのため `場` は導入時の前提か、U理論的な再到達点としてしか見えにくい。

### 2. `渦→束` を組織全体へ移送する変革実装の系譜が欠ける

- `001` `008` は制度化を示すが、局所的なまとまりが組織横断でどう定着し、抵抗や導入過程をどう越えるかを独立に扱う理論群が現11件には少ない。
- そのため D22 の `束` は「残る構造」としては見えるが、「どう広がるか」の解像度にはまだ空白が残る。

### 3. 戦略・能力再編の中間層が薄い

- `004` と `006` は再編や配分を扱うが、既存能力の組み替えがどのように `縁→渦→束` を跨ぐかを埋める中間理論が不足している。
- この空白のため、D22 では「市場が変わる」「探索と活用を配る」は見えても、能力がどの界面で再編されるかが弱い。

## §D: 保持論点の更新

### 仮説1: 場は「最初にあるもの」より「束から離れて再到達するもの」である

- `EV-D22-011` が直接の根拠になり、`003` `001` `008` の束残存もこの読みを補強する。
- ただし D22 単独では、再到達された `場` の質を厚く書く理論がまだ少ない。
- 判定: 強化。ただし依然として `[SPECULATIVE]`

### 仮説2: 束は「継承可能な残存構造」と定義した方が精度が高い

- 11件横断で最も強化された論点である。D22 の `束` は制度、役割、共有知、標準、残る意味体系として一貫して現れる。
- 判定: 大きく強化。D22 横断の中心結論として保持

### 仮説3: 縁には強度差を導入した方がよい

- `003` `007` `009` の強縁、`001` `004` `008` `011` の部分対応、`006` の空白がはっきりしており、横断比較でもこの差は消えなかった。
- 判定: 強化。D22 は強度差を導入する必要性をもっとも明確に示す領域である

### 仮説4: 過程理論と応答特性理論を同じ精度で扱わない方がよい

- `010` の再定位、`006` の空白保持、`004` の後半偏重は、理論型の混同が比較精度を崩すことを示している。
- 判定: 強化。しかも D22 では「全段階理論 / 部分特化理論 / 応答特性理論」の三区分まで進めた方がよい

## §E: 統合結論

- D22 の11件を横断すると、5段階モデルに対する最大の貢献は `縁` と `束` の再定義にある。`縁` は関係網・未決定性・渦への駆動が揃う界面であり、`束` は安定一般でなく継承可能な残存構造である。
- 同時に D22 は、`場` を十分に豊かには記述しない。むしろ既存の束を緩めた後に再到達される状態として `場` を示唆する。そのため D22 は、5段階モデルの起点より中盤以後を磨く領域である。
- D22 cross-insight の価値は、11件を通じて「どこが強いか」だけでなく、「どこがまだ書けていないか」をはっきり分けた点にある。

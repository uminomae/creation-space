# Agent: Gap Scan

## ミッション

D22 の過適合を下げるため、現行11件の外にある有力候補を local materials から抽出し、Run2 の優先順位を付ける。

## 結論

- D22 の不足は「社会的実践」「再構成能力」「改善ループ」「変革実装」「戦略対照枠」の5系統。
- Run2 の優先順は `CoP -> Dynamic Capabilities -> Deming/PDCA -> Change implementation -> Strategy/RBV`。
- ここで必要なのは件数追加ではなく、既存11件の万能化を防ぐための対照枠と安全弁の追加。

## 候補表

| 候補系統 | 役割 | 既存11件との関係 | 期待される強段階 | provisional triage | 優先度 |
|---|---|---|---|---|---|
| Community of Practice (Lave/Wenger 系) | 知識創造の社会的実践側を補う | `EV-D22-001` の `ba` を、共同実践と参加の側から補強できる | 縁 / 束 | CA | A |
| Dynamic Capabilities (Teece 系) | 探索/活用と破壊的イノベの再構成能力を補う | `EV-D22-004` と `006` の間を埋める | 渦 / 束 | CA | A |
| Deming / PDCA | TPS の上位改善ループを明示する | `EV-D22-008` の parent frame として自然 | 束 -> 場回帰 | CA | A |
| Change implementation (Lewin / Kotter / ADKAR) | 制度化と変革実装を独立に検証する | `EV-D22-003` と `011` の実装側対照枠になる | 波 / 束 | CA | B |
| Strategy / RBV / Porter | 破壊的イノベの対照枠を作る | `EV-D22-004` の「既存側」を相対化できる | 束 | CA または control | B |

## 予備候補

- 限定合理性・意思決定バイアス
- TOC / 制約理論
- Resilience / ERM

## 除外メモ

- Schumpeter / Hayek / Knight は D21 境界を越えやすく、Run2 の主対象にはしない。
- Resilience / ERM は `EV-D22-010` と近く、現段階では差分が弱い。
- TOC は面白いが、まず `PDCA` と `TPS` を先に縦に通したほうが構造が締まる。

## Run2 推奨順

1. CoP
2. Dynamic Capabilities
3. Deming / PDCA
4. Lewin / Kotter / ADKAR
5. RBV / Porter

## 期待効果

- `CoP` を入れると `EV-D22-001` の「知識創造が誰のあいだで成立するか」が強くなる。
- `Dynamic Capabilities` を入れると `EV-D22-004` と `006` の橋ができ、D22 の再構成能力が厚くなる。
- `PDCA` を入れると `EV-D22-008` の束→場回帰を、改善ループとして説明しやすくなる。
- 変革実装と戦略対照枠を足すと、D22 が「何でも5段階で読める」領域に見える危険を下げられる。

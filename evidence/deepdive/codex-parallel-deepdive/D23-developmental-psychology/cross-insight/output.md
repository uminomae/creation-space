## §A: 横断パターン

### 1. D23 を横断すると、5段階の厚みは `縁→渦→束` に最も集中する

- 15件のうち強い対応が出るのは、Kegan、Thelen & Smith、Vygotsky、Fischer、Stern、Tomasello のように、関係や変動の界面から新しいまとまりが立ち上がる理論である。
- ここでの `縁` は単なる接触ではない。足場かけ、技能協調、共同注意、情動調律のように、まだ結果が決まっていない界面で何かが生成される局面として現れる。
- `渦` も完成済みの自己ではなく、内面化、新アトラクタ、新技能、共有目標のように「まとまりが立ち上がる瞬間」の記述として厚い。
- `束` は終点一般ではなく、内的作業モデル、skill web、言語、規範、原理のような、別場面に残る構造として繰り返し現れる。

### 2. D23 の `場` は空白の起点ではなく、後続の変化を配向する前構造として現れやすい

- Bowlby の安全基地、Vygotsky の社会的関係場、Fischer の支援条件つき可能空間、Thelen のアトラクタ盆地は、いずれも `場` を「何も起きていないゼロ地点」として扱わない。
- D23 を横断すると、`場` は未分化であると同時に、すでに支え、制約、履歴、関係配置を含む。
- そのため `場→波` は、空白から差が出るというより、前構造の中で限界、不安定化、差異が露出する移行として読む方が精度が高い。

### 3. D23 の `波` は独立段階というより、限界露出と再編開始の信号として現れる

- Piaget の同化不能、DIDS の探索と反芻、Erikson の危機、Kohlberg のジレンマ、Thelen の不安定化はいずれも、既存構造がそのままでは通らない局面を記述する。
- ただし D23 の主要理論群は `波` 単独に長く留まるより、そこからどのような媒介や再編が起きるかを厚く書く。
- したがって D23 は「差が立つこと」の領域というより、「差がどう関係化され、まとまりへ移るか」の領域である。

### 4. 15件は「全鎖を比較しやすい理論」と「部分を鋭く照らす理論」に分かれる

- 全鎖アンカーは Kegan、Thelen & Smith、Vygotsky、Fischer、Tomasello であり、5段階をほぼ通しで比較できる。
- 部分特化理論としては、Stern と Bowlby が `場/縁/束`、DIDS と Erikson が `波/縁/渦`、Kohlberg が `縁/渦/束` を強く担う。
- Maslow と AQAL は対応理論というより、「段階数の近さ」や「包括性」だけで強対応と見なしてはいけないことを示す監査枠に近い。

## §B: 精度と限界

### 強い対応が成立する境界

- 強い対応は、理論内部に `縁→渦` の生成機構が明示されているときに成立する。足場かけから内面化へ、相転移近傍から新アトラクタへ、技能協調から新技能へ、共同注意から共有実践へ、という連鎖がその典型である。
- もう一つの条件は `束` の判定が「安定したか」ではなく「別場面に残るか」で書かれていることである。Fischer、Bowlby、Tomasello、Kohlberg はこの点で横断的に揃う。
- D23 横断では、少なくとも `移行機構 / 関係スコープ / 時間スケール / 移送可能性` の4軸で比較しないと、強度の違う理論を同列に扱ってしまう。

### 破綻しやすい境界

- 段階数の近さだけでは根拠にならない。Rochat、Erikson、Maslow、AQAL は、それぞれ有用だが、段階ラベルをそのまま5段階へ圧縮すると恣意性が増える。
- 内容序列や価値序列を語る理論は、生成メカニズムの理論と同じ精度では重ならない。Maslow はその典型である。
- メタ理論は比較対象と監査枠を分けないと過剰一般化を招く。AQAL は構造比較の主素材ではなく、何がどのスケールを語っているかを点検する補助線として扱う方が安定する。

### D23 横断から得られる比較原則

- `縁` を強く判定するには、関係があることだけでなく、媒介、未決定性、そこから次のまとまりが生まれる駆動が必要である。
- `束` を強く判定するには、その場の均衡より、支援撤去後や別文脈での再作動が必要である。
- `場` は中立的な背景としてではなく、後続段階を方向づける条件の束として読むと、15件の整合が高まる。

## §C: 盲点

### 1. 生態学的な多層環境の記述が薄い

- 15件は二者関係、三項関係、文化慣行までは厚いが、家庭、学校、制度、地域、歴史条件がどう重なって発達の `場` や `縁` を変えるかを独立には扱っていない。
- そのため D23 の `場` は前構造として見えても、多層環境の相互作用としてはまだ薄い。

### 2. 非定型発達や破綻ケースからの逆照射が不足している

- 現在の15件は生成メカニズムをかなり豊かに示す一方、トラウマ、発達障害、極端な剥奪、長期的失調のような境界条件をほとんど持たない。
- そのため `縁` が成立しない条件、`渦` が立ち上がっても維持されない条件、`束` が固定化や反復強迫に転じる条件はまだ弱い。

### 3. 横断的介入設計の理論が少ない

- Vygotsky と Fischer は支援条件を語るが、乳児期から成人期までを通して「何をどう支えると次段階が立ち上がるか」を比較可能な形で揃えてはいない。
- D23 は構造類似の記述には強いが、5段階モデル側へ戻して介入原理へ圧縮するには、まだ橋が足りない。

## §D: 保持論点の更新

### 1. `縁` の三項性仮説は強化されるが、二者理論は切り捨てず前駆的 `縁` として残る

- Tomasello、Vygotsky、Fischer を並べると、強い `縁` が対象媒介や共同課題を伴うという insight1 の見立ては強化される。 `[SCALE_JUMP]`
- 一方で Stern や Bowlby は弱いわけではなく、三項的 `縁` に先行する二者的調律や安全基地を示している。
- 判定: 強化。ただし「三項性を満たさない理論は不適切」とまでは言わず、前駆的/高精度の差として保持する。

### 2. `束` を移送可能な残存構造で測る仮説は、D23 横断の中心結論として強化される

- skill web、内的作業モデル、共有規範、普遍化可能な原理が、異なる理論系譜から同じ方向を示している。 `[SCALE_JUMP]`
- 逆に Piaget の均衡化や DIDS の一時的安定は、落ち着きではあっても `束` と呼ぶには条件が弱いことも明瞭になった。
- 判定: 大きく強化。D23 横断で最も再現性の高い更新点。

### 3. `場` を前構造として読む仮説は強化される

- 安全基地、支援条件、アトラクタ盆地、社会的関係場が揃ったことで、`場` を無色の始点とみなす読みは後退する。 `[SCALE_JUMP]`
- 判定: 強化。`場` は未分化でありつつ、すでに次の変化の方向を含む条件場として保持する方がよい。

### 4. 「比較対象 / 限定的比較対象 / 監査枠」の三区分は必要性が増した

- Kegan、Thelen & Smith、Vygotsky、Fischer、Tomasello は比較対象として強い。
- DIDS、Piaget、Erikson、Bowlby、Stern、Kohlberg は限定的比較対象として有益である。
- Maslow と AQAL は監査枠に寄せた方が精度が落ちにくい。 `[SPECULATIVE]`
- 判定: 強化。D23 はこの三区分を導入する根拠が十分ある。

## §E: 統合結論

- D23 の15件を横断すると、5段階モデルとの最大の接点は `縁→渦→束` の再定義にある。`縁` は媒介された関係界面、`渦` はそこで生じるまとまり、`束` は別場面へ残る構造として読むと整合が高い。
- 同時に D23 は、`場` を空白の起点としてではなく、安全基地、支援条件、履歴、アトラクタを含んだ前構造として描く。ここが 5段階モデル側の `場` 理解を押し返す。
- したがって D23 の価値は、「発達理論には段階がある」ことではない。関係の中で新しい秩序がどう生まれ、どう残るかを、複数の系譜から具体的な移行メカニズムとして与える点にある。

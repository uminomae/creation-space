## 1. 対象の同定

T2 が記述する「閾値（threshold）」は、縁→渦遷移の条件を規定する構造である。11ドメインが直接主題化し、全30領域中少なくとも17領域で関連する記述が確認されている。形式化の第一歩として、自然言語の記述を4カテゴリに分解する。

### 1.1 対象（Objects）

| 記号候補 | 自然言語 | 出現領域 |
|---------|---------|---------|
| X | 状態空間 — 系が取りうる状態の全体 | 全領域 |
| x(t) | 系の状態（時刻 t における）| D02, D03, D06, D29 |
| λ | 制御パラメータ — 系の外部条件 | D02, D03, D06, D29 |
| λ_c | 臨界パラメータ値（閾値）| D02(臨界温度), D03(活性化エネルギー), D06(チャンドラセカール限界) |
| En | 縁帯域 — 閾値近傍の構造（T1 で定義済み）| 全領域 |
| Vx | 渦領域 — 遷移後の状態集合 | 全領域 |
| Σ_c | 閾値面 — パラメータ空間内の分岐集合 | D02, D29 |

### 1.2 性質（Properties）

| 性質 | 自然言語 | 形式化候補 |
|------|---------|-----------|
| 不可逆性 | 閾値を超えた遷移は元に戻れない | 力学系の不安定多様体への遷移。帰還経路の非存在 |
| 臨界減速 | 閾値近傍で系の回復速度が低下する | ヤコビアンの固有値の実部が 0 に接近 |
| 突発性 | 量的蓄積が質的変化に転じる | 分岐パラメータが臨界値を横切る瞬間 |
| 制御可能性 | 閾値を上げ下げできる場合がある | 触媒（D03）= λ_c の低下、抱持（D3）= λ_c の引き上げ |
| 確率性 | 閾値が確定した点でなく確率分布である場合 | パーコレーション閾値 p_c（D29）、統計的閾値 |
| スケール依存性 | 閾値がスケールによって異なる振る舞いを示す | 繰り込み群的記述（D29 の臨界現象）|

### 1.3 関係（Relations）

| 関係 | 自然言語 | 形式化候補 |
|------|---------|-----------|
| 帯域と閾値の包含関係 | 閾値は帯域の端にある | Σ_c ⊆ ∂En（T1 定理1 と整合）|
| 閾値 → 不可逆遷移 | 閾値超過が遷移を引き起こす | λ が λ_c を横切ると安定性が消失する |
| 蓄積 → 閾値到達 | 量的変化が閾値に近づく | dλ/dt > 0 の持続が λ → λ_c をもたらす |
| 触媒 ↔ 閾値操作 | 触媒は閾値を下げる装置 | λ_c → λ_c - δ（触媒効果）|
| 抱持 ↔ 閾値操作 | 抱持は閾値を上げる態度 | λ_c → λ_c + δ（抱持効果）|
| 渦不到達 ↔ 閾値未到達 | 縁で止まることの構造 | λ < λ_c のまま dλ/dt → 0 |

### 1.4 量化（Quantification）

| 量的記述 | 自然言語 | 形式化候補 |
|---------|---------|-----------|
| 閾値の値 | 臨界温度、チャンドラセカール限界 | λ_c ∈ R（または R^k）|
| 不可逆性の程度 | 遷移後の帰還困難度 | ポテンシャル障壁の高さ ΔV |
| 臨界減速の指標 | 回復速度の低下度 | max Re(σ(Df)) の符号変化率 |
| 制御幅 | 閾値をどれだけ動かせるか | δ_max = sup{δ : λ_c ± δ が物理的に実現可能} |
| 遷移の急峻さ | 変化の速さ | ∂x/∂λ |_{λ=λ_c}（勾配の発散）|

## 2. 遷移の類型分解

T2 の横断分析から、閾値遷移には以下の質的に異なるモードが存在する。

| 遷移モード | 特徴 | 数学的対応候補 | 代表的領域 |
|-----------|------|-------------|-----------|
| 不連続遷移 | 一次相転移的。量の蓄積が突如として質に転じる | Saddle-node 分岐 | D02(一次相転移), D06(重力崩壊) |
| 連続遷移 | 二次相転移的。秩序パラメータが連続的に発生 | Pitchfork/Transcritical 分岐 | D02(二次相転移), D04(漸進的種分化) |
| 確率的遷移 | 閾値自体が確率変数 | パーコレーション理論 | D29(SOC), D08(神経発火) |
| 制御された遷移 | 外部介入で閾値が操作される | パラメータ空間の並進 | D03(触媒), D12(IPM), D22(自働化) |
| 遷移の不在 | 閾値に到達しないまま系が停止 | 不動点への収束 | D07(安定制御), D14(固着) |

## 3. 分解の結果得られた構造的洞察

1. **閾値と帯域の関係は位相的に明確に記述可能**。T1 で定義された帯域 En の境界 ∂En が閾値面 Σ_c を含む。帯域は開集合であり閾値はその境界——この関係は定理1（T1）で既に確立されており、T2 はその動力学的内容を記述する。

2. **閾値の「制御可能性」は5段階理論に実践的含意を与える**。触媒（D03）= 閾値低下、抱持（D3 コア定義）= 閾値上昇、という対称性が見出された。抱持を「閾値の意識的上方シフト」として形式化できる可能性がある。

3. **「渦不到達」は閾値理論の帰結として自然に導出される**。λ < λ_c のまま系が停留する条件を力学系理論で記述すれば、T7+T9（盲点）の一部が T2 の部分理論として位置づけられる。

4. **閾値の量的/質的の分岐は領域に依存する**。自然科学（D02, D06）では閾値は量的に確定するが、人文社会（D24, D14）では量的同定が困難。この非対称性は形式化の限界ではなく、異なる状態空間の位相的性質の反映として記述可能。

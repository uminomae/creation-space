# T2 閾値構造 — 形式化の限界・失敗した試み

**生成日**: 2026-03-22
**Phase**: 9D 数理形式化
**evidence フラグ**: [ai:investigation:claude-opus-4-6]

---

## 限界 1: 勾配系の仮定

ポテンシャル景観理論（Framework 2）は dx/dt = -∇V(x, λ) という勾配系を前提としている。しかし、多くの実システムは勾配系ではない:

- D28 舞台芸術のフィードバックループは散逸系であり、ポテンシャル関数が一般には存在しない
- D29 SOC は非平衡定常状態であり、自由エネルギーに基づくポテンシャルが定義できない
- D18 社会学の制度変化は、競合するアクター間の戦略的相互作用を含み、勾配系として記述できない

**対処**: 非勾配系における分岐理論（Framework 1）は依然として有効であるため、ポテンシャル景観に基づく議論は「勾配系として近似可能な系」に限定して適用すべきである。

## 限界 2: 有限次元力学系の仮定

全ての Framework が有限次元の状態空間を前提としている。しかし:

- D19 文学のテクスト解釈は無限次元の意味空間で生じる
- D13 哲学の概念的変容は有限次元に還元できない
- D24 宗教の修行プロセスは身体・心理・社会的次元が相互作用する高次元系

**対処**: 有限次元近似（POD: Proper Orthogonal Decomposition 等）で主要な自由度を抽出できる場合もあるが、次元削減が本質的な情報を失う領域では形式化の適用限界を明示する必要がある。

## 限界 3: 閾値の量的同定の困難

形式化は閾値 λ_c が原理的に同定可能であることを前提としているが:

- D24 宗教学の回心：何が「パラメータ」で何が「臨界値」かが操作的に定義できない
- D14 心理学の洞察：洞察の瞬間は事後的にのみ同定可能で、予測的同定が困難
- D15 美学の美的経験：「閾値を超えた」の判定基準が個人間で一致しない

これは「量的閾値の不在」（T2 §E 保持論点4）に直結する。形式化が提供するのは構造的理解（閾値的遷移が存在するということ）であり、数値的予測ではない。

## 限界 4: 意識的閾値操作の形式化

定理3（閾値制御の双対性）で「抱持」を δ > 0 として形式化したが、この形式化は:

- 抱持が「意識的な操作」であることを捕捉できない（δ が意識的に選択されたか自然発生かの区別がない）
- 抱持の「質」（何を保持しているか）を記述できない（δ の大きさだけで質が異なる抱持を区別できない）
- 抱持の「限界」（いつまで保持すべきか）の判断基準を提供しない

**根本的困難**: D3（抱持）は主観的経験を含むコア定義であり、力学系理論は主観性を扱えない。形式化は抱持の「外的効果」（遷移の遅延）を記述できるが、抱持の「内的質」を記述できない。

## 失敗した試み: 情報理論による閾値の定義

当初、閾値を「系の情報量が最大になる点」として定義する試みを行った:

I(λ) = -∫ p(x|λ) log p(x|λ) dx が最大 ⟺ λ = λ_c ?

しかしこの定義は:
- 二次相転移には適用可能（臨界点で相関長が発散し情報量が増大）
- 一次相転移には不適切（遷移は不連続であり、情報量の最大化が閾値と一致しない）
- 非平衡系には原理的に適用困難

情報理論的アプローチは T5（再循環）の形式化により適していることが後に判明した。

## 失敗した試み: ゲーム理論による社会的閾値

D22 経営学の閾値を N 人ゲームの Nash 均衡の消滅として定義しようとしたが:

- Nash 均衡の存在は一般には保証されているが、均衡の消滅条件は系の詳細に強く依存する
- 社会的閾値（D16 革命、D18 社会変動）では「プレイヤーの数」自体が変動し、固定人数のゲームとして定式化できない
- 進化ゲーム理論への拡張は可能だが、T2 の範囲を超える独立した研究プログラムになる

この試みは放棄し、より普遍的な分岐理論の枠組みに集中した。

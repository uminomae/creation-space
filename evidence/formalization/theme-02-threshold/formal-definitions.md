## Framework 1: 分岐理論による閾値の形式化

### 定義 1.1（パラメトリック力学系と閾値）

系 S の状態を連続力学系:

dx/dt = f(x, λ),  x ∈ R^n,  λ ∈ R^k

で記述する。ここで f は十分滑らかとする。

**閾値** λ_c ∈ R^k を、f(x, λ) の定性的振る舞いが変化する分岐パラメータ値として定義する。すなわち:

∃ x* : f(x*, λ_c) = 0 かつ det(D_x f(x*, λ_c)) = 0

（平衡点 x* においてヤコビアンが特異になるパラメータ値。）

### 定義 1.2（閾値面）

パラメータ空間 R^k 内の分岐集合:

Σ_c = {λ ∈ R^k : ∃ x* s.t. f(x*, λ) = 0 かつ det(D_x f(x*, λ)) = 0}

を **閾値面**（threshold surface）と呼ぶ。

T1 との整合: Σ_c = ∂En ∩ ∂Vx（縁帯域と渦領域の共有境界）。

### 定義 1.3（遷移の不可逆性）

閾値 λ_c における遷移が **不可逆的**（irreversible）であるとは:

λ が λ_c を超えた後、λ を元に戻しても系が元の平衡点 x* に復帰しないことを言う。形式的には:

λ_c^+ = inf{λ > λ_c : x*(λ) が安定}（順方向の閾値）
λ_c^- = sup{λ < λ_c : x*(λ) が安定}（逆方向の閾値）

**ヒステリシス幅**: H = λ_c^+ - λ_c^- > 0 のとき、遷移はヒステリシスを持ち不可逆的。H = 0 のとき可逆的。

**5段階との対応**:
- H > 0（不可逆）: D02 一次相転移、D06 重力崩壊、D05 ティッピングポイント
- H = 0（可逆）: D02 二次相転移
- H → ∞（完全不可逆）: D04 種分化（逆方向の閾値が存在しない）

### 定義 1.4（臨界減速）

閾値 λ_c の近傍における **臨界減速**（critical slowing down）を:

τ(λ) = -1 / max Re(σ(D_x f(x*(λ), λ)))

で定義する。ここで σ(A) は行列 A のスペクトル（固有値集合）。

**臨界減速の法則**: λ → λ_c のとき τ(λ) → ∞。

すなわち、閾値近傍で系の回復時間が発散する。これは「縁にいる時間が長くなる」ことの力学系的表現であり、D3 抱持との接続点を提供する——抱持とは、臨界減速の時間を意識的に活用する態度である。

### 定義 1.5（閾値の制御）

閾値の制御を、パラメータ空間の変換 T: R^k → R^k による閾値面の平行移動として定義する:

T_δ(Σ_c) = {λ + δ : λ ∈ Σ_c}

- **触媒作用**（D03）: δ < 0（閾値面を系の現在位置に近づける = 遷移を容易にする）
- **抱持作用**（D3）: δ > 0（閾値面を系の現在位置から遠ざける = 遷移を遅延させる）
- **安定制御**（D07）: δ → ∞（閾値を到達不能にする = 遷移を防止する）

## Framework 2: ポテンシャル景観理論

### 定義 2.1（ポテンシャル関数としての閾値）

勾配系 dx/dt = -∇V(x, λ) を考える。ポテンシャル V: R^n × R^k → R の極小点が系の安定状態に対応する。

閾値遷移は V の臨界点の消滅として記述される:

λ < λ_c のとき: V(·, λ) は2つの極小点 x_1, x_2 を持つ（二安定）
λ = λ_c のとき: x_1 と鞍点が衝突・消滅する（saddle-node）
λ > λ_c のとき: V(·, λ) は1つの極小点 x_2 のみ持つ

### 定義 2.2（ポテンシャル障壁と閾値到達の困難さ）

二安定領域（λ < λ_c）における **ポテンシャル障壁**:

ΔV(λ) = V(x_saddle(λ), λ) - V(x_1(λ), λ)

ΔV はノイズ駆動の遷移（ノイズが障壁を越えさせる）の困難さを定量化する。Kramers 理論により:

遷移率 ∝ exp(-ΔV / D)

ここで D はノイズ強度。

**5段階との対応**:
- ΔV が大きい: 縁の帯域が広く、遷移に時間がかかる（抱持の余地が大きい）
- ΔV が小さい: 縁の帯域が狭く、わずかな擾乱で渦に入る（制御困難）
- ΔV = 0: 閾値そのもの（λ = λ_c）

### 定義 2.3（カタストロフィー理論による閾値の分類）

Thom の初等カタストロフィーを用いた閾値の標準分類:

| カタストロフィー型 | ポテンシャル | 制御変数数 | 対応する閾値遷移 |
|----------------|-----------|---------|-------------|
| Fold | x^3 + ax | 1 | 単純な消滅（D06 重力崩壊）|
| Cusp | x^4 + ax^2 + bx | 2 | ヒステリシス（D02 一次相転移）|
| Swallowtail | x^5 + ax^3 + bx^2 + cx | 3 | 三重安定（D24 段階的遷移）|
| Butterfly | x^6 + ... | 4 | 四重安定（D12 レジームシフトの複雑な景観）|

**非自明な帰結**: 閾値遷移の質的類型は制御変数の数（コディメンション）で決まる。制御変数が少ない系ほど閾値遷移が単純であり、多い系ほど複雑な分岐パターンを示す。自然科学の閾値が「きれい」で人文社会の閾値が「複雑」なのは、制御変数の数の差として説明できる可能性がある。

## Framework 3: 確率的閾値理論

### 定義 3.1（パーコレーション閾値）

格子 G = (V, E) 上で各辺が確率 p で開いているとする。

パーコレーション閾値 p_c を:

p_c = inf{p : P_p(無限クラスターが存在する) > 0}

として定義する。

### 定義 3.2（確率的閾値帯域）

決定論的閾値 λ_c の確率的拡張。系にノイズ ξ(t) が加わるとき:

dx/dt = f(x, λ) + σξ(t)

閾値面 Σ_c は確率的帯域に拡がる:

Σ_c^σ = {λ : P(遷移 | 時間 T 内) ∈ (ε, 1-ε)}

ここで ε は小さな閾値。σ → 0 のとき Σ_c^σ → Σ_c（決定論的閾値に収束）。

**5段階との対応**: 自然科学（σ が小さい → 閾値が鮮明）、人文社会（σ が大きい → 閾値が帯域に拡がる）。T1 の「帯域性」と T2 の「閾値性」はノイズ強度の関数として統一的に記述される。

### 定義 3.3（SOC と自発的臨界性）

自己組織化臨界系（D29）を:

dx/dt = f(x) + η(t)

として記述する。ここで系は自律的に λ → λ_c の方向に駆動される（外部制御なし）。

SOC の閾値は:
- 外部からパラメータを操作する必要がない（系が自発的に閾値近傍に到達）
- 遷移（雪崩）後に系は再び閾値近傍に戻る
- 雪崩のサイズ分布が冪則に従う: P(s) ∝ s^{-τ}

**T5 との接続**: SOC は閾値遷移と再循環を同時に内蔵する。遷移後に系が閾値近傍に戻ることが、束→場循環の力学系的実装である。

## Framework 4: 渦不到達の力学系的記述

### 定義 4.1（渦不到達条件）

系が縁帯域 En 内で渦に到達しない条件を以下で定義する:

(NA1) **パラメータ停留**: dλ/dt → 0 かつ λ(∞) < λ_c（パラメータが閾値に到達しない）
(NA2) **帯域外帰還**: x(t) が En を出て F（場）に帰還する
(NA3) **安定化制御**: 外部入力 u(t) が存在し、f(x, λ) + u(t) の平衡点が En 内で安定

| 条件 | 5段階の対応 | 代表例 |
|------|-----------|-------|
| NA1 | 蓄積不足で遷移に至らない | D14(固着), D28(ブロック) |
| NA2 | 縁から場に戻る | D02(超臨界流体), D25(schism の前での和解) |
| NA3 | 意図的に渦を避ける | D07(安定制御), D22(抱持的経営) |

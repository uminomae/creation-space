## 定理 1（不完全性駆動の循環定理）

**主張**: 束 Bd_n のアトラクタ A_n の引力圏 B(A_n) が状態空間 X の真部分集合であるとき（B(A_n) ⊊ X）、残余 R_n = X \ B(A_n) が次のサイクルの摂動源として作用し、新しいサイクルが起動される。

**形式的記述**: 
R_n ≠ ∅ ⟹ ∃ x ∈ R_n, ∃ t > 0 s.t. x(t) ∉ B(A_n)（残余の状態はアトラクタに吸収されない）

残余からの摂動がアトラクタ A_n の構造を変化させるか、または新しいアトラクタの形成を引き起こすとき、次のサイクルが開始される。

**含意**: 循環の駆動力は「束の不完全性」にある。束が状態空間を完全に覆い尽くす（B(A_n) = X）場合のみ、循環が停止する。これは D13 シモンドンの前個体的余剰（個体化は前個体的現実のポテンシャルを完全には消費しない）、D13 アドルノの非同一性（概念は対象を完全には同定しない）の力学系的等価物である。

**予測**: 「完全な束」は原理的に不可能であるか、極めて稀である。R_n = ∅ となるには B(A_n) = X を要し、これは系に「取りこぼし」が一切ないことを意味する。D22 のロックインは B(A_n) ≈ X（ほぼ完全な覆い）だが厳密には R_n ≠ ∅ であり、長期的には循環が再開しうる。

## 定理 2（螺旋の不可逆性定理）

**主張**: 再循環写像 Φ が F_n 上の測度を保存しないとき、循環は不可逆的螺旋になる。すなわち:

μ(F_{n+1}) ≠ μ(F_n) ⟹ F_{n+1} ≠ F_n

ここで μ は状態空間 X 上の適切な測度。

**より強い主張**: Φ が状態空間の構造（位相、測度、接続性）のいずれかを変化させるとき、循環は螺旋的である。

**含意**: D05（不可逆螺旋としての地質循環）、D04（ニッチ構築による環境の不可逆的変化）、D13（ガダマーの効果史の堆積）が支持する「元の場には戻れない」は、Φ が構造変形写像であることの帰結。

**帰結**: 5段階の図示は「閉じた円」ではなく「開いた螺旋」が適切である（T5 §D 含意3）。

## 定理 3（循環モードの位相的分類定理）

**主張**: 再循環写像 Φ の位相的性質により、循環モードは以下の3クラスに分類される:

(C1) **収縮型**: Φ が状態空間を収縮させる（dim(F_{n+1}) < dim(F_n) or μ(F_{n+1}) < μ(F_n)）。循環は有限回で停止する可能性がある。
- 対応: 自然崩壊型（D16 文明の衰退、D21 Minsky）

(C2) **保存型**: Φ が状態空間の「大きさ」を保存する（μ(F_{n+1}) ≈ μ(F_n)）。循環は持続的。
- 対応: 制度的循環型（D11 薬学、D30 民俗芸能）、内在的循環型（D29 SOC）

(C3) **拡張型**: Φ が状態空間を拡張する（dim(F_{n+1}) > dim(F_n) or μ(F_{n+1}) > μ(F_n)）。循環はより豊かな場を生成し続ける。
- 対応: 劇的変換型（D04 内共生）、能動的更新型（D04 ニッチ構築、D30 TEK）

**含意**: 「循環の健全性」は Φ のクラスに依存する。C1 は循環の停止リスクを内蔵し、C3 は場の豊饒化をもたらし、C2 は持続的安定を提供する。D22 のコンピテンシー・トラップは C1 への退化、D30 の「反復の中の創造」は C2 と C3 の中間に位置する。

## 定理 4（場の質の単調性定理）

**主張**: 拡張型（C3）の循環写像 Φ において、場の「質」Q(F_n)（定義が与えられたとき）は n について単調非減少:

Q(F_{n+1}) >= Q(F_n)

ただし、Q の定義は系に依存し、普遍的な定義は存在しない。

**条件付き証明**: Q を場の「構造的複雑性」（例: 位相的エントロピー、相互情報量）として定義した場合、能動的更新型の Φ は各サイクルで構造を追加するため Q は非減少。

**含意**: D04（進化における遺伝子プールの多様化）、D30（TEK の世代を超えた蓄積）、D26（音楽聴取体系の洗練）は C3 の具体例であり、循環ごとに場の質が向上する。

**注意**: これは「進歩の必然性」を主張するものではない。Q の定義は価値判断を含むため、「質が向上する」は特定の Q に対してのみ成立する。D05（大量絶滅後の生態系は前よりも「豊か」とは限らない）は、Q の定義依存性の事例。

## 定理 5（循環停止の3条件定理）

**主張**: 再循環が停止する（Φ^k(Bd_n) が不定義になる or 不動点に達する）のは、以下の3条件のいずれかが成立するときに限る:

(S1) **完全安定化**: R_n = ∅（束が残余を持たない）。循環の駆動力が消失。
(S2) **場の消滅**: F_{n+1} = ∅（次の場が生成されない）。系の死。
(S3) **外部遮断**: Φ の実行が外部要因により阻害される。

| 条件 | 自然言語 | 代表例 |
|------|---------|-------|
| S1 | 束が完全に安定し、変化の余地がない | D22(ロックイン), D18(鉄の檻) |
| S2 | 系が消滅する | D04(絶滅), D17(言語の死滅) |
| S3 | 外部からの破壊 | D30(伝承の断絶), D27(border vacuum) |

**含意**: 循環の停止は系の「失敗モード」（T7+T9 で記述される盲点）に対応する。健全な循環は S1-S3 のいずれも満たされない状態——すなわち「不完全な束が、生きた場を、継続的に生成し続ける」状態である。

## 性質 1（循環の時間非対称性）

**観察**: D04 進化の「準備は長く、実現は短い」は、5段階の各段階が等しい時間を占めないことを示す。

形式的記述: 1サイクル Φ の時間 T を5段階に分解すると:

T = T_FW + T_WE + T_EV + T_VB + T_BF

ここで典型的に T_FW >> T_EV（場→波の蓄積時間 >> 縁→渦の遷移時間）。

これは T2 の臨界減速（定理2）と相補的——閾値近傍で時間が伸びるが、閾値超過の瞬間は瞬間的。

## 性質 2（循環の入れ子構造）

**観察**: 循環はマクロレベルとミクロレベルで入れ子になる。

- D08: シナプスレベルの循環（ミリ秒）→ 回路レベルの循環（秒）→ 学習レベルの循環（日-年）
- D22: 個人の意思決定循環（分-時間）→ チームの循環（週-月）→ 組織の循環（年）

形式的記述: Φ = Φ_macro ∘ (Φ_micro)^N（マクロの1サイクルがミクロの N サイクルを含む）。ミクロの束がマクロの波の段階を準備する。

T1 の入れ子構造（フラクタル的自己相似）との接続点。

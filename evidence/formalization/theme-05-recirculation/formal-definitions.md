## Framework 1: 離散力学系としての再循環

### 定義 1.1（5段階の離散力学系）

5段階の循環を離散力学系 (X, Φ) として定義する:

- X: 状態空間
- Φ: X → X: 「1サイクル写像」（場→波→縁→渦→束→新しい場 の全過程を1ステップとする）

第 n サイクルの場を F_n = Φ^n(F_0) と表記する。

### 定義 1.2（循環写像の分解）

1サイクル写像 Φ を5つの段階写像の合成として分解する:

Φ = φ_BF ∘ φ_VB ∘ φ_EV ∘ φ_WE ∘ φ_FW

ここで:
- φ_FW: F → W（場→波: 差異の顕在化）
- φ_WE: W → En（波→縁: 拮抗の形成）
- φ_EV: En → Vx（縁→渦: 閾値超過）— T2 で詳述
- φ_VB: Vx → Bd（渦→束: 凝集・安定化）
- φ_BF: Bd → F'（束→新しい場: 再循環の核心）

T5 の形式化は φ_BF に焦点を当てる。

### 定義 1.3（再循環写像 φ_BF の性質）

φ_BF: Bd → F' が以下の性質を持つ:

(R1) **非恒等性**: φ_BF ≠ id（新しい場は元の場と異なる）
(R2) **全射でないこと**: Im(φ_BF) ⊆ X だが Im(φ_BF) ≠ X（新しい場は元の状態空間の全てを覆わない）
(R3) **情報の遺伝**: Bd_n の構造が F_{n+1} に「痕跡」を残す
(R4) **非可逆性**: φ_BF^{-1} は一般には存在しない

### 定義 1.4（原初的場と循環的場）

(T0) **原初的場 F_0**: Φ の定義域の初期値。前のサイクルからの入力がない。
- 例: D06 星間分子雲、D01 公理系以前の未構造化空間、D29 孤立クラスター散在

(T1) **循環的場 F_n (n >= 1)**: Φ^n(F_0) として定義される。前のサイクルの束 Bd_{n-1} の情報を含む。
- 例: D04 種分化後の遺伝子プール、D29 SOCの臨界近傍背景、D30 TEKの蓄積された知識基盤

形式的区別: F_0 ∈ Type-0 ⟺ F_0 は Φ の像に属さない（Im(Φ) に含まれない）。

## Framework 2: アトラクタ理論による再循環

### 定義 2.1（5段階のアトラクタ）

連続力学系 dx/dt = f(x) において、5段階の「束」をアトラクタとして定義する:

**束 Bd** = 系のアトラクタ A（漸近安定な不変集合）

5段階の循環は、アトラクタの変容として記述される:

場 → 波 → 縁 → 渦 → 束(=A_n) → 場'(=A_n の構造変化を含む新しい初期条件)

### 定義 2.2（アトラクタの残余と循環駆動）

アトラクタ A_n の引力圏（basin of attraction）を B(A_n) とする。

**残余** R_n = X \ B(A_n)（アトラクタの引力圏に含まれない状態の集合）。

**循環駆動条件**: R_n ≠ ∅ のとき、残余 R_n が次のサイクルの「摂動」として作用し、新しいサイクルを起動する。

これは D13 シモンドンの「前個体的余剰」の力学系的表現である:
- 個体化（= 束の形成 = A_n の出現）は前個体的現実のポテンシャルを完全には消費しない
- 残余 R_n が次の個体化（= 次のサイクル）を可能にする

### 定義 2.3（螺旋軌道と閉軌道の区別）

離散力学系 (X, Φ) の軌道 {F_0, F_1, F_2, ...} について:

- **閉軌道（円環）**: ∃ p > 0 s.t. F_{n+p} = F_n（周期 p で元の場に戻る）
- **螺旋軌道**: ∀ n, m (n ≠ m) ⟹ F_n ≠ F_m（同じ場に二度と戻らない）

**5段階との対応**: 12+領域が支持する「循環は不可逆的螺旋」（T5 収束2）は、軌道が閉じないことの経験的確認である。

螺旋性の測度: 連続するサイクル間の距離 d(F_n, F_{n+1}) が 0 に収束しないとき、螺旋は「開いている」。

### 定義 2.4（ストレンジアトラクタとしての再循環）

循環が決定論的でありながら非周期的である場合、再循環はストレンジアトラクタ上の運動として記述できる:

- 軌道は有界（系は発散しない）
- 軌道は非周期的（同じ場に戻らない）
- 初期条件に敏感（わずかな違いが異なる循環パスを生む）

これは D29 SOC のアバランシェダイナミクスに対応する。

## Framework 3: 圏論による循環の構造

### 定義 3.1（循環圏 Cycle）

T1 で定義した圏 Penta を拡張し、循環の構造を明示的にする。

圏 Cycle を以下で定義する:
- Ob(Cycle) = {(段階, n) : 段階 ∈ {場, 波, 縁, 渦, 束}, n ∈ N}
  - 各段階がサイクル番号 n でラベルされる
- Hom((束, n), (場, n+1)) = {循環射 φ_BF^{(n)}}
  - 第 n サイクルの束から第 n+1 サイクルの場への射
- 他の射は Penta の構造を各サイクル内で保持

### 定義 3.2（螺旋の圏論的定義）

圏 Cycle において、循環が螺旋的であるとは:

循環射 φ_BF^{(n)}: (束, n) → (場, n+1) が、全ての n について同型射でないことを言う。

すなわち、各サイクルの「束→場」遷移が構造を保存しない（新しい場は古い束の単なるコピーではない）。

### 定義 3.3（循環モードの関手的記述）

5つの循環モード（decomposition §2）を関手として記述する:

| モード | 関手の型 | 特徴 |
|-------|---------|------|
| 自然崩壊型 | 忘却関手 U: Bd → F' | 束の構造を「忘れて」場に戻す |
| 能動的更新型 | テンソル積関手 Bd ⊗ Env → F' | 束と環境の相互作用から場を生成 |
| 劇的変換型 | 余極限 colim: {Bd_i} → F' | 複数の束の統合から新しい場を生成 |
| 制度的循環型 | 定数関手 Δ: Bd → F_fixed | 制度が循環の形を固定する |
| 内在的循環型 | 自己関手 Φ: C → C | 圏自体の自己変換として循環が内蔵される |

## Framework 4: 繰り込み群的アプローチ

### 定義 4.1（スケール変換としての再循環）

再循環を繰り込み群（Renormalization Group）のアナロジーで記述する。

繰り込み変換 R: X_l → X_{l'} は、スケール l の系をスケール l' (> l) の系に変換する。

5段階の再循環を:
Φ: (X, 解像度_n) → (X, 解像度_{n+1})

として記述する。各サイクルで系の「解像度」（構造の粒度）が変化する。

### 定義 4.2（不動点と普遍性クラス）

繰り込み変換 R の不動点 X* = R(X*) は、スケール不変な構造を表す。

5段階文脈での解釈:
- **不動点** = スケールを変えても同じ構造が現れる「普遍的パターン」
- **普遍性クラス** = 異なる微視的メカニズムを持つ系が、マクロなスケールで同じ振る舞いを示す

これは T1 の「実装独立性」と T5 の「循環の普遍性」を統一する——30領域で同じ循環構造が現れるのは、それらが同じ「普遍性クラス」に属するからである。

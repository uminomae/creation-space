## 1. 対象の同定

T5 が記述する「再循環（recirculation）」は、束→場の還流メカニズムである。19ドメインが直接主題化し、「束は終点ではなく次のサイクルの場の種」という命題は15+領域で収束している。

### 1.1 対象（Objects）

| 記号候補 | 自然言語 | 出現領域 |
|---------|---------|---------|
| X | 状態空間 | 全領域 |
| Bd_n | 第 n サイクルの束 | 全領域 |
| F_n | 第 n サイクルの場 | 全領域 |
| F_0 | 原初的場（循環以前の未分節状態）| D01, D06, D29 |
| Φ | 循環写像（束→新しい場への変換）| 全領域 |
| R_n | 残余（束が取りこぼすもの）| D13(シモンドンの前個体的余剰), D04(Red Queen) |
| Ω | 螺旋の「進行方向」（各サイクルで変質する座標）| D05, D13, D24 |

### 1.2 性質（Properties）

| 性質 | 自然言語 | 形式化候補 |
|------|---------|-----------|
| 不可逆性 | 循環は元の場への回帰ではなく変質した場の生成 | Φ(Bd_n) = F_{n+1} ≠ F_n（写像が恒等でない）|
| 螺旋性 | 循環は円環でなく螺旋 | 軌道が閉じない: {F_n} の極限が存在しない、or 固定点でない |
| 駆動力としての不完全性 | 束が完全な安定を達成しないことが循環を駆動 | R_n = X \ Bd_n ≠ ∅（束が状態空間を覆い尽くさない）|
| モードの多様性 | 循環には質的に異なるモードがある | Φ の型による分類（5モード）|
| 停止可能性 | 循環は必ずしも永続しない | Φ^k(Bd_n) → ∅（有限ステップで循環が停止する場合）|

### 1.3 関係（Relations）

| 関係 | 自然言語 | 形式化候補 |
|------|---------|-----------|
| 束 → 新しい場 | 束が次の場を準備する | F_{n+1} = Φ(Bd_n)。Φ は単射でも全射でもない |
| 残余 → 駆動力 | 束の不完全性が次のサイクルを起動する | R_n ≠ ∅ → ∃ 波_{n+1} |
| 原初的場 vs 循環的場 | 初回の場と2回目以降は性質が異なる | F_0 ∈ Type-0、F_n (n>=1) ∈ Type-1 |
| 場の質の蓄積 | 各サイクルが場の質を変化させる | dim(F_n) の変化、または F_n 上の測度の変化 |
| 循環の停止 | 伝承の断絶、絶滅 | Φ^k が不動点に達する、or 定義域が空になる |

### 1.4 量化（Quantification）

| 量的記述 | 自然言語 | 形式化候補 |
|---------|---------|-----------|
| 循環の周期 | サイクル1回の時間 | T_n（不定——サイクルごとに異なりうる）|
| 場の変質度 | 前の場からの距離 | d(F_n, F_{n+1})（適切な距離関数が必要）|
| 残余の大きさ | 束が取りこぼす量 | μ(R_n) / μ(X)（残余の測度比）|
| 循環の持続回数 | 何サイクル続くか | sup{n : Φ^n(Bd_0) ≠ ∅} |
| 束の開放度 | 循環への開放度（T5 §D 提案1）| 操作的定義未確立 |

## 2. 循環モードの分解

T5 の横断分析から同定された5つの循環モード:

| モード | 特徴 | Φ の数学的性質 | 代表的領域 |
|-------|------|-------------|-----------|
| 自然崩壊型 | 束が内部から崩壊して場に戻る | Φ は収縮写像的（束を「溶かす」）| D16(成功→自壊), D21(Minsky) |
| 能動的更新型 | 束が環境との相互作用で場を再構成 | Φ は環境依存的（外部入力を含む）| D04(ニッチ構築), D30(TEK) |
| 劇的変換型 | 一つの束が以降の全ての場を決定的に変える | Φ の像が全空間に及ぶ | D04(内共生), D06(超新星) |
| 制度的循環型 | 循環が制度として設計・維持される | Φ が外部から規定される（設計された循環）| D11(薬学), D30(民俗芸能) |
| 内在的循環型 | 循環が理論そのものに内蔵される | Φ が力学系のアトラクタに対応 | D29(SOC), D03(触媒サイクル) |

## 3. 分解の結果得られた構造的洞察

1. **再循環は力学系のアトラクタ構造として自然に定式化できる**。束→場の移行は、一つのアトラクタの消滅と新しいアトラクタの出現（or 同じアトラクタの変形）として記述可能。螺旋性は「同じアトラクタに戻らない」ことに対応する。

2. **「駆動力としての不完全性」は集合論的に明確**。束が状態空間の真部分集合（Bd ⊊ X）であるとき、残余 R = X \ Bd が存在する。この残余が次のサイクルの「種」になるという構造は、D13 シモンドンの前個体的余剰、D13 アドルノの非同一性と厳密に対応する。

3. **原初的場と循環的場の区別は初期条件問題として定式化可能**。F_0（初期条件なしの場）と F_n（前の束が初期条件を提供する場）の区別は、力学系の初期値問題における「第一の初期条件」と「以降の初期条件」の区別に帰着する。

4. **循環の停止は「束の完全化」または「場の消滅」として記述可能**。R_n = ∅（束が完全な安定を達成）か F_{n+1} = ∅（次の場が生まれない）のいずれか。前者は D22 のロックイン、後者は D04 の絶滅に対応する。

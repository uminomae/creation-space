# T5 再循環メカニズム — 形式化の限界・失敗した試み

**生成日**: 2026-03-22
**Phase**: 9D 数理形式化
**evidence フラグ**: [ai:investigation:claude-opus-4-6]

---

## 限界 1: 循環写像 Φ の具体的構成

全ての Framework で Φ（再循環写像）の存在を仮定しているが、Φ の具体的な関数形は領域ごとに異なり、統一的な構成法が存在しない。

- D29 SOC: Φ は具体的に記述可能（sandpile automaton の1サイクル写像）
- D04 進化: Φ は原理的には集団遺伝学のモデルで近似可能だが、全変数を含む完全な記述は不可能
- D13 哲学: Φ は概念空間上の変換であり、数学的に厳密な記述は困難
- D24 宗教: Φ の入力・出力空間すら明確に定義できない

**対処**: 形式化は Φ の「構造的性質」（非恒等性、非可逆性等）を記述するものであり、Φ の関数形を具体的に与えるものではない。これは限界であるが、構造的洞察の価値を減じない。

## 限界 2: 「場の質」Q の定義

定理4（場の質の単調性）が Q(F_n) の単調性を主張するが、Q の普遍的定義が存在しない。

試みた定義と問題点:
- **位相的エントロピー**: 系の複雑性を測る → 複雑性の増大が「質の向上」とは限らない（D05 の大量絶滅後の生態系は複雑性が低下するが、新しい適応放散の「場」としては豊か）
- **相互情報量**: 系の部分間の相関を測る → 全ての循環で情報量が増大するわけではない
- **多様性指数**: 状態の多様さを測る → D22 のロックインでは多様性が減少しつつ「安定」が増大する

Q の定義は系と文脈に依存せざるを得ない。普遍的な「場の質」は、少なくとも現在の形式化では定義できない。

## 限界 3: 循環の「回数」の不確定性

離散力学系として形式化すると「n 回目のサイクル」が明確だが、実際には:

- 1サイクルの始まりと終わりの境界が曖昧（D30 口承伝統の「自動化→異化→再自動化」はどこが1サイクルか）
- 複数の循環が並行して進行する（D22 の個人・チーム・組織の3レベル循環）
- サイクルの「速度」が変動する（D04 の断続平衡では停滞期と急変期で速度が極端に異なる）

離散化は数学的には便利だが、連続的プロセスへの適用には注意が必要。

## 限界 4: アトラクタ理論の前提

Framework 2 がアトラクタの存在を前提としているが:

- 散逸系以外ではアトラクタの概念が適用困難（保存系、開放系）
- 非自律系（時間変動する外部入力を受ける系）ではアトラクタの定義自体が問題になる
- D19 文学のテクスト解釈のように「正解」（= アトラクタ）が存在しない系への適用は不適切

## 失敗した試み: エルゴード理論による再循環の形式化

当初、再循環をエルゴード理論の枠組みで記述しようとした:

- 状態空間 X 上の測度保存変換 T: X → X として Φ を記述
- Birkhoff のエルゴード定理により、時間平均 = 空間平均が成立する条件を導出
- 循環の「定常性」をエルゴード性として定式化

しかし:
- T5 収束2（不可逆的螺旋）が Φ の測度保存性と矛盾する
- エルゴード理論は「同じ変換 T の反復」を前提とするが、5段階では各サイクルで Φ 自体が変化する
- 測度保存変換の理論は可逆系に強く、不可逆系への拡張が非自明

エルゴード理論は「同じ循環の長期的振る舞い」には有効だが、「各サイクルで変化する螺旋」の記述には不適切であった。アトラクタ理論（Framework 2）に切り替えた。

## 失敗した試み: 圏論の高次圏化

循環の入れ子構造（性質2）を高次圏（2-圏、∞-圏）で記述しようとしたが:

- 高次射（循環の循環）の具体的意味が不明確
- 2-圏の構成は可能だが、得られる洞察が自然言語の記述を超えない
- 技術的複雑さに対して、新しい予測や理解をほとんど生まない

高次圏的記述は「可能だが有益でない」と判断し、離散力学系 + 1-圏の範囲に留めた。

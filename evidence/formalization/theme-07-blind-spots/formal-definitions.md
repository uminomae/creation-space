## Framework 1: モデルの射程の集合論的記述

### 定義 1.1（5段階モデルの適用領域）

全ての可能な過程の集合を U（universe of processes）とする。5段階モデル Penta の **適用領域** を:

Dom(Penta) = {p ∈ U : p は場→波→縁→渦→束の構造を持つ}

として定義する。

**盲点** Blind(Penta) = U \ Dom(Penta)（5段階で記述できない過程の全体）。

### 定義 1.2（失敗モードの形式化）

5段階の各遷移射 f に対し、**失敗モード** を射の部分的不定義として記述する:

Fail(f) = {x ∈ dom(f) : f(x) が「期待される帰結」に到達しない}

具体的な失敗モード:

| 段階遷移 | 失敗モード | 形式的記述 | 代表例 |
|---------|----------|----------|-------|
| 場→波 (f_FW) | 場の凍結 | f_FW(x) = x（恒等、変化なし）| D08(凍結反応), D22(VoF) |
| 波→縁 (f_WE) | 波の消散 | f_WE(x) ∈ F（波が場に戻る）| D12(撹乱の欠如) |
| 縁→渦 (f_EV) | 渦不到達 | f_EV(x) ∈ En ∪ F（渦に至らない）| D14(固着), D25(schism), D07(安定制御) |
| 渦→束 (f_VB) | 渦の暴走 | f_VB(x) が定義不能（渦が収束しない）| D08(てんかん), D05(破壊的渦) |
| 束→場 (f_BF) | 束の固着 | f_BF(x) = x（循環停止）| D22(ロックイン), D18(鉄の檻) |

### 定義 1.3（盲点の3類型）

Blind(Penta) を以下の3類型に分割する:

(B1) **秩序解体**: p が秩序の減少過程 → Penta は秩序増大を前提としているため p ∉ Dom(Penta)
(B2) **非段階的過程**: p が連続的であり離散的段階化を拒否 → Penta の離散性の前提により p ∉ Dom(Penta)
(B3) **スケール間接続**: p が複数スケールを同時に跨ぐ → Penta は単一スケールを前提としているため p ∉ Dom(Penta)

## Framework 2: 解体過程の独立的形式化

### 定義 2.1（解体写像）

秩序解体を、5段階の逆ではない独立の写像として定義する:

Δ: Bd → X_unstructured（束から非構造化状態への写像）

**重要**: Δ ≠ Φ^{-1}（解体は再循環の逆ではない）。

解体の性質:
(D1) **非可逆性**: Δ^{-1} は一般に存在しない（解体されたものは元に戻らない）
(D2) **非順序性**: Δ は束→渦→縁→波→場の逆順を辿らない
(D3) **固有の経路**: Δ は独自の段階を持つ可能性がある

### 定義 2.2（解体の経路空間）

解体過程 Δ が辿りうる経路の集合 Path(Δ) を定義する。

T7+T9 §A の分析から、解体の経路は5段階の逆順ではなく、例えば:
- 束 → 束の部分的崩壊 → 部分的束の共存 → 競合 → 全面的崩壊 → 未構造化状態（D16 文明崩壊）
- 束 → 束の過剰固定 → 環境との乖離 → 急激な崩壊（D22 ロックイン→Minsky モーメント）

Path(Δ) ∩ Path(Φ^{-1}) = ∅（解体の経路と循環の逆経路は共有しない）が T7+T9 収束2 の形式的表現。

### 定義 2.3（計画的解体と非計画的解体）

解体を2つのクラスに分類する:

(PD) **計画的解体**: Δ_planned: Bd → F'（解体が新しい場を生む）。
- D09 アポトーシス（計画的細胞死が発生に不可欠）
- D30 里山の撹乱管理（意図的な解体が安定を維持）
- D27 建築の解体→再建

(UD) **非計画的解体**: Δ_unplanned: Bd → X_unstructured（解体が新しい場を生まない）。
- D04 大量絶滅（場に戻れない解体）
- D05 気候暴走（不可逆的崩壊）
- D17 言語の死滅

**含意**: PD は T5 の再循環の特殊ケース（Δ_planned ≈ φ_BF の破壊的バージョン）として5段階内で記述可能。UD は5段階の射程外。

## Framework 3: 失敗モードの圏論的記述

### 定義 3.1（拡張された5段階圏 Penta+）

T1 で定義した圏 Penta を拡張し、失敗モードを射として追加する:

圏 Penta+ の追加射:
- f_freeze: 場 → 場（凍結: 場が波に遷移せずに場に留まる）
- f_dissipate: 波 → 場（消散: 波が場に戻る）
- f_stuck: 縁 → 縁（固着: 縁が渦にも場にも遷移しない）
- f_runaway: 渦 → ∅（暴走: 渦が収束せず系が破壊される）
- f_lock: 束 → 束（ロックイン: 束が場に遷移せず固定される）

### 定義 3.2（正常経路と失敗経路）

Penta+ において:

**正常経路**: 場 →^{f_FW} 波 →^{f_WE} 縁 →^{f_EV} 渦 →^{f_VB} 束 →^{f_BF} 場'（5段階の完遂）
**失敗経路**: 正常経路上のいずれかの射が失敗射に置き換わった合成射

失敗経路の分類:

| 失敗経路 | 到達先 | 意味 |
|---------|------|------|
| 場 →^{f_freeze} 場 | 場（不変）| 何も始まらない |
| 場 → 波 →^{f_dissipate} 場 | 場 | 差異が認知されない |
| 場 → 波 → 縁 →^{f_stuck} 縁 | 縁 | 永続的保留（過剰な抱持）|
| 場 → 波 → 縁 → 渦 →^{f_runaway} ∅ | 系の消滅 | 暴走的崩壊 |
| 場 → ... → 束 →^{f_lock} 束 | 束（不変）| ロックイン |

## Framework 4: モデル選択理論による段階数の評価

### 定義 4.1（段階モデルの族）

5段階モデルを、段階数 k をパラメータとするモデルの族 {Model_k}_{k=1,2,...} の一元として位置づける:

- Model_1: 単一の連続的過程（段階なし）
- Model_3: 場→縁→束（簡略化した3段階）
- Model_5: 場→波→縁→渦→束（現行の5段階）
- Model_7: テレサの霊的結婚の7段階
- Model_10: 十牛図の10段階

### 定義 4.2（モデル選択基準）

各 Model_k の適合度を情報量基準で評価する:

AIC(k) = -2 log L(k) + 2k

ここで L(k) は Model_k の30領域データへの適合度（尤度）。

**含意**: 段階数 k の「最適値」は、適合度と複雑さのトレードオフで決まる。k が大きいほど適合度は上がるが過剰適合のリスクが増す。D24 の段階数多様性は、異なる領域が異なる最適 k を持つことの反映かもしれない。

### 定義 4.3（段階化の情報損失）

連続的過程 p を k 段階に離散化するときの情報損失:

Δ I(k) = H(p) - H(partition_k(p))

ここで H はシャノンエントロピー、partition_k は k 段階への分割。

k → ∞ のとき Δ I → 0（無限の段階 = 連続的記述で情報損失なし）。
k = 5 での情報損失 Δ I(5) が許容範囲内であれば、5段階は実用的に十分。

## 整合性注記

T1 との対応:
- T1 圏 Penta が T7+T9 の Penta+ に拡張される（失敗射の追加）
- T1 の方向選択性（定義 1.2 の B2）の「選択肢」に「失敗方向」が追加される

T2 との対応:
- T2 定義 4.1 の渦不到達条件が、T7+T9 の f_stuck（固着射）と f_dissipate（消散射）に対応
- T2 の閾値制御（定理3）の「閾値を到達不能にする」操作は、T7+T9 の f_freeze の意図的導入に対応

T5 との対応:
- T5 定理5 の循環停止条件 S1-S3 が、T7+T9 の f_lock（ロックイン）と f_runaway（暴走）に対応
- T5 の計画的解体（PD）は T5 の再循環の特殊ケースとして統合可能

T6 との対応:
- T6 性質2 の「場の安全性条件」の違反が、T7+T9 の f_freeze（凍結）に対応
- T6 の活性度関数 α が α_safe 以下に低下 → 場の凍結 = f_freeze の発動

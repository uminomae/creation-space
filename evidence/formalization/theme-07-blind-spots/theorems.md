## 定理 1（解体の非双対性定理）

**主張**: 秩序解体の過程 Δ は、5段階圏 Penta の双対圏 Penta^{op} と同型でない。

Δ ≇ Penta^{op}

**証明の概略**: Penta^{op} では全射の方向が逆転し、束→渦→縁→波→場 となる。しかし T7+T9 の分析から:
1. D16 文明崩壊は束→渦→縁→波→場の逆順を辿らない（崩壊は独自の経路を持つ）
2. D29 エントロピー増大は秩序生成のどの段階の「逆」にも対応しない
3. D03 化学的分解は合成反応の逆反応として記述できる場合もあるが（可逆反応）、多くの分解は不可逆であり逆経路が存在しない

したがって、Path(Δ) ∩ Path(Penta^{op}) が空または微小であり、Δ は Penta^{op} と同型でない。

**含意**: 「5段階を逆に辿れば解体が記述できる」という素朴な直観は誤りである。解体を記述するには独自の理論が必要。これは5段階の射程を明確に限定する重要な定理——5段階は「秩序の生成」のモデルであり、「秩序の解体」のモデルではない。

## 定理 2（失敗モードの各段階存在定理）

**主張**: 5段階の各遷移射 f_i に対し、少なくとも1つの失敗モード Fail(f_i) が存在する。すなわち:

∀ i ∈ {FW, WE, EV, VB, BF}: Fail(f_i) ≠ ∅

**証明**: T7+T9 §D の体系的調査により、各段階の失敗モードが少なくとも2領域で独立に確認されている:

| 遷移 | 失敗モード | 確認領域数 |
|------|----------|----------|
| f_FW | 凍結（場から動けない）| 3+ (D08, D22, D28) |
| f_WE | 消散（波が場に戻る）| 2+ (D12, D05) |
| f_EV | 固着・渦不到達 | 7+ (D01, D07, D14, D25, D28 等) |
| f_VB | 暴走（渦が収束しない）| 4+ (D05, D08, D21, D29) |
| f_BF | ロックイン（束が循環しない）| 5+ (D09, D11, D17, D18, D22) |

**含意**: 5段階は「成功パス」のみを記述するモデルではなく、各段階に内在する失敗の可能性を含む。失敗モードを理論に明示的に組み込むこと（Penta → Penta+ への拡張）は、理論の記述力を大幅に向上させる。

**T2 との接続**: 渦不到達（f_EV の失敗）は T2 定義 4.1 の3条件と一致。最も多くの領域で報告される失敗モードは「縁→渦」の遷移失敗であり、これは閾値理論の中心的対象。

## 定理 3（段階化の情報損失定理）

**主張**: 連続的過程 p を k 段階に離散化するとき、情報損失 ΔI(k) は k に関して単調減少し、k → ∞ で 0 に収束する。

ΔI(k) = H(p) - H(partition_k(p)) >= 0
ΔI(k+1) <= ΔI(k)
lim_{k→∞} ΔI(k) = 0

**含意**: 段階数を増やせば情報損失は減るが、モデルの複雑さが増す。「5」は情報損失と複雑さのトレードオフにおける特定の選択であり、理論的必然ではない。

**D24 宗教学の段階数多様性との対応**: テレサの7段階（k=7）は5段階より情報損失が少ないが複雑。十牛図の10段階（k=10）はさらに精密だがさらに複雑。各伝統は異なるトレードオフを選んでいる。

**実用的判断**: 5段階は30領域にわたって適用可能であることが Phase 7-8 で確認されており、実用上十分な粒度を提供する。段階数の最適化は今後の課題だが、5段階を否定する根拠は得られていない。

## 定理 4（計画的解体の5段階帰属定理）

**主張**: 計画的解体 Δ_planned は、T5 の再循環写像 φ_BF の特殊ケースとして5段階モデル内で記述可能。

Δ_planned: Bd → F' ≅ φ_BF の「破壊を含む」バージョン

**証明の概略**: 計画的解体は「束を意図的に解体して新しい場を作る」過程であり:
- D09 アポトーシス: 細胞の計画的死 → 発生の場を構成
- D30 里山の撹乱管理: 意図的な撹乱 → 生態系の場を維持
- D27 建築の解体→再建: 構造物の解体 → 新しい建築の場を作る

いずれも束→場の遷移（φ_BF）であり、その経路が「破壊」を含む点で通常の循環と異なるが、入力（束）と出力（新しい場）の構造は保存される。

**含意**: 盲点カテゴリの中で、計画的解体は5段階の射程内に回収可能。射程外に残るのは非計画的解体（Δ_unplanned）のみ。

## 定理 5（価値中立性と方向性ラベルの両立定理）

**主張**: 5段階モデルの価値中立性を保ちつつ、各射に「方向性ラベル」を付与することは矛盾しない。

方向性ラベル d: Hom(Penta+) → {constructive, destructive, neutral} を、系の存続/消滅への寄与度として操作的に定義する:

d(f) = constructive ⟺ f の適用後に系の存続可能性が増加
d(f) = destructive ⟺ f の適用後に系の存続可能性が減少
d(f) = neutral ⟺ 上記の判定が不能

**含意**: 癌（D09）は destructive な束、制度（D18）は constructive な束として区別可能。ただし、方向性は「系の存続」に相対的であり、「絶対的な善悪」ではない——これが価値中立性の保持。D09 の癌も「癌細胞の系」にとっては constructive であり、方向性は参照系に依存する。

## 性質 1（盲点の不可避性）

**観察**: 任意の有限段階モデル Model_k は盲点を持つ。すなわち:

∀ k < ∞: Blind(Model_k) ≠ ∅

これはゲーデルの不完全性定理のアナロジーではないが、有限の離散モデルで連続的現実を完全に記述できないという原理的限界を反映している。

**含意**: 盲点の存在は5段階モデルの「欠陥」ではなく、有限モデルの「本質的特性」。盲点を認識し明示することが理論の成熟を示す。

## 性質 2（失敗モードの段階依存的非対称性）

**観察**: 失敗モードの報告数は段階によって非対称に分布する:

- f_EV（縁→渦）の失敗: 最多（7+領域）
- f_BF（束→場）の失敗: 次多（5+領域）
- f_VB（渦→束）の失敗: 中程度（4+領域）
- f_FW（場→波）の失敗: 少（3+領域）
- f_WE（波→縁）の失敗: 最少（2+領域）

**含意**: 5段階の「ボトルネック」は縁→渦遷移であり、これは T2（閾値構造）が最も重要なテーマである理由の統計的確認。「閾値を超えること」が創造過程の最も困難な段階。

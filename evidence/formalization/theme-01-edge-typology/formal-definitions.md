## Framework 1: グラフ理論による縁の類型学

### 定義 1.1（創造過程グラフ）

創造過程を有向重み付きグラフ G = (V, E, w, l) として定義する。

- V: 頂点集合。各頂点は「状態」を表す。
- E ⊆ V × V: 有向辺集合。状態間の遷移を表す。
- w: E -> R_{>0}: 辺の重み関数。遷移の「困難さ」（活性化エネルギー的なもの）を表す。
- l: V -> {場, 波, 縁, 渦, 束}: 頂点ラベル関数。各状態の段階帰属。

### 定義 1.2（縁の帯域としての形式化）

グラフ G において、縁帯域 B ⊆ V を次の条件を満たす頂点の部分集合とする:

(B1) **帯域性**: |B| >= 2（縁は単一の点ではなく幅を持つ）
(B2) **方向選択性**: B から出る辺の終点集合 N^+(B) = {v ∈ V : ∃ u ∈ B, (u,v) ∈ E, l(v) = 渦} が少なくとも2つの異なる「渦の型」を含む
(B3) **拮抗条件**: B 内の任意の頂点 v に対し、少なくとも2つの異なる方向への辺が存在する
(B4) **帰還可能性**: B から l^{-1}(場) への辺が存在する（渦に至らず場に戻る経路がある）

### 定義 1.3（縁の分類——6座標系）

縁帯域 B に対し、以下の6つの属性を割り当てる座標系 C(B) を定義する:

C(B) = (τ, μ, σ, ρ, β, α) ∈ T × M × Σ × P × Β × A

ここで:
- τ ∈ T: 時間的性質（when）— {瞬間的, 漸進的, 周期的}
- μ ∈ M: 遷移メカニズム（how）— {閾値型, 競合型, 確率型}
- σ ∈ Σ: 空間的性質（where）— {界面型, 内部型, 境界型}
- ρ ∈ P: 媒介の型（through what）— {伝播型, 変換型, 触媒型}
- β ∈ Β: 構造基盤（on what）— {格子型, 連続型, ネットワーク型}
- α ∈ A: 主体性（who/what）— [0, 1] の連続値（0 = 完全に無意識、1 = 完全に意識的）

### 定義 1.4（縁の同型）

二つの縁帯域 B_1 (系 S_1 内) と B_2 (系 S_2 内) が同型であるとは、次を満たす全単射 φ: B_1 -> B_2 が存在することを言う:

(I1) φ は B_1 の隣接構造を保存する: (u, v) ∈ E_1 ⟺ (φ(u), φ(v)) ∈ E_2
(I2) φ は方向選択性を保存する: φ(N^+(B_1)) = N^+(B_2) として、方向の対応が保たれる

座標系レベルでの弱い同型（座標同値）:
B_1 ~_C B_2 ⟺ C(B_1) = C(B_2)

## Framework 2: 位相空間論による縁の帯域構造

### 定義 2.1（状態空間と縁帯域）

系 S の状態空間を位相空間 (X, τ_X) とする。
5段階構造を X の分割として記述する:

X = F ⊔ W ⊔ En ⊔ Vx ⊔ Bd

ここで F（場）, W（波）, En（縁）, Vx（渦）, Bd（束）は X の部分集合。

### 定義 2.2（縁の位相的特徴づけ）

縁 En ⊆ X が以下の性質を持つとき、T1 で同定された構造的特徴を満たす:

(T1) **帯域性**: En は X の開集合（少なくとも位相的内部が空でない: int(En) ≠ ∅）
(T2) **境界としての閾値**: ∂En ∩ ∂Vx ≠ ∅（縁と渦の境界が空でない）
(T3) **拮抗生成**: En 上に連続ベクトル場 F_1, F_2 が定義され、零点集合 Z = {x ∈ X : F_1(x) + F_2(x) = 0} が En ∩ Z ≠ ∅ を満たす
(T4) **方向選択性**: ∂En ∩ ∂Vx 上に少なくとも2つの連結成分が存在する（複数の「出口」がある）

### 定義 2.3（帯域の測度論的特徴づけ）

(X, Σ, μ) を測度空間とする。縁帯域は:

μ(En) > 0（正の測度を持つ——これが「線ではなく帯域」の測度論的表現）

帯域幅を W(En) = μ(En) / μ(∂En ∩ ∂Vx) と定義する（帯域の面積対閾値面の面積比）。

## Framework 3: 圏論による実装独立性の記述

### 定義 3.1（5段階圏 Penta）

圏 Penta を次のように定義する:

- Ob(Penta) = {場, 波, 縁, 渦, 束}
- Hom(場, 波) = {遷移射 f_FW}（場から波への遷移の集合）
- Hom(波, 縁) = {遷移射 f_WE}
- Hom(縁, 渦) = {遷移射 f_EV} ∪ {帰還射 f_EF}（渦への遷移 + 場への帰還）
- Hom(渦, 束) = {凝集射 f_VB}
- Hom(束, 場) = {循環射 f_BF}（束から新たな場への還流）
- 恒等射と合成射は通常の規則に従う

### 定義 3.2（領域関手）

各領域 D_i (i = 1, ..., 30) に対し、関手 F_i: Penta -> Set を定義する:

- F_i(場) = 領域 D_i における「場」の具体的実現の集合
- F_i(波) = 領域 D_i における「波」の具体的実現の集合
- ...（同様に各段階について）
- F_i(f_EV) = 領域 D_i における縁->渦遷移の具体的メカニズムの集合

### 定義 3.3（実装独立性の圏論的定義）

二つの領域 D_i, D_j が「縁において実装独立的」であるとは:

F_i|_{En} と F_j|_{En} の間に自然変換 η: F_i|_{En} => F_j|_{En} が存在し、
この自然変換が「構造的特徴を保存する」（方向選択性、帯域性等）ことを言う。

より厳密に: 自然変換 η が以下の図式を可換にする:

```
F_i(縁) --η_縁--> F_j(縁)
   |                  |
F_i(f_EV)         F_j(f_EV)
   |                  |
   v                  v
F_i(渦) --η_渦--> F_j(渦)
```

**これが T1 収束4「縁は実装独立的」の圏論的表現である。**

### 定義 3.4（縁の普遍的性質）

全ての領域関手 F_i が共通して保存する縁の性質を「普遍的性質」と呼ぶ。
これは関手の極限（limit）として記述可能:

U_En = lim_{i ∈ I} F_i(縁)

U_En は全領域に共通する縁の「本質」——30領域の縁概念の積（product）として構成される抽象的な「縁そのもの」。

## Framework 4: 分岐理論による縁->渦遷移の記述

### 定義 4.1（パラメトリック力学系としての5段階）

系の動力学を:

dx/dt = f(x, λ)

x ∈ R^n: 状態変数
λ ∈ R^k: パラメータ（外部条件）

5段階は λ の変化に伴う系の質的変化として記述される:

- 場: f の安定平衡点 x* の近傍
- 波: 平衡点からの微小変位（線形化で記述可能な領域）
- 縁: 分岐点の近傍（λ が分岐値 λ_c に近い）
- 渦: 分岐後の新しいアトラクターの形成過程
- 束: 新しいアトラクターへの収束

### 定義 4.2（縁の分岐論的定義）

λ_c を分岐パラメータ値とする。縁帯域を:

B = {(x, λ) : |λ - λ_c| < ε, x ∈ 中心多様体 W^c}

ここで W^c は分岐点における中心多様体（center manifold）。

この定義は以下を包含する:
- T1 収束1（帯域性）: ε > 0 より B は幅を持つ
- T1 収束2（方向選択性）: 分岐の型により方向が決まる
- T1 収束3（拮抗依存性）: 分岐点は相反する安定性の拮抗点
- T2 収束1（閾値性）: λ_c が閾値

### 定義 4.3（縁の分岐型分類）

分岐理論の標準分類を用いた縁の型分類:

| 分岐型 | 数学的特徴 | 対応する縁の自然言語記述 | 領域例 |
|--------|-----------|---------------------|--------|
| Saddle-node | 2つの平衡点が衝突・消滅 | 閾値型（越えると戻れない）| D02(相転移), D06(重力崩壊) |
| Pitchfork | 1つの平衡点が3つに分岐 | 対称性破れ型 | D02(SSB), D09(分化) |
| Hopf | 平衡点がリミットサイクルに | 振動発生型 | D26(グルーヴ), D28(フィードバックループ) |
| Transcritical | 2つの平衡点が安定性を交換 | 交替型 | D04(種分化), D19(逸脱-規範) |
| Period-doubling | 周期倍化のカスケード | カオスへの道 | D29(SOC近傍), D05(気候変動) |

## 整合性注記

Framework 1-4 は相互に矛盾しない。具体的な対応:

- Graph G の頂点 V は位相空間 X の離散化に対応する
- 圏 Penta の射は力学系の軌道に対応する
- 分岐型の分類は、グラフにおける出次数のパターンに帰着する
- 圏論的な実装独立性は、異なる力学系が同じ分岐型を持つことに対応する

最も強力なフレームワークは、系の性質に依存する:
- 離散的・ネットワーク的な系 -> Framework 1（グラフ理論）
- 連続的・空間的な系 -> Framework 2（位相空間論）+ Framework 4（分岐理論）
- 領域間比較 -> Framework 3（圏論）

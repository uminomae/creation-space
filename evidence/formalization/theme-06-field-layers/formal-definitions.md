## Framework 1: フィルトレーション（層的構造）による場の多層性

### 定義 1.1（場のフィルトレーション）

場の全体 F に対し、以下のフィルトレーション（増大列）を定義する:

F^{(0)} ⊆ F^{(1)} ⊆ F^{(2)} ⊆ ... ⊆ F

ここで:
- F^{(0)}: 原初的場（pre-structural field）。構造以前の基底状態。
- F^{(1)}: 循環的場（cyclic field）。前の束が提供した構造を持つ。
- F^{(2)}: 存在論的場（ontological field）。F^{(1)} を含む、より広い可能性の空間。

### 定義 1.2（原初的場 F^{(0)} の位相的特徴づけ）

原初的場 F^{(0)} を以下の性質を持つ位相空間として定義する:

(P1) **連結性**: F^{(0)} は弧状連結（任意の2点が連続な道で結ばれる）
(P2) **縮約可能性**: F^{(0)} は縮約可能（contractible）— 一点に連続変形できる
(P3) **非空性**: F^{(0)} ≠ ∅

**含意**: 原初的場は「何もない」（∅）ではなく、「構造がない」（縮約可能）状態。D02 量子真空は「無」ではなく揺らぎの海であり、D01 の公理系以前の空間は無構造だが空ではない——これらは (P3) + (P2) の自然言語的表現。

### 定義 1.3（循環的場 F^{(1)} の位相的特徴づけ）

第 n サイクルの循環的場 F_n^{(1)} を、前の束 Bd_{n-1} の情報を含む位相空間として定義する:

F_n^{(1)} = F^{(0)} ∪ Struct(Bd_{n-1})

ここで Struct(Bd_{n-1}) は束が場に残した「構造的痕跡」。

**性質**:
- F_n^{(1)} は一般に縮約可能でない（構造が追加されているため）
- π_1(F_n^{(1)}) ≠ 0 が可能（基本群が自明でない = 「穴」が存在する = 前のサイクルの記憶）
- ベッチ数 b_k(F_n^{(1)}) >= b_k(F^{(0)}) = 0 for k > 0

**含意**: 循環的場が原初的場より「豊か」であることは、位相的不変量（ベッチ数）の増加として測定可能。D04 進化の遺伝子プールの多様化、D30 TEK の蓄積は、F^{(1)} のベッチ数の増加に対応する。

### 定義 1.4（場の質の位相的定義）

場の質 Q(F) を位相的不変量の関数として定義する:

Q(F) = f(b_0(F), b_1(F), ..., b_k(F), χ(F))

ここで b_k はベッチ数、χ はオイラー標数。

**具体例**:
- Q = Σ b_k（全ベッチ数の和 = 位相的複雑性）
- Q_0 = b_0（連結成分数 = 多様性）
- Q_1 = b_1（1次ベッチ数 = 循環構造の数）

T5 定理4（場の質の単調性）の Q がこの位相的定義で具体化される。

## Framework 2: ファイバーバンドルによる場の多層性

### 定義 2.1（場のファイバーバンドル）

場の多層性をファイバーバンドル (E, B, π, F_fiber) として記述する:

- B = F^{(2)}（存在論的場）: 底空間
- F_fiber = F^{(1)}_specific（特定の経験的場）: ファイバー
- E = 全体の場: 全空間
- π: E → B: 射影

**含意**:
- 異なる b ∈ B（存在論的場の異なる「点」）の上に、異なる経験的場 π^{-1}(b) が乗る
- 30領域の場は、同じ底空間（存在論的場）の異なるファイバーとして理解可能
- T1 の「実装独立性」と同構造: 底空間が普遍的構造、ファイバーが領域固有の実装

### 定義 2.2（場の切断としての具体的場）

特定の領域 D_i における場は、バンドルの切断（section）として記述される:

s_i: B → E  s.t. π ∘ s_i = id_B

すなわち、存在論的場の各点に対して経験的場の具体的状態を対応させる写像。

**含意**: 各領域は「存在論的場をどのように経験するか」の異なる切断を選ぶ。D13 哲学はフッサールの受動的背景として切断し、D27 建築は「間」の余白性として切断し、D29 複雑系は孤立クラスター散在として切断する——これらは同じバンドルの異なる切断。

## Framework 3: 前層（Presheaf）による場の構造

### 定義 3.1（場の位相としての開集合系）

状態空間 X に位相 τ を入れ、5段階を X の部分集合として定義する（T1 定義 2.1 を継承）。

場の「潜在性」を前層（presheaf）として定義する:

P: τ^{op} → Set

P(U) は開集合 U 上で「可能な状態」の集合を返す。

### 定義 3.2（場の層条件と潜在性の大域化）

P が層（sheaf）の条件を満たすとき:

局所的な可能性（各 U_i 上の可能状態）が大域的な可能性（X 全体の可能状態）に一貫して貼り合わせられる。

**5段階との対応**:
- 場が層条件を満たす ⟺ 局所的に見た可能性が大域的に矛盾しない ⟺ 場は「一貫した潜在性」を持つ
- 場が層条件を満たさない ⟺ 局所的にはあり得る状態が大域的には矛盾する ⟺ 場に「内部緊張」がある

**含意**: D08 神経科学の「動的均衡」は層条件を満たす場（安定だが覚醒している）、D05 地球科学のティッピングポイント近傍は層条件が破れかけた場（局所的に安定だが大域的に不安定）と解釈できる。

### 定義 3.3（潜在性の測度）

場の潜在性の大きさを、層のコホモロジーで測る:

H^0(F, P) = 大域的に可能な状態の集合（場の「幅」）
H^1(F, P) = 局所的には貼り合わせられない障害（場の「ねじれ」）

**5段階との対応**:
- H^0 が大きい ⟺ 場の潜在性が豊か（多くの可能性を含む）
- H^1 ≠ 0 ⟺ 場に非自明な構造がある（前の束の痕跡が位相的障害として残る）

## Framework 4: 場と波の境界——勾配フローによる活性度

### 定義 4.1（活性度関数）

状態空間 X 上の連続関数 α: X → [0, 1] を **活性度関数** として定義する:

α(x) = 0: 完全な場（差異が顕在化していない）
α(x) = 1: 完全な波（差異が最大限に顕在化している）

5段階の「場」と「波」の区別は α の閾値で与えられる:

F = {x ∈ X : α(x) < α_FW}
W = {x ∈ X : α_FW <= α(x) < α_WE}

ここで α_FW は場→波の遷移閾値。

### 定義 4.2（場の動的定義）

場を静的な集合ではなく、α の勾配フローの文脈で動的に定義する:

場の状態 x は α の極小点の近傍にあり、dα/dt ≈ 0（活性度が低く安定）。

波への遷移は α の値が増大し始めることに対応: dα/dt > 0。

**含意**: 場と波の境界は連続的であり、離散的な「段階」は活性度の閾値として人為的に導入される。T6 §C 分岐3（場の定義を拡張すると波との境界が曖昧になる）はこの定式化で解消される——境界は「ある」が連続的なので「曖昧」に見える。

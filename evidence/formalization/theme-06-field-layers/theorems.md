## 定理 1（場の非空虚性定理）

**主張**: 原初的場 F^{(0)} は空集合ではなく、かつ自明でない位相構造を持ちうる。

**形式的記述**: 定義 1.2 の条件 (P1)-(P3) により、F^{(0)} は少なくとも弧状連結な空でない空間。さらに、原初的場上に定義される前層 P が自明でない（H^0(F^{(0)}, P) が非自明な可能状態を含む）。

**含意**: 5段階の「場」の現行記述「ゼロ、無。可能性だけがある」のうち、「ゼロ、無」は修正が必要であり、「可能性だけがある」は正確である。場は「何もない」のではなく「構造がない（が可能性はある）」状態。

**整合性**: D02（量子真空 = 揺らぎの海、「最大の潜在性」）、D15（Schiller 規定可能性 = 全ての決定が可能）、D08（動的均衡 = 安定すぎず不安定すぎない）、D27（余白 = 何もないことが何かである）が独立にこの定理の自然言語的表現を提供している。

## 定理 2（循環的場の構造蓄積定理）

**主張**: n サイクルの再循環を経た循環的場 F_n^{(1)} は、原初的場 F^{(0)} よりも位相的に複雑である。具体的には:

Σ_k b_k(F_n^{(1)}) >= Σ_k b_k(F^{(0)})

ここで b_k はベッチ数。等号は Φ が位相的に自明な場合に限り成立する。

**証明の概略**: 各サイクルで Struct(Bd_{n-1}) が F^{(0)} に付加される（定義 1.3）。Struct が位相的に非自明な構造（穴、ループ等）を導入する場合、ベッチ数は非減少。T5 の拡張型（C3）の循環では厳密に増加する。

**含意**: D04（遺伝子プールの多様化 = b_0 の増大）、D30（TEK の蓄積 = 知識空間の b_1 の増大）、D26（音楽聴取体系の洗練 = 期待パターンの複雑化 = b_k の増大）はいずれもこの定理の具体例。

**実用的帰結**: 創造過程において、「何回の循環を経た場か」が場の質を決定する。初回（F^{(0)} からの出発）は最も貧しい場から始まり、循環を重ねるほど場が豊かになる。これは D30 伝統知が「反復の中の創造」を強調する理由の位相的説明。

## 定理 3（場-波連続性定理）

**主張**: 活性度関数 α: X → [0, 1] が連続であるとき、場と波の間に「鮮明な境界」は存在しない。すなわち、任意の ε > 0 に対して、α_FW - ε < α(x) < α_FW + ε を満たす状態 x が存在する（場でも波でもない「中間状態」）。

**含意**: T6 §C 分岐3（場の定義を拡張すると波との境界が曖昧になる）は、活性度関数の連続性の数学的帰結。5段階の離散的段階区分は、連続的な活性度空間上の便宜的な区切りである。

**D13 哲学との対応**: 「段階化への内在的抵抗」（リゾーム的思考）は、この連続性の哲学的表現。5段階を「離散的段階」ではなく「連続的密度変化」として再記述する可能性を支持する。

**実用的判断**: 連続的記述は正確だが実用性が低い。5段階の離散的区分は「α の閾値による便宜的離散化」として理論的に位置づけつつ、実用的には維持する。

## 定理 4（場のファイバー定理）

**主張**: 30領域の場がファイバーバンドル (E, B, π, F_fiber) の切断として記述できるとき、バンドルの構造群 G が場の「普遍的制約」を定める。

**含意**: 異なる領域の場は異なる切断だが、同じ構造群 G の制約の下にある。G の性質が「場一般に成り立つ法則」を定義する。

**具体例**:
- G が自明（G = {e}）⟺ バンドルが自明 ⟺ 全ての領域の場が本質的に同じ構造を持つ
- G が非自明 ⟺ 局所的には同じに見えるが大域的に異なる ⟺ ある領域の場の知見が他の領域に「翻訳不能」な場合がある

T1 定理4（実装独立性のファイバー定理）の「場」特化版。

## 定理 5（条件付き潜在性の測定定理）

**主張**: 場の潜在性を層のコホモロジー H^0(F, P) で測定するとき、循環的場の潜在性は前の束の性質に条件づけられる。

H^0(F_n^{(1)}, P) = h(H^0(F^{(0)}, P), Bd_{n-1})

ここで h は束からの構造的痕跡が潜在性をどう変形するかを記述する関数。

**含意**: 「同じ場」でも、前の束が異なれば潜在性が異なる。D04（多様な遺伝子プール → 大きい H^0）と D22（ロックインした組織文化 → 小さい H^0）は、同じ位相空間 X 上の異なる前層 P の違いとして記述可能。

T5 定理4（場の質の単調性）の「潜在性」バージョン。

## 性質 1（3層目の到達不能性）

**観察**: D13 西田の絶対無、D24 仏教の空に対応する「究極的場 F^{(3)}」は、F^{(0)}, F^{(1)}, F^{(2)} のフィルトレーションの延長として自然に到達しない。

**理由**: F^{(3)} は「全てを包摂する」性質を持つが、集合論では「全ての集合の集合」はパラドクスを生む（Russell のパラドクス）。圏論では「全ての圏の圏」が通常の圏として構成できない（サイズの問題）。

F^{(3)} は形式的体系の外部にあり、形式化の対象ではなく限界として記録すべき。

## 性質 2（場の「安全性」条件）

**観察**: D08 ポリヴェーガル理論が示唆する「場が作動するには安全だが覚醒している条件が必要」は、活性度関数 α の下界条件として記述可能:

α_safe < α(x) < α_FW（安全かつ覚醒の帯域）

α(x) < α_safe のとき場は「凍結」（ポリヴェーガルの凍結反応）、α(x) > α_FW のとき波に移行。

D22 心理的安全性、D12 生態系安定性も同構造——場が「機能する」には最低限の活性度が必要であり、完全な静止は場の機能を停止させる。

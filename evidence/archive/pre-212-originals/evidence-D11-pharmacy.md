# 論拠DB：薬学（Pharmacy）

**概要**: 候補探索から臨床運用、耐性や安全性監視を通じた再設計まで循環が強く構造類似は高い。製剤設計・品質保証・配伍など「関係の制度化」が薬学固有の強み。「縁のスペクトラム」（精密設計↔意図せざる出会い）を最も鮮やかに示す領域。

**凡例**: **[P]** 文献に基づく解釈 / **[M]** 理論から着想した構造的類似

**方法論的原則**: 指し示すだけ。無理に当てはめない。表面的類似と構造的類似を区別する。

**評価レンズ**: ①縁の判別力 ②PID制御対応 ③意識の有無（分析生成/存在生成）

## 領域レポート

### L-1: 領域概観

薬学における「創造」は新規医薬品の発見・設計・製造・品質保証という一連のプロセスとして扱われてきた。分子レベルの相互作用から制度的な品質保証まで複数スケールにまたがるプロセスを統合的に管理する実践的学問である。

歴史的には偶然の発見（ペニシリン等）→体系的スクリーニング（HTS）→構造ベース設計（SBDD）→AI創薬へとパラダイムが移行。品質保証思想も「事後検査」→「事前設計」（QbD）へ転換。東洋医学（漢方）の配伍の知恵はネットワーク科学の視点から再解釈されつつある。

薬学の特筆すべき点は「関係の制度化」が極めて進んでいること。ICH Q8のDesign Space、FDAのDDIガイダンス、漢方の配伍原理など、「相互作用」そのものを制度的・原理的に管理する体系が確立されている。5段階の中でも「縁」との対応が特に濃密。

### L-2: 対応密度

- **Accept**: 10/10（100%）
- **CA**: 0, **Reject**: 0
- **縁フラグ**: 🔴 6件（PM-002,003,005,006,008,009）/ 🟡 4件（PM-001,004,007,010）/ ⚪ 0件
- **他領域との比較**: Accept率・縁🔴率ともに非常に高い。D04進化生物学やD02物理と同水準
- **クラスター分析**:

### L-3: スケール横断

- **最小**: 原子（SBDD結合ポケット）
- **最大**: 公衆衛生制度（耐性対策、規制システム）
- **時間**: 分（薬物代謝）〜十年（開発パイプライン、耐性進化）
- **フラクタル**: 分子相互作用（PM-007,010）→酵素レベル個体差（PM-002,008）→処方レベル配伍（PM-005）→制度レベル品質保証（PM-006）で「関係の構造」が同パターン反復。薬学内フラクタルが明確

### L-4: 洞察

薬学は「縁のスペクトラム」を最も鮮やかに示す領域。PM-010(SBDD)の精密設計→PM-007(プロドラッグ)の計画的起動→PM-002/008(PK/PD/ファーマコゲノミクス)の個体差による個別化→PM-009(DDI)の意図せざる出会いまで、「縁の制御可能性のグラデーション」が一領域内で完全に揃う。このスペクトラムは本書全体の重要メタファーとなりうる。

もうひとつの洞察は「東西の接続」。漢方の配伍（PM-005）とネットワーク薬理学は「関係の全体性」を東洋的直観と西洋的定量分析の両面から記述する。証の見立て＝D2欠損認識の具体化。

## 1. Wallas：創造性の4段階モデル（1926）

### 1.1 モデル概要

Graham Wallasは『The Art of Thought』において、創造的思考の4段階を提唱した：

| 段階 | 英語名 | 内容 |
|------|--------|------|
| 1 | Preparation | 問題の認識、情報収集、意識的な取り組み |
| 2 | Incubation | 意識的処理の中断、無意識的な処理 |
| 3 | Illumination | 洞察の瞬間、「アハ体験」 |
| 4 | Verification | アイデアの検証、精緻化、実装 |

### 1.2 5段階との対応

| Wallas | 5段階 | 対応の質 |
|--------|-------------|---------|
| Preparation | 場（漂う） | 部分的：情報収集は「場」だが、問題認識は既に「波」 |
| Incubation | 場→波 | **強い対応**：意識下での揺らぎ、対立の醸成 |
| Illumination | 縁→渦 | **強い対応**：境界を超えて「個」が立ち上がる瞬間 |
| Verification | 束 | **強い対応**：方向性の確定、集合化 |

### 1.3 差異と補完

**Wallasモデルの限界**:
- 線形的・一方向的モデル（循環性の欠如）
- 「Incubation」の内部構造が不明
- 社会的・間主観的次元の欠如

**欠損駆動思考による補完**:
- 5段階は循環的に適用可能（束→場への回帰）
- Incubationを「波」と「縁」に分解し、内部構造を記述
- M3（事業構造）との接続で社会的次元を補完

### 1.4 「欠損」概念との接続

Wallasの「Preparation」における「問題の認識」は、欠損駆動思考では以下のように再解釈できる：

> 問題の認識 = 予測と現実のズレ（予測誤差）を、意識が「欠け」として捉える経験

つまり、創造プロセスの出発点は「欠損の経験」である。Wallasは前提としていた「問題」を、我々は「欠損」として内的メカニズムから説明する。

## 2. Guilford：発散的思考と収束的思考（1950s）

### 2.1 概念定義

J.P. Guilfordは知能の構造モデル（SOI）において、以下を区別した：

| 思考タイプ | 特徴 | 例 |
|-----------|------|-----|
| 発散的思考（Divergent） | 多様なアイデアを生成、正解なし | ブレインストーミング |
| 収束的思考（Convergent） | 一つの正解に収束、論理的推論 | 数学の証明 |

### 2.2 5段階との対応

| 思考タイプ | スペクトラム位置 |
|-----------|----------------|
| 発散的思考 | 場→波→縁（拡散、分離、関係の探索） |
| 収束的思考 | 渦→束（個の確立、方向の確定） |

**重要な洞察**: Guilfordの二分法は、5段階の前半（1-3）と後半（4-5）に対応する。創造プロセスは「発散→収束」の単純な二項ではなく、5段階の連続的移行として記述できる。

### 2.3 欠損駆動思考への示唆

発散的思考の神経科学的基盤として、以下が示唆されている：
- デフォルトモードネットワーク（DMN）の活性化
- 前頭葉の抑制制御の緩和
- 遠隔連想の促進

これは4層モデルにおける：
- Layer 3（抱持）の一時的緩和
- Layer 1（予測-誤差ループ）の拡張モード

として解釈可能。

## 3. Csikszentmihalyi：フロー理論とシステムモデル

### 3.1 フロー（Flow）理論

Mihaly Csikszentmihalyiは『Flow: The Psychology of Optimal Experience』（1990）において、最適経験（フロー）の特徴を記述した：

| フローの特徴 | 欠損駆動思考との対応 |
|-------------|-------------------|
| 明確な目標 | Layer 2（F-O評価）による方向づけ |
| 即座のフィードバック | Layer 1（予測-誤差ループ）の高速作動 |
| 挑戦と能力の均衡 | 予測誤差が「適度な」範囲にある状態 |
| 行為と意識の融合 | Layer 3（抱持）の最適化 |
| 自意識の消失 | メタ認知の一時的停止 |
| 時間感覚の変容 | 没入による時間知覚の変化 |
| 自己目的的経験 | 内発的動機づけ |

### 3.2 システムモデル（1996, 1999）

後期のCsikszentmihalyiは、創造性を「個人-領域-場」の相互作用として捉えた：

```
      ┌─────────┐
      │  領域   │←──文化的記号体系
      │(Domain) │
      └────┬────┘
           │選択・変容
     ┌─────┴─────┐
     ↓           ↓
┌────────┐   ┌────────┐
│  場    │←→│  個人  │
│(Field) │   │(Person)│
└────────┘   └────────┘
  門番機能     新奇性生成
```

### 3.3 4モジュールとの対応

| Csikszentmihalyi | 4モジュール | 対応 |
|------------------|-----------|------|
| 個人（Person） | M1: 意識OS | 創造の主体、内的プロセス |
| 領域（Domain） | M4: 世界観 | 文化的記号体系、知識構造 |
| 場（Field） | M3: 事業構造 | 社会的評価システム、門番 |
| （創造プロセス） | M2: 創造プロセス | 3者の相互作用の記述 |

**重要な対応**: Csikszentmihalyiの「システムモデル」は、我々の4モジュール構造と高い親和性を持つ。特に「創造は個人の内部だけでなく、社会的・文化的文脈との相互作用で生じる」という主張は共通。

### 3.4 フローと「欠損」の関係

フロー状態は以下のように再解釈できる：

> フロー = 予測誤差が「適度に」発生し、かつそれが即座に処理される状態

- 誤差が小さすぎる → 退屈（challenge不足）
- 誤差が大きすぎる → 不安（skill不足）
- 誤差が適度 → フロー（欠損が問いとして機能し、即座に応答できる）

これは「欠損駆動」が最適に機能している状態と解釈できる。

## 4. Amabile：創造性の構成要素モデル（1983, 1996）

### 4.1 3構成要素

Teresa Amabileは創造性を以下の3要素の交差として定義した：

```
        領域関連スキル
       (Domain-Relevant Skills)
              ↑
              │
    創造性関連プロセス ←→ 課題動機づけ
(Creativity-Relevant Processes)  (Task Motivation)
```

| 構成要素 | 内容 |
|---------|------|
| 領域関連スキル | 専門知識、技術的スキル、才能 |
| 創造性関連プロセス | 認知スタイル、発見的方法、作業スタイル |
| 課題動機づけ | 内発的動機、課題への態度 |

### 4.2 欠損駆動思考との接続

| Amabile構成要素 | 4層/4モジュール対応 |
|----------------|-------------------|
| 領域関連スキル | M4（世界観）+ Layer 1の予測モデル精度 |
| 創造性関連プロセス | M2（創造プロセス）+ Layer 3（抱持） |
| 課題動機づけ | Layer 2（F-O評価）、特にO軸（愛着・好奇心） |

### 4.3 内発的動機づけ原理

Amabileの「内発的動機づけ原理」は以下を主張する：

> 外発的動機づけは創造性を阻害し、内発的動機づけは創造性を促進する

欠損駆動思考の観点からは：

- **内発的動機** = 欠損そのものが「問い」として機能する状態（O軸優位）
- **外発的動機** = 欠損が「脅威」として処理される状態（F軸優位）

F-O評価の軸の違いが、動機づけの質を決定する。

## 5. Sawyer：協調的創造性（2000s）

### 5.1 即興と創発

R. Keith Sawyerは『Group Genius』（2007）等で、創造性の協調的・即興的側面を強調した：

| 概念 | 内容 |
|------|------|
| グループフロー | 集団で共有されるフロー状態 |
| 創発（Emergence） | 個人の総和を超えた集団的創造 |
| 即興（Improvisation） | 計画なしに生成される協調的パフォーマンス |

### 5.2 5段階との対応

Sawyerの即興理論は、5段階を「集団レベル」で適用したものと解釈できる：

| 段階 | 個人レベル | 集団レベル（Sawyer的） |
|------|-----------|---------------------|
| 場 | 個人の認知的場 | 共有された可能性の空間 |
| 波 | 内的な揺らぎ | 参加者間のテンション |
| 縁 | 概念の境界 | 参加者間の相互作用 |
| 渦 | 個としてのアイデア | 創発的なグループアイデア |
| 束 | 個人の決定 | 集団的合意、共有ビジョン |

### 5.3 M3（事業構造）への示唆

Sawyerの知見は、M3（事業構造）の設計に直接関連する：

- チーム構成における「適度な多様性」の重要性
- 心理的安全性とグループフローの関係
- 「欠損」の共有がチーム創造性を促進する可能性

## 6. Boden：計算論的創造性（1990, 2004）

### 6.1 創造性の3類型

Margaret Bodenは『The Creative Mind』において、創造性を3つのタイプに分類した：

| 類型 | 英語名 | 内容 |
|------|--------|------|
| 組合せ的 | Combinational | 既存要素の新しい組み合わせ |
| 探索的 | Exploratory | 概念空間内の未探索領域の発見 |
| 変換的 | Transformational | 概念空間自体の変容 |

### 6.2 5段階との対応

| Boden類型 | スペクトラム位置 | 対応説明 |
|-----------|----------------|---------|
| 組合せ的 | 縁（関係） | 既存要素間の新しい「繋がり」 |
| 探索的 | 波→縁→渦 | 場の内部を探索し、新しい「個」を発見 |
| 変換的 | 場の再構成 | 予測モデル自体の変容、パラダイムシフト |

### 6.3 AIと創造性：欠損駆動思考の立場

Bodenの計算論的アプローチは「創造性は計算可能か？」という問いを提起する。

欠損駆動思考の立場：

| 創造性タイプ | AI実装可能性 | 理由 |
|-------------|-------------|------|
| 組合せ的 | ✅ 高い | 組み合わせ探索は計算可能 |
| 探索的 | ✅ 高い | 概念空間の探索は実装済み |
| 変換的 | ⚠️ 部分的 | 概念空間の「外部」へ出ることが困難 |

**欠損駆動思考の独自性**:

> AIは予測誤差を「計算」するが、「欠損」を「経験」しない

- 予測誤差の検出 → AI可能
- 予測誤差の主観的経験（欠損） → AI不可能（現時点）
- 欠損を「問い」として拾う判断 → AI困難（価値判断を含む）

これが「AIが苦手なことはこの分野」という主張の根拠となる。

## 7. Rhodes：4P（Person/Process/Product/Press）（1961）

**概要**: 創造性を「個人/過程/産物/環境」に分解する整理枠。原因論ではなく、議論の混線防止に効く。

**欠損駆動思考との接続**:
- 4Pはそのまま4モジュールではないが、ProcessをM2、PressをM3/M4（制度/規範）として接続しやすい。

**TC-012（要点）**:
- [類似] 単一因子ではなく“分解して扱う”
- [独自] 分解枠を4層（L0-L3）へ落とし、Processを機構として説明する
- [学び] 粒度を固定して議論を事故らせない（プロセスガード）
- [文脈] 研究の整理枠であり、因果モデルではない

参照: EV-CR-007

## 8. Mednick：連想理論 / Remote Associates（1962）

**概要**: 創造性は遠隔連想（離れた概念の架橋）能力に関係する。RATはその測定タスク。

**欠損駆動思考との接続**:
- 「縁（関係の生成）」に焦点。欠損（関係欠損）→保持→結びつき、という流れを部分的に測れる。

**TC-012（要点）**:
- [類似] 新規性は“関係の生成”として現れる
- [独自] 連想を欠損検出（D2）と抱持（D3）の循環に位置づける
- [学び] 縁の生成を測る実験タスク（RAT）
- [文脈] 個人内過程中心。社会的評価は別モデルが必要

参照: EV-CR-008

## 9. Finke/Ward/Smith：Geneplore（生成→探索）（1992）

**概要**: 生成（preinventive structures）と探索（解釈・精緻化）の往復で創造が進む。

**欠損駆動思考との接続**:
- 生成≒場→波、探索≒縁→渦、の往復として自然に接続できる。

**TC-012（要点）**:
- [類似] 往復運動（生成↔探索）が創造の本体
- [独自] 往復の燃料を欠損（D2）とし、止めない力を抱持（D3）に置く
- [学び] “中間成果”概念（何を保持しているか）を持てる
- [文脈] 認知実験の操作概念が中心

参照: EV-CR-009

## 10. Campbell/Simonton：BVSR（盲目的変異と選択的保持）（1960s–）

**概要**: 創造を「変異（試行）→選択→保持」のサイクルとして捉える。

**欠損駆動思考との接続**:
- 変異＝探索（場/波）、選択＝束（方向確定）、保持＝抱持 と読める。

**TC-012（要点）**:
- [類似] 試行と淘汰のプロセス
- [独自] “blind”を欠損の主観（わからなさ）として内側から扱う／選択をF-O評価として扱う
- [学び] 創造を美談ではなく探索・淘汰として扱う冷静さ
- [文脈] 進化論アナロジーであり、具体手続きは別途必要

参照: EV-CR-010

## 11. Sternberg & Lubart：投資理論（1990s）

**概要**: 低評価アイデアに投資し、後に価値化（評価の反転）するという比喩で創造を捉える。

**欠損駆動思考との接続**:
- 価値化はM3（評価/門番）とM4（領域規範）を必須化する。創造は個人内で完結しない。

**TC-012（要点）**:
- [類似] 価値は後から立ち上がる（束→場の往復）
- [独自] 価値化をF-O評価としても記述し、投資の継続を抱持で支える
- [学び] 評価制度（M3）を創造理論に組み込む
- [文脈] 社会的評価とキャリアの文脈が前提

参照: EV-CR-011

## 12. Kaufman & Beghetto：4C（mini-c / little-c / Pro-c / Big-C）（2009）

**概要**: 創造性を4水準に分け、評価スケール差による混線を防ぐ。

**欠損駆動思考との接続**:
- mini-c（個人的創造）をD2（欠損の経験）起点で扱いやすい。Big-CはM3/M4の評価・歴史性が不可欠。

**TC-012（要点）**:
- [類似] 創造は評価と不可分
- [独自] mini-cを4層で機構記述して“個人的創造”を理論の中心に置く
- [学び] レベル差を明確化して過剰一般化を防ぐ
- [文脈] 教育心理学・才能研究の枠組み

参照: EV-CR-012

## 13. Torrance：TTCT（発散的思考の測定・教育）（1960s–）

**概要**: 発散的思考を測定するテスト群。教育実践と結びつく。

**欠損駆動思考との接続**:
- 場→波→縁（発散/探索側）の一部を操作的に捉える足場になる。

**TC-012（要点）**:
- [類似] 発散（拡散）を創造の重要要素とみなす
- [独自] 測定対象を“アイデア数”から“欠損の保持と変換”へ拡張する必要
- [学び] 実証接続のための指標・手続き
- [文脈] 教育評価（能力としての創造性）

参照: EV-CR-013

## 14. Ohlsson：表象変化（洞察問題）（1990s–）

**概要**: 洞察は表象の再編（制約緩和/再符号化など）で生じる。

**欠損駆動思考との接続**:
- 波（詰まり）→縁/渦（再構成）というジャンプを、表象変化として精密化できる。

**TC-012（要点）**:
- [類似] 洞察＝モデル（表象）の更新
- [独自] 表象変化を欠損（D2）と抱持（D3）の循環＋F-O評価で駆動する
- [学び] 制約緩和などの“手続き語彙”
- [文脈] タスク依存で精密、社会文化は別枠

参照: EV-CR-014

## 15. Nijstad/De Dreu：Dual Pathway（柔軟性/持続性）（2008–）

**概要**: 創造は柔軟性経路（多様化）と持続性経路（掘り下げ）の2経路で高まる。

**欠損駆動思考との接続**:
- 持続性は“欠損を問いとして保持する力（抱持）”の候補概念になる。

**TC-012（要点）**:
- [類似] 発散だけでは創造は説明できない
- [独自] 持続性を抱持（D3）として定義し直す
- [学び] 失敗モード（柔軟性過多/持続性過多）を分類できる
- [文脈] 社会心理学（気分・動機）系の実証

参照: EV-CR-015

## 16. Beaty ほか：DMN×実行制御の協調（2010s–）

## 20. 結論：創造性研究における欠損駆動思考の位置

### 20.1 独自の貢献（更新）

1. **「欠損」概念による出発点の固定**: 創造は「問題」ではなく「欠損の経験」から始まる
2. **内部機構の記述**: 5段階・4層・抱持・F-O評価により、段階間移行を機構として書ける
3. **社会文化・評価の内蔵**: M3/M4を必須化し、評価・受容・環境を“外付け”にしない
4. **実証への足場**: RAT/TTCT/神経ネットワーク指標を足場に、検証可能な仮説を設計できる
5. **AI対比の弁別**: 「計算」と「経験（欠損）」を分けて主張できる

### 20.2 残された課題（再定義）

| 課題 | 次にやること（最小） |
|------|----------------------|
| 実証研究との接続 | (a) 抱持指標（持続性/抑制/遅延）を操作化し、(b) RAT/TTCT/dual pathway と相関・差分を仮説化する |
| フロー状態の4層モデル（暫定） | L0（自律神経の安全）→L1（即時フィードバック）→L2（F-Oの適度化）→L3（過剰抑制の回避としての抱持最適化）を仮説として置く |
| 協調的創造性とM3 | 5A（Audience/Press）と投資理論（価値化）を使い、評価制度・心理的安全性・多様性の設計原則としてM3へ落とす |

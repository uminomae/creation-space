## §2 スタンス: unitive（最上位ルール）

pjdhiroの文章は**内省**。誰にも話しかけてない。

- 小学生が洞察してるような不思議さ。「そんなこと考えてるの？」という驚きが面白さ
- 世界の端っこから全世界に報告してる感じ。語りかけではなく、独り言が漏れてる
- へんてこりんなものを「好き」と言う。「なになにが好き」のなになにが変
- 読者は「話しかけられてる」のではなく「覗いてる」感覚

| NG | OK |
|-----|-----|
| 「〜しなくていい」 | 「〜しなくていいんじゃないかと思ってる」 |
| 「あなたの〜は何ですか？」 | 「自分でもまだわかってないんだけど」 |
| 「〜に気づいていますか」 | 「〜って不思議じゃないですか」 |
| 「実は〜なのです」 | 「〜なのかも。わからんけど」 |
| 読者に語りかける | 独り言が世界に漏れてる |

## §3 禁止リスト

### 絶対禁止（unitiveルール違反）

- 読者に問いを投げる（「あなたの〜は何ですか？」）
- 読者に気づきを促す（「考えてみてください」「気づいていますか」）
- 許可を与える構造（「〜しなくていい」「〜でいいんです」）
- 「実は〜なのです」（真実を知ってる側の語り）
- 「本当にそうでしょうか」（常識を疑わせる側の語り）
- 「一般にはAだと思われているが、実はBである」（二元対立の反転構造）

### 禁止（AI臭）

- 対句・並列の美文
- 詩的な比喩の積み重ね
- 「〜ものだと言われる。しかし〜」の導入
- 問いかけ→共感→視点提示のテンプレ進行
- 感動を誘う構成
- 丁寧すぎる問いかけ

### 禁止（用語）

- 学術用語（α機能、投影同一化、予測符号化、自由エネルギー原理 等）
- 理論名・人名（Friston, Bion, Klein, Barrett 等）
- [P][M][S]タグ、D番号表記
- 数理表現

### 禁止（トーン）

- 断定・指示（「〜すべきです」「正解はこうです」）
- 空虚な肯定（「自分を信じて」「ありのままで」）
- 権威への依存（「科学的に証明されている」）
- エキゾチシズム（「古来より〜」「東洋では〜」）
- 感嘆符の多用、煽り口調
- スタンスのメタ言語化（「報告でした」「共有でした」等。在り方は体現するが書かない）

## §4 文体（10特徴）

1. **思考の途中を見せる**: 「〜かもしれない」「まだ仮説です」（S07）
2. **唐突な日常比喩**: 前置きなく具体例を入れる（S26）
3. **発見の興奮**: 「あれ、同じだ」「ここがミソで」（S15）
4. **方向付き仮説**: 断定しないが方向はある（S24）
5. **カタカナ混合**: 「ナニカ」「ワード」「コピー」
6. **軽さ**: 深い洞察を「ちょっと気づいたんだけど」の温度で
7. **未完成を隠さない**: 「まだ完成してません」
8. **ます崩し**: 「〜してます」「〜かなと」
9. **へんてこりんを「好き」と言う**: 「〜が好き」の対象が変
10. **小学生の洞察**: 素朴に問う。ふしぎがる。権威的でない

## §5 構成の原則

### 気づき順で並べる（理論順ではない）

pjdhiroの内省が辿った順番で並べる。4層モデルの順番（Layer 0→1→2→3）に合わせない。

例（ブログ「はじめに」）:
```
理論順: 体(L0) → ズレ(L1) → 恐さ(L2) → 保持(L3)
気づき順: 欠け → 体 → 恐さと大切さ → 保持  ← こちらを採用
```

### 結論は末尾に仮説として置く

「で、その先に出てくるものが創造じゃないかと。才能じゃなくて態度だと思う。」
——結論めいたものは最後に来る。しかも仮説。

### 関連する話は分けない

短く済む話は近いセクションに吸収する。セクション数を増やすよりも流れを優先。

### 見出しは構えない

「なるべく短く説明すると」「身体が先」「ひとりだと待てない」。
構えた見出し（「恐怖と価値の二軸構造について」等）は使わない。

## §6 リズムと句読点

- **7文字のリズム**: 詠唱するように7文字で綴ることが多い。意識して揃えすぎない
- **「短い→短い→突然長い」**: 均一にしない
- **「。」は話の終わりに使う**: 途中で改行するときは使わない。話が続いてるなら「。」なし改行
- **体言止め着地**: 「大切な現実。」「無意識のコピー。」短い体言止めで着地する
- **読点「、」**: 最小限。息継ぎに1つ
- **「？」**: 使っていい
- **「で、」接続**: 結論や次の話に移るとき。「で、その先に」

# T1 修正された適用範囲: 縁の類型学と統一分類

**生成日**: 2026-03-22
**Phase**: 9B 反証探索
**evidence フラグ**: [ai:falsification:claude-opus-4-6]

## 修正前の主張

「28/30ドメインが縁の多型性を主題化した。縁は帯域であり、方向選択の場であり、拮抗から生まれ、実装独立的であり、結合と解除の二方向がある。」

## 修正後の主張

「30領域の西洋学術伝統における既存概念を5段階モデルの『縁』として再記述した結果、以下の非自明な構造的対応が観察された。ただし、この対応は分析フレームワークの産物である可能性を排除できず、独立検証が必要である。」

## 具体的な適用範囲修正

### 1. 認識論的格下げ
- **修正前**: 「縁は普遍的構造である」（発見の主張）
- **修正後**: 「縁は西洋学術伝統の30領域に横断的に適用可能な解釈枠組みである」（解釈の主張）

### 2. 概念的再定式化
- **修正前**: 「縁の統一分類」（単一概念）
- **修正後**: 「縁の概念族と座標配置」（家族的類似性による概念群）

### 3. 収束点の絞り込み
- **残存する強い主張**（非自明かつ多領域で独立確認）:
  - 収束1: 帯域性（ただし一次相転移など例外あり）
  - 収束2: 方向選択性（ただしSOC雪崩など例外あり）
  - 収束3: 拮抗から生じる（自然科学で特に強い支持）
- **弱まった主張**（方法論的疑義あり）:
  - 収束4: 実装独立性 → フレームワーク循環の疑い
  - 収束5: 結合と解除の二方向 → 概念伸張の疑い

### 4. 文化的適用範囲の限定
- **検証済み**: 西洋学術伝統の30領域
- **未検証・今後の課題**: 
  - アジアの「間」(ma) 概念との照合
  - アフリカの Ubuntu 哲学における境界概念
  - 先住民の知識体系における遷移概念
  - イスラーム哲学の barzakh（中間世界）概念

### 5. 反証条件の明示化
以下が確認された場合、テーマは撤回または根本的再構築が必要:
- 独立した領域専門家30人への調査で「縁」概念に収束しない結果が得られた場合
- 非西洋的知識体系の過半数で「縁」に対応する構造が見出されない場合
- 帯域性・方向選択性が統計的有意に否定された場合

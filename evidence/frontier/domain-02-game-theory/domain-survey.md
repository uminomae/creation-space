## 1. 縁・境界に関する知見

### 1.1 混合戦略均衡の境界性
混合戦略均衡点は純粋戦略の「境界」に位置する。Harsanyi の disturbed game 理論では、プレイヤーの利得に微小な確率的攪乱を加えると、混合戦略均衡は純粋戦略均衡の「限界」として得られる。均衡は「帯域」的振る舞いを示す——mutation rate の変化に応じて mixed region の境界角度が変動する。

### 1.2 空間ゲームにおける境界ダイナミクス
空間ゲームモデルでは、プレイヤーが格子上に配置され隣接者とのみ対戦する。**協力者の領域と裏切り者の領域の境界**が戦略的緊張の場となり、勝利戦略が隣接近傍を支配し、その境界が隣接近傍と相互作用する。これは「縁」の空間的実装。

### 1.3 メカニズムデザイン = 「逆ゲーム理論」
メカニズムデザインは「結果から逆算してゲームのルールを設計する」理論。場（ゲーム構造）そのものの設計であり、D27建築の「場を設計する」と構造的に対応。設計者はプレイヤーの真の選好を知らずに良い結果を生むルールを構築する。

## 2. 循環・再生に関する知見

### 2.1 Rock-Paper-Scissors と Poincare 再帰
RPS ゲームの replicator dynamics は循環的軌道を描く。内部 Nash 均衡が存在するとき、ほぼ全ての軌道が初期条件に無限回近づく（**Poincare 再帰**）。平均距離がパラメータに応じて中心に収束／一定距離で無限循環／中心から発散する。

### 2.2 進化ゲームの動態
戦略は頻度に比例する速度で再生産される（replicator equation）。戦略分布の変化（束）が次の選択圧の場を構成する。進化的安定戦略（ESS）は「侵入されない束」だが、数学的には ESS が存在しない場合もある。

### 2.3 繰り返しゲームの Folk Theorem
無限に繰り返されるゲームでは、協力を含む広範な結果が均衡として維持可能（Folk Theorem）。前のラウンドの結果が次のラウンドの戦略的状況（場）を構成する。

## 3. ティッピングポイント・閾値に関する知見

### 3.1 臨界質量とネットワーク効果
ネットワーク技術の採用では、採用者数が臨界質量（critical mass）を超えるとネットワーク効果が支配的戦略になる。臨界質量点で、財から得られる価値が支払う価格を上回る。市場のティッピング——一つのシステムが初期の優位を得ると、競合から引き離される傾向。

### 3.2 囚人のジレンマからティッピングゲームへの変換
公共財供給のゲーム設計で、技術標準の採用がネットワーク外部性を伴う場合、「十分な数の他国が採用すれば自国も採用する」という構造に変わり、囚人のジレンマがティッピングゲームに変換される。ゲームのルール設計（メカニズムデザイン）により閾値構造が導入される。

### 3.3 分岐（Bifurcation）
Nash 均衡点の周囲で Neimark-Sacker 分岐により閉じた不変曲線が出現。系のパラメータ変化により安定/不安定への遷移（Hopf 分岐）。これは閾値的遷移の数学的記述。

## 4. 失敗・解体に関する知見

### 4.1 囚人のジレンマ = 集合的非合理性
個人合理性が集合的非合理性を生む。支配戦略が双方にとって劣る結果を導く。「悪い束」の古典的事例。

### 4.2 コモンズの悲劇
共有資源の過剰利用。各個人は過剰利用のインセンティブを持ち、協力の確保が困難。**過剰利用が系の回復能力を侵食し、特定の点を下回ると系が自己回復不能に**——不可逆的閾値の記述。

### 4.3 「勝つことがゲームを破壊する」
Persistence Game Theory: 勝利がゲーム自体の存続を脅かす構造。過度の搾取が資源基盤を破壊し、ゲームの「場」を消滅させる。

### 4.4 協力の崩壊
突然変異による協力の崩壊。Zealot（熱狂者）の存在が臨界質量効果を引き起こし、協力レジームから非協力レジームへの相転移を生む。

---

## 5. 場の多層性に関する知見

### 5.1 ゲーム構造の所与性と設計可能性
古典的ゲーム理論: ゲーム構造（利得行列、プレイヤー集合、情報構造）は所与。メカニズムデザイン: ゲーム構造自体を設計の対象にする。この二面性は T6 の「場は前提か到達物か」に対応。

### 5.2 ネットワーク上のゲーム
プレイヤー間の関係ネットワークが場を構成。ネットワーク構造（トポロジー、密度、クラスタリング）がゲームの結果を規定。ネットワーク構造自体が前のゲームの結果で変化する場合、循環的場が出現。

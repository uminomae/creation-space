## 継承する規律

- **[P][M][S] タグ**: [P]確立事実 / [M]比喩的解釈 / [S]推測仮説（作業中のみ。公開整形時に除去）
- **access status**: `raw-confirmed` / `citation-only` / `blocked-access`。citation-only の文献で内容を断定しない
- **Safety valve タグ**: `[SPECULATIVE]`, `[WEAK_MAPPING]`, `[SCALE_JUMP]`, `[UNCERTAIN]`
- **一面の探究スタンス**: 対立構図で書かない。実証の厚みだけを正直に注記する
- ファイル削除禁止。不要になったら `archive/` へ

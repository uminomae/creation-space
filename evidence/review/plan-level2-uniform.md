## 0. コンセプト（常に立ち返る）

> **創造の5段階モデル（場→波→縁→渦→束）に関する、先行事例の構造類似の探索。**
>
> M2が「存在そのものの創造」を記述しているなら、あらゆる学問領域で同じ構造が指し示せるはず。
> 「群盲象を評す」ように、様々な領域の類似概念から交点を差し示す。
> **論証はしない。指し示すだけ。** — pjdhiro

このステップの目的は、30領域の深さを均一にし、Step 5（調査作業レポート）の素材とすること。
深掘りとは「指し示す精度を上げる」こと。牽強付会を増やすことではない。

## 1. 範囲

**全30領域 × 代表1エントリ = 30エントリ**

| 範囲定義 | 内容 |
|---------|------|
| 対象 | `base/schema/academic-domains.md` に登録された D01-D30 全領域 |
| 粒度 | 各領域から代表1エントリを選定し Level 2 に引き上げる |
| 除外 | triage=Reject/NA のエントリは深掘り対象外 |
| 代表エントリ選定 | `judgments.md` に候補と判断状況を記録 |

### 範囲テスト（T-SCOPE）

| ID | テスト | PASS条件 |
|----|--------|---------|
| T-SCOPE-1 | 30領域すべてに代表エントリが指定されているか | academic-domains.md の全D番号にエントリIDが対応 |
| T-SCOPE-2 | 代表エントリは全て triage=Accept か | Reject/NA/CAのまま深掘りしていない |
| T-SCOPE-3 | 深掘り完了エントリが30件に達したか | memo.md の完了チェック欄が30件 |

## 2. 深さ

**ターゲット: Level 2（PROJECT.md 仕様）**

全エントリを以下の均一な深さに揃える:

### Level 2 必須フィールド（Level 1 に追記）

| フィールド | 内容 |
|-----------|------|
| `proposer` | 提唱者（人名） |
| `scale` | 時間/空間スケール |
| `module` | M1/M2/M3/M4 |
| `[類似]` | 欠損駆動思考との重なり（2-5文） |
| `[独自]` | 欠損駆動思考にありこの理論にない（2-5文） |
| `[学び]` | この理論にあり欠損駆動思考に不足（2-5文） |
| `[文脈]` | 理論固有の前提・適用範囲（2-5文） |

### 深さテスト（T-DEPTH）

| ID | テスト | PASS条件 |
|----|--------|---------|
| T-DEPTH-1 | Level 2 全フィールドが存在するか | proposer, scale, module, [類似],[独自],[学び],[文脈] が全て記述済み |
| T-DEPTH-2 | 4面記述の粒度は均一か | 各面2-5文。キーワードのみ不可。30エントリ間で極端な差がない |
| T-DEPTH-3 | Level 1 フィールドが既存基準を満たすか | TC-016 §3 全項PASS |
| T-DEPTH-4 | 既にLevel 2相当のエントリも同じフォーマットで揃っているか | 初期世代（EV-PH, EV-CR等）も同一仕様に統一 |

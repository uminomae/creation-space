## Task 3: 縁タイプの独立分類（有判定のみ）

対象: Task 1で `有` 判定の25領域

多重所属基準:
- 同一DR内で「縁の機能」が2種以上（例: 臨界閾値 + 制度設計）として明示される場合のみ多重所属を許容
- 一次記述が弱い場合は単独所属に固定

| タイプ | 定義 | 主な領域 |
|---|---|---|
| T1: 臨界・界面トリガ型 | 閾値/界面で相互作用が急増し渦が発火する | D02, D03, D06, D08, D29 |
| T2: 手続・制度編成型 | 行為者間の手続境界を設計し収束を作る | D11, D18, D20, D21, D22 |
| T3: 関係学習・発達型 | 複数方略の未決定状態から関係を編み収束する | D14, D17, D23, D30 |
| T4: リミナル変容型 | 旧/新に属さない帯域で再編が進み変容が起きる | D24, D25, D28 |
| T5: 表現・期待編成型 | 感性/表現の境界操作で秩序化が起きる | D15, D19, D26 |
| T6: 生態・歴史循環型 | 関係網の再配置が周期的に渦/束を更新する | D12, D16 |
| T7: 抽象整合型 | 局所整合と関係網から大域構造が成立する | D01, D13 |

補足（多重所属例）:
- D21 は T1（不安定化閾値）と T2（制度編成）の両性格を持つ
- D30 は T3（関係学習）と T4（儀礼的帯域）の橋渡しを持つ

## Task 4: H-1〜H-6 の具体的検証

### H-2: Reject 1件の意味（牽強付会リスク）

### H-3: 「縁」が創造の本質
- 支持:
  - DR-D16 §歴史学-002: 「関係構造が秩序を生む」と明示

- 反証/弱化:

  - DR-D05 §地球科学 総評: 渦解釈が候補間で揺れる

# Phase 7: cross-domain-synthesis（横断統合）— D05 地球科学

## §A: 横断パターン

### Pattern 1: 「不発の記録」の体系的存在

D05 内の3つの独立したサブシステムで「縁に到達したが超えなかった」事例が地質記録に保存されている:
- **Failed rift（D05-001）**: リフトが海洋底拡大に至らず、オーラコジェンとして残る
- **貫入岩（D05-005）**: マグマが噴火に至らず、地下で冷却固化して残る
- **エクスカーション（D05-009）**: 磁場が逆転しかけて元の極性に戻る

これは5段階の「波→縁→（超えず）→場回帰」という分岐経路が、物理系の違いを超えて構造的に共通であることを示す。5段階モデルは「完結するサイクル」だけでなく「不完結で終わるケース」を含めて記述する必要がある。核生成理論（D03-001）の「臨界核以下のクラスター消滅」と同型のパターン。

**5段階への含意**: 5段階ダイアグラムに「縁→不発→場回帰」の分岐を明示すべき。完結は例外的であり、不発が常態であるかもしれない。

### Pattern 2: 波の振幅と束の振幅の非比例性

地球科学の複数の事例で「小さな波→大きな束」のパターンが確認される:
- **ミランコビッチ 100kyr問題**: 離心率による日射変化は約0.2%（最弱の外因）だが、10万年周期の氷床変動（最大のシグナル）を生む
- **地震のGutenberg-Richter則**: 微小な応力増加が最大級の地震を引き起こしうる（べき乗分布）
- **ENSO**: 局所的な西風バーストが全球的なテレコネクションに発展する

これは5段階において「縁と渦のメカニズムが波の入力を非線形的に増幅する」ことの地球科学的実証。創造のきっかけ（波）の大きさは、結果（束）の大きさを決定しない。縁と渦の構造が増幅率を支配する。

**5段階への含意**: 「波は大きくなくてよい」という理解の根拠。5段階の本質的ダイナミクスは波→縁→渦にあり、波の振幅は初期条件にすぎない。

### Pattern 3: T1型（臨界・閾値トリガ）の集中と5段階の「閾値バイアス」

D05 の10エントリ中5件がT1型を含む（プレートテクトニクス、地震、火山、磁場逆転、惑星分化）。地球科学が「閾値を超えるかどうか」の学問であることを反映するが、同時に5段階モデルへの注意も要する:
- 5段階は「閾値超過モデル」に見えやすいが、ENSO（T2: 結合振動）、ミランコビッチ（T4: 外因強制＋内因応答）、シーケンス層序（T5: パッケージ化）が異なるメカニズムで5段階を実現している
- D05-008（風化: T7: 漸進的変換）は閾値なしの5段階適用テストケースであり、適用限界マーカーとして機能

**5段階への含意**: 5段階は閾値モデルに限定されないが、最も明確に嵌まるのは閾値型プロセス。非閾値型への適用は慎重にすべきであり、D05-008のCA判定は妥当。

### Pattern 4: 束→場の螺旋構造

D05 の複数の事例で「束は元の場に戻らず、異なる場を生む」ことが確認される:
- **ウィルソンサイクル**: 各サイクルで大陸配置が異なる（パンゲア→現在の配置は同じではない）
- **大量絶滅-回復**: 回復後の生態系は質的に異なる（恐竜→哺乳類）
- **惑星分化→プレートテクトニクス**: 一回限りの束が以後の全ての場を規定

5段階は閉じた円環ではなく、開いた螺旋として理解すべき。「束→場」回帰において「場」は前の場とは異なる。不可逆性が基本であり、厳密な循環は例外（ENSO のような振動系でも各サイクルの背景状態は変化する）。

**5段階への含意**: 5段階ダイアグラムを円環から螺旋に改訂すべきか。少なくとも「束→場」矢印に「新しい場」のラベルを付すべき。

### Pattern 5: 渦の多義性 — 4つの質的バリエーション

D05 内で「渦」が4つの異なる質で現れ、これは5段階の渦の定義を問う:

| 渦の質 | 共通構造 | 事例 | 5段階との対応強度 |
|--------|---------|------|-----------------|
| 正帰還増幅 | 正帰還ループ→自己維持 | ENSO(D05-002), 地震(D05-004), 火山(D05-005) | 最強 |
| 破壊的カスケード | 正帰還だが崩壊方向 | 大量絶滅(D05-007) | 強（方向が逆） |
| 非線形再編 | 旧秩序解体→新秩序構築 | 磁場逆転(D05-009) | 強 |
| スタッキング再帰 | 繰り返しの積み重ね | シーケンス層序(D05-006) | 弱 `[WEAK_MAPPING]` |

共通する最小要件は「自己組織化の過程」。正帰還はその最も典型的な実現だが、唯一の実現ではない。渦を「正帰還」に限定するか「自己組織化一般」に広げるかは、モデルの精度と一般性のトレードオフ。

**5段階への含意**: 渦の定義を「正帰還による自己増幅」から「秩序の自己組織化プロセス」に広げれば全バリエーションを包含できるが、定義が緩くなりすぎるリスクもある。現時点では「正帰還が典型、他のバリエーションも存在する」という記述が妥当。

## §B: 精度と限界

### 強い対応の条件

D05 内で5段階対応が最も強い（confidence >= 0.80）エントリに共通する条件:
1. **縁が明確な閾値として定義されている** — 臨界応力（地震）、過圧閾値（火山）、Bjerknes feedback発動点（ENSO）
2. **渦が正帰還ループとして記述できる** — 動的破壊伝播（地震）、Bjerknes feedback（ENSO）、重力分離（惑星分化）
3. **束が物質的・記録的に固定される** — 地質記録、磁気記録、堆積物
4. **「不発」の事例が存在する** — failed rift、貫入岩、エクスカーション

つまり、「閾値→正帰還→固定」のトリプレットが揃い、かつ「不発」の比較対象がある場合に対応が最も強い。

### 破綻条件

D05 内で5段階対応が弱い（confidence < 0.60）エントリに共通する条件:
1. **縁が明確な閾値を持たない** — 風化・土壌形成の連続的プロセス
2. **波→縁の区別が困難** — 漸進的変換では「どこまでが波でどこからが縁か」が決まらない
3. **渦がフィードバックとして記述しにくい** — スタッキングの再帰は正帰還ではない

### 比較原則

D05 の分析から導出される比較原則:
- **閾値の有無がカバレッジを決定する**: 明確な閾値を持つプロセスほど5段階対応が強い。これは5段階が「分岐点のある過程」のモデルであることを示唆する
- **不発事例の有無が信頼性を高める**: 「縁を超えなかった」事例が存在する場合、縁の同定がより確実になる
- **スケールは問わない**: 秒（地震）から億年（ウィルソンサイクル）まで同型構造が出現。ただしスケール間で「同じ構造が見える」ことと「同じメカニズムが働いている」ことは異なる `[SCALE_JUMP]`

## §C: 盲点

### Blind Spot 1: 「場の生成問題」の未解決

D05 内で「場はどこから来るか」が十分に扱われていない。惑星分化（D05-010）の場は「原始太陽系円盤」だが、その円盤自体はどの5段階の束として生成されたか。5段階モデルは「場を所与とする」傾向があり、場の起源についてはメタレベルの議論が必要。地球科学内では惑星分化が「最初の場を創った5段階」として位置づけられるが、その前段の場の生成は天文学（D06）の管轄に跨る。

### Blind Spot 2: 人間の関与する地球科学プロセスの不在

D05 の10エントリは全て「意識なき」プロセスである。しかし現代では人為的気候変動（第6の大量絶滅、人為的CO2による気候強制）が地球科学的プロセスに介入している。5段階モデルにおいて「意識主体が波を人工的に発生させる」場合の記述が D05 には含まれていない。これは意図的な除外（地球科学は自然過程を扱う）だが、盲点として認識しておくべき。人為的介入は「場の外部から波を注入する」行為であり、ミランコビッチの外因的波と構造的に類似するが、意図性を持つ点が異なる。

### Blind Spot 3: 「渦の終了条件」の未記述

D05 の各エントリで渦がどのように終了するか（渦→束への移行条件）が体系的に記述されていない。地震の渦は「エネルギー枯渇」で終わり、ENSO の渦は「遅延振動子による位相転換」で終わる。渦の終了メカニズムは束の性質を決定するはずだが、現在の evidence 記述では渦の開始（縁→渦）に比べて渦の終了（渦→束）の分析が手薄。

## §D: 保持論点の更新

### Phase 5-6 からの継承（更新あり）

1. **渦の多義性問題** — Phase 6 の Q2 を §A Pattern 5 で横断的に分析。4つの質的バリエーションを特定。「正帰還が典型、他も存在する」という暫定結論に到達。確定は保留。

2. **縁のない5段階の可能性** — Phase 6 の Q3 を §B「破綻条件」で分析。「閾値の有無がカバレッジを決定する」という原則を導出。D05-008 の CA 維持を推奨。

3. **不発の記録の位置づけ** — Phase 6 の Q4/H2 を §A Pattern 1 で横断的に分析。3つの独立事例から「不発は構造的構成要素」と暫定的に結論。ダイアグラムへの反映は pjdhiro 判断。

4. **100kyr問題の保持** — 変更なし。「縁の同定困難性の実証」として保持。

### 新規保持論点

5. **渦の終了条件問題（§C Blind Spot 3）**: 渦→束の移行がどのようなメカニズムで生じるかの体系的分析が不足。エネルギー枯渇、負のフィードバック、外因的遮断など、渦の終了パターンを分類すべき。

6. **場の生成問題（§C Blind Spot 1）**: 5段階が「場を所与とする」傾向に対して、場の起源をどう扱うか。惑星分化の事例は「場を創る5段階」の存在を示すが、それは「メタ5段階」なのか、同じ5段階の入れ子なのか。

## §E: 段階定義の精緻化提案

| 段階 | 現理解（CLAUDE.md コア定義参照） | D05からの更新提案 | 確信度 |
|------|------|------|------|
| **場（Field）** | 背景条件・前提状態。「舞台」 | 場には2種類ある可能性: (1)「構造がまだない原初の場」（惑星分化前の均質物質）、(2)「前のサイクルの束が創った場」（ウィルソンサイクルの安定期）。両者の区別は5段階が一回限りか循環かに対応する。 | 0.60 `[UNCERTAIN]` |
| **波（Wave）** | 揺らぎ・擾乱。場からの逸脱 | 波は内因的（ENSO: 系内のゆらぎ）にも外因的（ミランコビッチ: 軌道パラメータ）にもなりうる。また「波の振幅は束の振幅を決定しない」（100kyr問題）。波は「きっかけ」であって「原因」ではない。 | 0.75 |
| **縁（Edge）** | 関係の網として成立する分岐点。超えるか超えないかの未決定性。渦との接続 | D05 で縁の3条件（関係網・未決定性・渦接続）が7/10件で充足（🔴）。「不発」事例（failed rift、エクスカーション、貫入岩）の存在が縁の同定を強力に支持する。縁は「閾値」として最も強く機能するが、漸進的プロセス（風化）では曖昧化する。 | 0.85 |
| **渦（Vortex）** | 正帰還による自己増幅・自己維持 | D05 では4つの質的バリエーションが確認される。正帰還増幅（典型）、破壊的カスケード、非線形再編、スタッキング再帰。共通の最小要件は「自己組織化の過程」。「渦は方向を選ばない」（破壊にも創造にも作動する）。渦の終了条件の体系化が未着手。 | 0.70 |
| **束（Bundle）** | 安定したパターン・固定・記録 | D05 は束が最も強い領域。地質記録としての物質的固定が束の「記録性」を裏付ける。ただし束には質的バリエーションがある: 新規秩序（超大陸）、パターン（El Nino）、鏡像対称（磁場逆転）、漸進的到達（成熟土壌）。シーケンス層序の「不整合に挟まれた遺伝的パッケージ」が束の最も厳密な定義。「束は認識行為でもある」という側面（シーケンス層序の観察者位置依存性）。 | 0.80 |

### 5段階全体への D05 固有の貢献

1. **「意識なき創造」の最大規模の実証**: 惑星スケール（10^9年）から気象スケール（年）まで、意識主体なしに5段階が繰り返し出現する。30領域中で「時間スケールの幅」と「意識の不在」が最も際立つ。

2. **「場を創った5段階」と「場の上で回る5段階」の入れ子構造**: 惑星分化（一回限り）→プレートテクトニクス（循環）→地震・火山（イベント）の階層が、5段階の入れ子構造を単一の領域内で実証。

3. **「不発の記録」の体系的存在**: 3つの独立サブシステムで確認される「縁を超えなかった事例」が、5段階モデルに「不発ループ」を加える根拠を提供。

4. **スケールフリー性の劇的実証**: 10^10倍のスケール幅（地震の秒〜ウィルソンサイクルの億年）で同型構造が出現。5段階のフラクタル的性質の最も広いスケール範囲での確認。

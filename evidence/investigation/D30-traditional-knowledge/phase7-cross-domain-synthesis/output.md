## §A: 横断パターン

### P1: 束の動態性 — 伝統知は「束が生きている」領域

D30の最も顕著な横断パターンは、束が固定的到達点ではなく動的に更新される構造が複数エントリで確認されることである。

- TEK: 環境フィードバックにより束（制度・規範）が世代を超えて更新される
- 口承伝統: Ongのhomeostatic nature — 現在の文脈に適合するよう伝統が常に更新され、古い要素は忘却によって淘汰される
- 民俗芸能: 年次祭礼サイクルにより束（演目・役割・制度）が毎年再起動され、微細な変容を含みつつ伝承される
- 里山: 撹乱管理のサイクルにより景観秩序が動的に維持される

この「束の動態性」は、5段階モデルの束→場回帰の循環性を最も鮮明に示す領域横断パターンである。他のドメイン（科学理論の制度化、法制度の固定化など）では束が固定される傾向があるのに対し、伝統知では束が環境・身体・共同体との相互作用の中で「生きている」。

**5段階への含意**: 束は「完成」ではなく「維持的更新」の段階として理解すべきである。束→場回帰は例外的経路ではなく、束の本質的性質である可能性をD30は示唆する。

### P2: 縁の多形性 — 対面的・物質的・記号的の3形態

Phase 6で仮説として提示した「縁の3形態」が、D30のエントリ群で横断的に確認される。

| 縁の形態 | エントリ | 特徴 |
|----------|---------|------|
| **対面的縁** | LPP, 一座建立, 民俗芸能 | 人と人の相互作用。正統性・共在が条件 |
| **物質的縁** | 職人のわざ, 里山, TEK | 人と素材/環境の相互作用。抵抗・応答が条件 |
| **記号的縁** | 杜氏, 口承伝統 | 暗黙知と形式知の境界。翻訳・変換が条件 |

一つのエントリが複数の形態を含む場合もある（TEKは物質的縁と対面的縁の両方を含む）。守破離は対面的縁（師弟関係）と物質的縁（自己と型の身体的せめぎ合い）にまたがる。メーティスは記号的縁（テクネーとメーティスの対比）と物質的縁（地域環境との相互作用）を含む。

**5段階への含意**: 縁は単一の現象ではなく、媒介の性質（人・物質・記号）によって異なる形態をとる。5段階の縁の定義（「関係の中で意味が編まれる過程」）はこの多形性を包含するが、形態の違いが渦の性質にどう影響するかは未探索 `[SPECULATIVE]`。

### P3: 反復としての創造 — 線形モデルの超克

D30の全エントリに共通するのは、「創造」が一回的な新規生成ではなく、反復的サイクルの中での差異の蓄積として現れることである。

- 守破離: 型の反復の中から「自分の型」が生まれる
- 民俗芸能: 毎年の祭礼が「再現と創造の不可分」を示す
- 口承伝統: パフォーマンスの反復の中で伝統が更新される
- TEK: 季節的・世代的な実践の反復の中で知が蓄積される
- 杜氏: 醸造サイクルの反復の中で工程が改善される

この「反復の中にある創造」は、5段階を線形的段階モデルとして誤読する危険に対する最も強い補正材料である。5段階は「場→波→縁→渦→束」の一方向的進行ではなく、束→場の回帰を含む螺旋的循環であり、各サイクルで微細な差異が蓄積される。

**5段階への含意**: 5段階の「段階」は「ステージ（到達すべき水準）」ではなく「フェーズ（循環の中の位相）」として理解すべきである。D30はこの理解を最も強く支持する領域の一つ。

### P4: 場の前提性 — 場は段階か基盤か

メーティス（E007）の再読から浮上し、TEK、里山、LPPでも確認されるパターン。場は他の段階の「前に来る段階」ではなく、全段階の「前提条件」として機能している。

- メーティス: 場（地域固有の文脈）を無視した国家計画は失敗する → 場がなければ全段階が起動しない
- TEK: 場（社会-生態系）は全過程の基盤であり、一過性の段階ではない
- 里山: 場（社会-生態系の前提）は管理放棄されても消滅するのではなく、質的に変化する
- LPP: 場（共同体）は参加の全過程を通じて存在し続ける

**5段階への含意**: 場を「第一段階」として扱うモデル記述と、場を「全段階を支える基盤」として扱う理解の間に緊張がある。D30はこの緊張を鮮明に示す。ただし、場を基盤として扱うと5段階モデルは4段階+基盤のモデルになり、構造が変わる。この解釈変更は保持論点として維持する `[UNCERTAIN]`。

### P5: 身体性の不可欠性 — 伝統知は「身体を経由する知」

D30のエントリ群では、知の生成・伝承が身体を経由することが横断的に確認される。

- 守破離: 型は身体で覚える。「守の中のせめぎ合い」は身体的体験
- 職人のわざ: 「素材からの抵抗」は身体的に経験される。手と脳の対話
- 口承伝統: リズム・韻律・定型句は身体に刻まれる記憶装置
- 民俗芸能: テキスト非依存の身体的伝承
- 一座建立: 所作・沈黙を媒介とした身体的交流
- 生田の「わざ」: 「わかる」前に「できる」段階がある

これは5段階の各段階が「認知的」プロセスとしてのみ理解されることへの補正を与える。場は身体が置かれた環境、波は身体が感じる抵抗、縁は身体を通じた相互作用、渦は身体技能の統合、束は身体を通じて伝承される制度。

**5段階への含意**: 5段階の記述が「認知」に偏りすぎていないかをチェックする視点。D30は身体を経由する知の生成を多数含み、5段階が認知モデルではなく存在の生成モデルであることを身体的実践の側面から裏付ける。

## §B: 精度と限界

### 強い対応の条件

D30で5段階との対応が強い（Anchor級）エントリには以下の共通条件がある:

1. **原著がプロセスを段階的に記述している**: TEK（Berkes）と里山（Takeuchi）は、著者自身がプロセスを段階的に記述しており、5段階への対応が「後付けの切り出し」ではなく原著の構造に内在する
2. **全段階で具体的な対応物が同定できる**: 特定段階が抽象的・推論的にしか対応しないエントリ（メーティスの波、民俗芸能の縁など）は強度が下がる
3. **縁の対応が明確**: 縁が「関係の中で意味が編まれる過程」として具体的に記述できるエントリほど、全体の対応も強い。縁が5段階の判別基準として機能している

### 破綻条件

1. **原著の主題が「プロセス」ではなく「構造」である場合**: メーティス（Scott）は「メーティスの構造的特徴」を記述しており、「メーティスの生成過程」を記述していない。プロセスモデルとしての5段階は、構造記述との対応が弱くなる
2. **5段階対応が汎用的すぎる場合**: 民俗芸能の年次サイクルは「集団活動の年次サイクル」として広く当てはまる。ドメイン固有の構造が5段階対応に反映されていないと、対応は形式的になる
3. **波が場を破壊する方向に作用する場合**: Scottの「国家介入」は波ではなく場の破壊。波は場を豊かにする契機であるべきだが、過度な撹乱は場を破壊する。この閾値の記述が5段階にはない

### 比較原則

- **構造類似は因果関係を含意しない**: 伝統知のプロセスが5段階に「対応する」とは、同じ構造を持つことであり、5段階が伝統知を「説明する」ことではない
- **対応の精度はエントリごとに異なる**: Anchor（TEK、里山）とHigh-risk（メーティス、民俗芸能）では対応の精度が大きく異なり、D30全体を「強い対応」として一括することはできない
- **日本文化への偏りは精度の限界**: 10エントリ中6件が日本文化関連であり、伝統知の普遍的構造を主張するには地理的・文化的多様性が不足

## §C: 盲点

### C1: 「伝承の断絶」の構造が未記述

D30は伝統知の「成功的な伝承」に焦点を当てており、「伝承の断絶」「知の消失」の構造が十分に記述されていない。里山の管理放棄、民俗芸能の後継者不足、口承伝統の文字文化への移行など、束→場の循環が停止する条件が5段階モデルの中でどう記述されるべきかは盲点である。

束の崩壊は「波の停止」（里山の管理放棄）として記述できるが、波の停止自体が5段階モデルの中でどのように位置づけられるかは不明瞭。「循環の停止」は5段階の射程内か射程外か。

### C2: 権力関係・非対称性の構造的位置づけ

LPPの「正統性」、TEKの「FPIC/ABS」、メーティスの「国家vs地域」は、いずれも権力関係・非対称性を含む。しかし5段階モデルは権力関係の記述を明示的に含んでいない。縁の成立に「権力的条件」が必要であること（LPPの正統的アクセス）は重要な洞察だが、5段階モデルの中で権力がどの段階に位置するかは未記述。

これはD30だけの問題ではなく、5段階モデル全体の盲点である可能性がある。ただし、権力関係の記述を5段階に含めるべきかどうかは、モデルの射程の問題であり、必ずしも欠陥ではない。

### C3: テクノロジーの介入による伝統知の変容

杜氏のデータ化は一事例だが、より広くデジタル技術・AIが伝統知の伝承に介入する現在的状況が未カバー。口承伝統のデジタルアーカイブ化、民俗芸能の映像記録、TEKのGIS統合など、「記号的縁」の新形態がD30の射程に含まれるべきかどうかは検討の余地がある。ただし、これは5段階との構造比較の範囲を超える可能性がある `[UNCERTAIN]`。

## §E: 段階定義の精緻化提案

### 場（未分化の前提空間）

| 項目 | 内容 |
|------|------|
| **現理解** | 未分化の可能性が満ちた状態。差異が生じる前の前提空間 |
| **D30からの更新** | 場は「最初の段階」ではなく「全段階を支える基盤」として機能している可能性がある。TEK（社会-生態系）、LPP（共同体）、里山（景観基盤）はいずれも場が全過程を通じて存在し続ける。場は通過する段階ではなく、持続する条件である `[UNCERTAIN]` |
| **確信度** | 中。複数エントリで確認されるが、モデル構造の変更を伴うため慎重な検討が必要 |

### 波（差異の立ち上がり）

| 項目 | 内容 |
|------|------|
| **現理解** | 予想と現実のズレが意識される。差異が顕在化する |
| **D30からの更新** | 波には強度のスペクトルがある。里山の「管理された撹乱」は意図的に波を生成する行為であり、TEKの「ecological surprise」は予期せぬ波。職人の「素材からの抵抗」は微細な波。波の停止（撹乱の欠如）が創造的秩序の喪失につながるという逆説がD30の重要な貢献 |
| **確信度** | 高。「波の不可欠性」は里山の管理放棄事例で明確に裏付けられる |

### 縁（関係の中で意味が編まれる）

| 項目 | 内容 |
|------|------|
| **現理解** | 複数要素が境界で影響し合い、関係の中で意味が編まれる過程 |
| **D30からの更新** | 縁には少なくとも3つの形態がある: 対面的（人-人）、物質的（人-素材/環境）、記号的（暗黙知-形式知）。成立条件として「応答性」が最小要件であり、「双方向性」（両者に主体性がある）は十分条件だが必要条件ではない可能性 `[SPECULATIVE]`。LPPの「正統性」は、縁の成立に社会的・権限的前提が含まれることを示す |
| **確信度** | 中。3形態の識別は複数エントリで支持されるが、この分類が5段階モデルの公式定義に含まれるべきかは別問題 |

### 渦（まとまりとして立ち上がる）

| 項目 | 内容 |
|------|------|
| **現理解** | 複数の要素がひとつのまとまりとして安定的に立ち上がる |
| **D30からの更新** | 生田の「わざ」概念から、渦は「理解してまとまる」のではなく「身体がまとまってから理解がついてくる」順序で成立する可能性がある。口承伝統のOngの「累加的」思考様式は、渦が分析的統合ではなく累積的まとまりとして成立する事例 `[SPECULATIVE]`。守破離の「破」は渦の不安定段階として位置づけられる可能性 |
| **確信度** | 低。身体性の指摘は複数エントリで支持されるが、渦の定義変更に至るほどの根拠はない |

### 束（構造として残り更新される）

| 項目 | 内容 |
|------|------|
| **現理解** | 生成された秩序が構造として残り、次の場の一部となる |
| **D30からの更新** | D30は束の「動態性」を最も強く示す領域。TEKの環境フィードバック、口承伝統のhomeostatic nature、民俗芸能の年次サイクルは、束が「完成」ではなく「維持的更新」の段階であることを示す。束の動態性は固定性とスペクトル上に位置し、動態性が高いほど循環が活性的、固定性が高いほど循環停滞のリスクがある。束が外部装置（文字）ではなく身体（リズム・韻律・定型句）に刻まれる形態が存在する |
| **確信度** | 高。束の動態性は複数エントリで明確に支持される。D30はこの更新の最重要根拠領域 |

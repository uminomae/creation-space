# Phase 7: cross-domain-synthesis（横断統合）— D07 工学・情報科学

## §A: 横断パターン

### パターン1: フィードバック循環の普遍性と変種

D07の10エントリ中6件がmechanism_type T2（フィードバック循環型）を含む。しかし「誤差→帰還→修正」の基本構造は同一でも、各エントリが扱う「誤差」の性質は根本的に異なる。

| エントリ | 誤差の性質 | フィードバックの方向 |
|---------|----------|-------------------|
| D07-001 フィードバック制御 | 数学的・連続的 e(t) | 外界（プラント）を変える |
| D07-003 TCP | 離散的イベント（パケット損失） | 送信率を変える |
| D07-004 深層学習 | 勾配（連続的・高次元） | 内部表現を変える |
| D07-007 強化学習 | TD error（確率的） | 行動規則を変える |
| D07-008 GA | 適応度差（集団統計） | 集団組成を変える |
| D07-002 PDCA | 定性的・主観的（品質指標） | 組織プロセスを変える |

5段階モデルとの対応: この変種の分布は、5段階の「波」（偏差・誤差）が単一概念ではなく、「予測と現実のずれ」のスペクトルを形成することを示す。数学的に厳密なe(t)から、主観的な品質指標まで、「ずれを検出し帰還させる」構造が5段階の「波→縁→渦」の本質。

### パターン2: 場の構造化度が創造の経路を決定する

D07の複数エントリが「場」の構造化度と5段階の展開経路の関係を示す。

- **高構造化の場**: D07-005（情報理論）——通信路モデルを定義した瞬間にShannon容量（束）が数学的に確定。D07-006（圧縮センシング）——スパース性仮定が強ければ少ない観測で復元可能
- **低構造化の場**: D07-007（強化学習）——MDP定義時点では最適方策は不明。膨大な探索（渦）が必要。D07-008（GA）——No Free Lunch定理が「万能の場は存在しない」と証明

5段階モデルとの対応: 場の構造化度が高いほど渦の必要性が低下し、束に直接到達できる。場の構造化度が低いほど渦（探索・反復・試行錯誤）の必要性が増す。これは5段階における場と渦のトレードオフ関係を示唆する。

### パターン3: 設計された5段階 vs 自然に生じる5段階

D07は「設計者の意図が介在する創造」を扱う唯一のドメイン群であり、D06（天文学=意識なき創造）と対極をなす。

- **自然を模倣した設計**: D07-008（GA）はD04（自然選択）の工学的再実装。「盲目のプロセスを目の見える設計者が利用する」
- **独立に到達した構造**: D07-001（フィードバック制御）は生物の恒常性（D04）とは独立に、工学的必要性から発明された。Watt調速機(1788)は進化論(1859)より前
- **自然を発見した理論**: D07-005（情報理論）のShannon容量は自然の構造的限界を数学的に「発見」したもの

5段階モデルとの対応: D07は「5段階が有用な設計原理である」ことの証拠類型を提供する。これはD01-D06の「5段階が自然現象に存在する」証拠とは性質が異なり、独立した証拠として扱うべき。両者が合流する点——「自然の構造と有用な設計原理が同一である」——が5段階モデルの核心的主張となる。

### パターン4: 束の多様性——D07が示す束の分類学

D07の各エントリが示す「束」は単一概念ではなく、複数の性質に分類できる。

| 束の型 | エントリ | 特徴 |
|--------|---------|------|
| **収束状態型** | D07-001（安定点）、D07-004（学習済み表現）、D07-007（最適方策） | プロセスが到達する安定パターン |
| **限界値型** | D07-005（Shannon容量） | 構造的に先在する、超えられない上限 |
| **安全性型** | D07-010（安全な通信路） | 攻撃者に対する耐性の確立 |
| **公平性型** | D07-003（max-min公平性） | 分散的に達成される資源配分 |
| **構造改善型** | D07-009（改善されたコード構造） | 質的に向上した構造 |
| **解集合型** | D07-008（パレートフロント） | 複数の等価な束が面を形成 |

5段階モデルとの対応: 束は「安定パターン」という一語では捉えきれない多面的概念。D07は束の分類学の必要性を示す。

### パターン5: 5段階の入れ子構造

D07-003（TCP）は局所的5段階（各送信者のAIMDループ）が集合的に大域的束（公平帯域分配）を生む構造を持つ。D07-004（深層学習）は層ごとの局所的勾配更新（局所的渦）がネットワーク全体の表現学習（大域的束）を生む。

5段階モデルとの対応: 5段階が階層的に入れ子になり、下位レベルの束が上位レベルの場を構成する。工学システムの多くが「モジュール→サブシステム→システム」の階層構造を持つことは、5段階の入れ子構造が設計原理として有用であることの証拠。

## §B: 精度と限界

### 強い対応の条件

D07において5段階対応が強いエントリ（Anchor: D07-001, D07-004, D07-007）に共通する条件:

1. **誤差の数学的定式化**: e(t)、勾配、TD errorのいずれも数式で定義可能
2. **フィードバックループの明示的存在**: 閉ループ構造が設計仕様として存在
3. **収束の定量的証明**: 安定性条件、収束定理が数学的に証明されている
4. **全5段階に対応物が存在**: 場・波・縁・渦・束のいずれも空白がない

### 破綻条件

1. **渦の不在**: D07-005（非反復復号）、D07-006（閉形式解）では渦が存在しない。渦なしでも5段階対応を主張できるかは未決
2. **縁の一回性**: D07-010（認証ハンドシェイク）の縁は一回性であり、連続的フィードバックの縁とは性格が異なる
3. **束の順序逆転**: D07-005のShannon容量は場の定義と同時に確定し、通常の「場→束」の過程的順序に反する
4. **設計者バイアス**: D07-008（GA）のように設計者がD04を参照してシステムを設計した場合、5段階対応は循環的

### 比較原則

- D07の証拠は「5段階の自然性」ではなく「5段階の設計原理としての有用性」の証拠として扱う
- 数学的裏付けのある対応（D07-001, D07-004, D07-005, D07-007）と実務的経験知に基づく対応（D07-002, D07-009）を区別する
- フィードバック型（T2）以外のmechanism_type（T1, T3, T4, T5）を持つエントリの独自性を積極的に評価する

## §C: 盲点

### 盲点1: フィードバックを持たない工学系の不在

D07の10エントリはすべて何らかの形で「誤差検出→修正」のフィードバック構造を含む。しかし工学には「一発構築」型のシステムも存在する——橋梁設計、ASIC設計、ロケット発射シーケンス等。これらの「フィードバックなき設計」に5段階がどう適用されるか（あるいは適用できないか）はD07の盲点。フィードバック偏重の選択バイアスが生じている可能性がある。

5段階モデルへの含意: 「渦」を必須とする5段階はフィードバック型にしか適用できない——あるいは一発構築にも「設計者の内部的な渦（思考の反復）」が存在するのか。設計プロセスそのもの（ブレインストーミング→プロトタイプ→テスト→改良）が渦であり、成果物としてのシステムには渦がない、という区別が必要かもしれない。

### 盲点2: 失敗事例の不在

D07のエントリはすべて「成功した」工学的手法を扱う。制御理論は成功、深層学習は成功、TCPは成功。しかし5段階の理解を深めるには「5段階的構造を持ちながら失敗した工学的試み」や「5段階的構造を持たないのに成功した工学的試み」の検討が必要。成功バイアスが生じている。

5段階モデルへの含意: 5段階が「成功の条件」なのか「成功の記述」なのかを区別するには、反例の検討が不可欠。

### 盲点3: 「誤差」概念の文化的・歴史的文脈

D07は西洋工学の伝統（制御理論、情報理論、コンピュータサイエンス）に偏っている。日本の品質管理（TQM/カイゼン）はPDCAとして記載されているが、他の工学的伝統——例えば中国の土木工学、イスラム世界の水利工学——における「誤差」の扱い方は未検討。5段階の普遍性を主張するなら文化横断的な検討が必要。ただしこれは本調査のスコープを超える可能性がある。

## §E: 段階定義の精緻化提案

D07（工学・情報科学）の調査から得られた各段階の理解の更新。

### 場（Ba）

| 項目 | 内容 |
|------|------|
| **現理解** | 初期条件・背景・可能性の空間。創造の「舞台」 |
| **D07からの更新** | 場は中立的な舞台ではなく、束の到達可能性を能動的に規定する。D07-006（圧縮センシング: スパース性仮定が復元を可能にする）とD07-008（GA: No Free Lunch定理が「万能の場は存在しない」と証明）が示す。場の構造化度が渦の必要性を決定する（高構造化→渦不要→Shannon容量型の束確定、低構造化→渦必須→探索型の束到達）。また、場は必ずしも観測可能でなくてよい（D07-003: TCPの見えない場） |
| **確信度** | 高——複数の数学的証明（RIP条件、NFL定理）が裏付ける |

### 波（Nami）

| 項目 | 内容 |
|------|------|
| **現理解** | 予測と現実のずれ、偏差の顕在化。場の変動や外乱 |
| **D07からの更新** | 波は「誤差」のスペクトルを形成する: 数学的誤差（e(t), 勾配, TD error）→統計的誤差（パケット損失, ノイズ）→構造的歪み（技術的負債）→未知の可能性（探索-活用）。最も広い解釈では「まだ経験していない可能性への気づき」（D07-007）も波に含まれる。波は場の情報を運ぶインターフェースとしても機能する（D07-003: 損失を通じて見えない場を推測） |
| **確信度** | 中——スペクトルの端（「未知の可能性」）まで波に含めてよいかは [UNCERTAIN] |

### 縁（En）

| 項目 | 内容 |
|------|------|
| **現理解** | 関係網の結節点、未決定性、渦への接続。分岐点 |
| **D07からの更新** | 縁の3条件（関係網・未決定性・渦接続）はD07-001（フィードバック制御）で最も精密に満たされる（唯一の🔴エントリ）。他のエントリでは「分岐」よりも「閾値検出」（D07-003）、「分析」（D07-002）、「連続的判断」（D07-009）、「一回性ハンドシェイク」（D07-010）として現れ、縁の多様な現れ方を示す。縁は数学的構造を介して構築可能（D07-010: Diffie-Hellman鍵交換=事前の秘密なしに信頼を構築） |
| **確信度** | 中——縁フラグ🔴がD07-001のみであり、他エントリでの縁の記述精度にばらつきが大きい |

### 渦（Uzu）

| 項目 | 内容 |
|------|------|
| **現理解** | 自己維持的な反復ループ。フィードバックによる自律的修正 |
| **D07からの更新** | 渦はD07の多くのエントリで最も明確な段階（PIDループ、AIMDサイクル、SGDループ、方策改善、世代ループ）だが、渦が不在の系（D07-005: 非反復復号、D07-006: 閉形式解）も存在する。場の構造化度と渦の必要性は逆相関する可能性がある。渦の安定性は保証されず（D07-001: 不適切な帰還は発振を引き起こす）、渦の「適切な量」に閾値がある |
| **確信度** | 高——フィードバック型エントリでの対応は安定的。渦不在の系の扱いが残課題 |

### 束（Taba）

| 項目 | 内容 |
|------|------|
| **現理解** | 安定パターン。創造の「到達点」 |
| **D07からの更新** | 束は単一概念ではなく少なくとも6つの型を持つ: (1) 収束状態型（安定点への到達）、(2) 限界値型（Shannon容量=構造的先在）、(3) 安全性型（攻撃者耐性の確立）、(4) 公平性型（分散的資源配分）、(5) 構造改善型（質的向上）、(6) 解集合型（パレートフロント）。束は過程の終点だけでなく、構造的に先在する限界（D07-005）や設計者が定義する目標（D07-001）としても存在する。束は外在的（外界の状態: D07-001）にも内在的（内部表現: D07-004）にもなりうる |
| **確信度** | 中——6つの型の分類は暫定的。型間の関係（包含? 独立? ）は未確定 |

### EV-PM-001: 医薬品開発パイプライン

| 軸 | 評価 |

| 正確な対応 | 段階的絞込み（場→束）の制度的構造は堅固。規制科学が段階移行の基準として機能する点は「波→縁→渦」の制度化として正確 |

### EV-PM-002: ADME-PK/PDと用量最適化

| 軸 | 評価 |
|----|------|
| 正確な対応 | PID制御構造との対応は D11 で最も定量的に堅固。投与量＝操作量、血中濃度＝制御量、治療域＝設定値。5段階の各段階が数式で表現可能な点は稀有 |
| 怪しい対応 | 「フラクタル的に現れる」という主張。分子レベル（結合定数）と個体レベル（血中濃度曲線）で「同じフィードバック構造」が現れるとするが、スケール間で構造が保存される根拠が不十分。類似パターンの反復とフラクタルは区別が必要 |
| 破綻箇所 | 「制御」モデルと「創造」の接続が解釈的と自認しているが、ここが最大の構造的緊張。PK/PDは「最適化」であり「創造」ではない。5段階モデルが「創造の段階」であるならば、PK/PDは「創造されたものの運用・調整」に位置する |
| 見えていなかった構造 | CYP多型による個体差は「場が個人ごとに異なる」ことを意味する。これは5段階モデルにおいて「場の個別性」が以降の全段階を規定するという、場の決定力の強さを示す事例 |

### EV-PM-003: 抗菌薬耐性進化

| 軸 | 評価 |
|----|------|
| 正確な対応 | 束→場循環が最も明示的。新薬（束）→耐性菌出現（場の変容）→次サイクルという循環は、5段階が一回で完結せず螺旋的に反復する構造を直接示す |
| 怪しい対応 | 「人為的介入が進化を駆動」は正確だが、これを「意識的介入が無意識的帰結を生む」と一般化する記述はやや拡大解釈。抗菌薬使用は「意識的介入」だが、耐性獲得は「無意識的帰結」というよりも「予測可能だが制御困難な帰結」 |
| 破綻箇所 | 特段の破綻なし。D04進化生物学との差分（「人為的加速版」）も明確 |
| 見えていなかった構造 | 水平遺伝子伝播（プラスミド等）は「縁の物質的媒体」。遺伝子が種間を移動する物理的プロセスが、異なる「場」同士を接続する。これは縁が「関係」だけでなく「媒体」としても機能する事例。D03化学の触媒との構造的類似 |

### EV-PM-004: 経口徐放性製剤の設計・評価

| 軸 | 評価 |
|----|------|
| 正確な対応 | Higuchi式（Q=K√t）による波の定量化は堅実。「手続き的構造類似」という自己認識も誠実で適切 |
| 怪しい対応 | 縁の対応「試験条件×製剤特性×生体条件の相互作用」は相互作用ではあるが、設計者が条件を制御可能な範囲が大きい。「出会い」の未決定性が薄い |
| 破綻箇所 | 渦の対応「in vitro↔in vivoの反復調整」は「反復」ではあるが「自己組織化」ではない。設計者が意図的に反復しており、渦の本質（自己増幅的なフィードバック）とは質が異なる |
| 見えていなかった構造 | in vivo個体差が「設計が予測しきれない縁」を持ち込むという記述は重要。設計された系に「制御不能な変数」が侵入する構造は、5段階モデルにおける「縁の不可避性」を示す。完全に設計された製剤でも、患者の体内環境という「場」が縁の質を変える |

### EV-PM-005: 漢方処方設計原理（君臣佐使と多成分ネットワーク）

| 軸 | 評価 |
|----|------|
| 正確な対応 | 「配伍＝縁の制度化」は D11 で最も直接的な縁の対応。君臣佐使の4層構造が「関係の質に名前をつけて設計原理にした」点は、5段階モデルの「縁」概念を薬学が独自に言語化した事例として堅固 |
| 怪しい対応 | 場（「証」）の対応がやや抽象的。「証」は東洋医学固有の概念であり、5段階の「場」（可能性の空間）との対応は解釈に依存する。「証」は状態診断であり、「可能性の空間」とは性質が異なる |
| 破綻箇所 | 渦（「多成分—多標的—多経路の同時作用」）の対応が弱い。多成分の同時作用は「複雑性」であって「自己組織的渦」とは異なる。渦には「自己増幅」の要素が必要だが、多成分同時作用にその構造は明確でない |
| 見えていなかった構造 | 君臣佐使は「関係の質にグラデーションをつける」設計原理。主（君）→補助（臣）→調整（佐）→調和（使）の階層は、縁の中にも「強度の差」があることを示す。これは5段階モデルにおける「縁の内部構造」の精緻化に貢献しうる |

### EV-PM-006: QbDによる製剤開発・品質保証（ICH Q8/Q9/Q10）

| 軸 | 評価 |
|----|------|

### EV-PM-007: プロドラッグ設計

| 軸 | 評価 |
|----|------|
| 正確な対応 | 「不活性→縁（酵素との出会い）→活性化」で縁が「起動スイッチ」として機能する記述は独自。縁の機能の多様性（選別/制約/起動）を示す事例として価値あり |
| 怪しい対応 | PM-002のサブセット問題が依然として残る。「体内酵素との出会い」はPK/PDの一部でもある。独立エントリとしての価値は「縁の起動スイッチ機能」に全面的に依存 |

| 見えていなかった構造 | プロドラッグは「縁を待つ設計」。体内酵素に出会うまで不活性であり、「設計者が縁の発生を信頼して待つ」構造。これは D3（Withhold）との構造的類似が潜在する。「反応せず保持し、適切な出会いで起動する」 |

### EV-PM-008: ファーマコゲノミクス / 個別化医療

| 軸 | 評価 |
|----|------|
| 正確な対応 | CYP多型が「縁の構造を個別化する」物質的基盤であるという記述は堅固。「ゲノム型判明まで代謝パターンは未決定」= 縁の未決定性が遺伝情報として物質的に裏付けられる点は重要 |

## §B: 再読から浮上した問い

### Q1: 「制御」と「創造」の境界はどこにあるか

PM-002（PK/PD）, PM-004（徐放性製剤）, PM-006（QbD）は「制御・最適化・品質保証」のプロセスであり、「創造」のプロセスとは質が異なる可能性がある。5段階モデルが「創造の段階」を記述しているならば、これらのエントリは「創造されたものの運用」を記述しているのではないか。5段階モデルは「制御」にも「創造」にも適用可能な「プロセスの一般構造」である可能性。

### Q2: 「縁のスペクトラム」は5段階モデルの精緻化に貢献するか

D11固有の発見「縁のスペクトラム」（精密設計→計画的起動→個別化→意図せざる出会い）は、「縁」の定義を精緻化する素材となりうる。現在の定義（D2「予想と現実の誤差を、意識が欠けとして捉えた主観的経験」に基づく関係的出会い）に「制御可能性のグラデーション」を加えるべきか。

### Q3: 「場の個別性」は5段階モデルでどう位置づけるか

PM-002/PM-008が示す「CYP多型による場の個別性」は、5段階モデルにおいて「場は普遍的か個別的か」という問いを提起する。物理学（D02）では場は普遍的法則に従うが、薬学では場が個人ごとに異なる。この差異は5段階モデルの適用範囲に関わる。

### Q4: プロドラッグ設計とWithhold（D3）の構造的類似は本質的か

PM-007で見出した「不活性→縁の出会い→活性化」構造と、D3（Withhold: 反射的に処理せず保持する機能）との類似は表面的な比喩か、それとも構造的に同型か。「適切な出会いまで待つ」という構造が異なるスケールで反復するならば、フラクタル構造の証拠となる。ただし「不活性」と「保持」は異なる操作であり、安易な同一視は避けるべき [SPECULATIVE]。

### Q5: 「全件Accept」の一様性は何を意味するか

D11の10件全てがAcceptであることは、薬学が5段階モデルと高い構造類似を持つ証拠か、それとも分析者のバイアス（見たいものを見ている）か。比較対象として「構造類似が低い」領域との対比が必要。PM-007/PM-010の独立性問題を考慮すると、実質的には8件程度が堅実なエントリかもしれない。

## §C: 仮説と統合的知見

### H1: 薬学は「プロセスの制度化」が最も進んだ領域であり、5段階との対応はプロセス構造の一般性を反映している [SPECULATIVE]

QbD（PM-006）、開発パイプライン（PM-001）、GCPガイドライン等、薬学は「プロセスを制度化する」ことに長けた領域。5段階との対応が強いのは、5段階モデル自体が「プロセスの一般構造」を記述しているためかもしれない。これが正しければ、5段階モデルの適用範囲は「創造」に限定されず、「制度化されたプロセス一般」に拡張される。この仮説は5段階モデルの射程を広げるが、同時に「創造」固有の説明力を薄める可能性がある。

### H2: 「縁のスペクトラム」はD11固有の発見であり、縁の概念の精緻化に直接貢献する

PM-010→PM-007→PM-002/008→PM-009の「縁の制御可能性グラデーション」は、他領域では見出しにくい。薬学が「関係の制度化」に長けているからこそ、縁の質的差異を体系的に示せる。この知見は Phase 7 で他領域との比較に用いる価値がある。

### H3: 「束→場循環」は薬学において制度的に観察可能な形で現れる

PM-003（耐性進化）とPM-001（サリドマイド事件→制度改革）は、束→場循環が「歴史的記録として追跡可能」な形で現れる。多くの領域では束→場循環は推測的だが、薬学では新薬承認→耐性出現→次世代薬開発というサイクルが文献で追跡できる。

# Phase 7: cross-domain-synthesis（横断統合） — D17 言語学

---

## §A: 横断パターン

### Pattern-1: 波→縁の移行における二重メカニズム（統計的蓄積 vs 情報制約）

**関連エントリ**: 006 構文創発、010 ILM、002 音変化

D17言語学の最も重要な横断パターンは、波→縁の移行を駆動する二つの異なるメカニズムの並存である。

**(1) 統計的蓄積型（006 構文創発）**: 使用事例の反復が頻度の偏りを生み、偏りが閾値を超えるとチャンク化（処理単位の形成）が起きる。チャンク化がカテゴリ化を駆動し、カテゴリ間の関係が「縁」として編成される。駆動力は「十分な反復による統計的パターンの顕在化」。

**(2) 情報制約型（010 ILM）**: 世代間伝達のボトルネック——全入力を伝達できないという制約——が、組合せ的で体系的な構造への圧力を生む。駆動力は「不完全さからの構造創発」。

この二重メカニズムは相補的に作動する。十分な入力がある場合は(1)が、入力が不十分な場合は(2)が主に波→縁の移行を駆動する。002音変化のS字曲線（拡散パターン）は、(1)の時間的展開を社会的スケールで可視化したものと読める。

5段階モデルへの示唆: 波→縁の移行は、5段階モデルの記述が最も弱い部分の一つ。D17は「なぜ差異が関係になるのか」に対して、「反復が偏りを作るから」と「伝達の不完全性が構造を強制するから」という二つの具体的回答を提供する。

### Pattern-2: 「意図なき創造」の連続体

**関連エントリ**: 005 NSL、010 ILM、007 語用論、002 音変化、001 文法化

D17のエントリ群は、H-4（意図なき創造）を二値的なものから連続体へと精緻化する材料を提供する。

| 意図の位置 | エントリ | メカニズム |
|-----------|---------|-----------|
| 完全に意図なき | 005 NSL、010 ILM | 個々の話者に「文法を作る」意図はないが、コホート間伝達で文法が創発 |
| 無意識的→慣習化 | 002 音変化（下から）、001 文法化 | 話者が気づかない変異が社会的に拡散し、新しい規範として固定 |
| 意図的逸脱→非意図的慣習化 | 007 語用論 | 格率の意図的違反（皮肉、婉曲等）が繰り返されて含意が慣習化 |
| 意図的採用→非意図的帰結 | 002 音変化（上から） | 威信形式の意識的採用が過修正を引き起こし、意図されなかった変化を生む |

5段階モデルへの示唆: 5段階は「構造の生成プロセス」を記述するものであり、意図の有無はプロセスの条件であって段階構造を変えない。ただし意図の程度が縁の編成方法（自然発生的 vs 制度的）に影響する可能性がある。H-4は「意図なき創造が存在する」ではなく「構造創発は意図を必要条件としない」と再定義できるかもしれない。

### Pattern-3: 「場の条件性」——場は無条件に開かれていない

**関連エントリ**: 004 臨界期、003 クレオール、005 NSL

5段階モデルの「場」は暗黙に「自然に存在する未分化な状態」を想定しているが、D17は場の形成・制約条件の多様性を示す。

| 条件の型 | エントリ | 内容 |
|---------|---------|------|
| 時間的条件 | 004 臨界期 | 場が開く時間窓に生物学的制約がある |
| 社会的条件 | 003 クレオール | 権力関係（植民地化）が場を強制的に作る |
| 制度的条件 | 005 NSL | ろう学校という制度が集合の場を提供する |

5段階モデルへの示唆: 場の定義に「条件」の次元を加えるべきか。場は「未分化な素材が存在する状態」であると同時に、「その状態が成立するための条件」を持つ。条件が場の「質」を決定し、以降の段階展開（波の方向、縁の型）に影響する。ただし場の定義を拡張しすぎると「場」概念の識別力が低下するリスクがある。[UNCERTAIN]

### Pattern-4: 縁の型の多様性——D17の最大の貢献

**関連エントリ**: 全10エントリ

D17は10エントリで10種類の縁の型を提示する。これは他の単一ドメインでは見られない多様性であり、「縁」が単一のメカニズムではなく多様な実装を持つことを最も明確に示すドメインである。

| 縁の型 | エントリ | メカニズム |
|--------|---------|-----------|
| 制度型 | 001 文法化 | 構文環境での再分析 |
| 伝播型 | 002 音変化 | 社会的ネットワークでの拡散 |
| 界面型 | 003 クレオール | 異なる体系の接触面 |
| 閾値型 | 004 臨界期 | 生物学的成熟による制約 |
| 分化型 | 005 NSL | 機能の分化と装置割当 |
| 認知型 | 006 構文創発 | チャンク化・カテゴリ化・類推 |
| 推論型 | 007 語用論 | 格率違反→推論による含意回復 |
| 制約型 | 008 言語相対性 | 既存の束による次サイクルの制約 |
| 競合型 | 009 OT | 制約間の優先順位決定 |
| 欠損型 | 010 ILM | 伝達の不完全性が構造を強制 |

5段階モデルへの示唆: 「縁の分類学」の構築にD17が最も貢献する。縁の型は大きく「内生的」（認知型、推論型）と「外生的」（伝播型、界面型、制度型）に分けられ、さらに「駆動力の方向」（蓄積型 vs 制約型）で分類できる可能性がある。

### Pattern-5: フラクタル性——個人獲得と歴史変化の同型性

**関連エントリ**: 006 構文創発、001 文法化、010 ILM、002 音変化

D17は個人獲得（微視的スケール）と歴史変化（巨視的スケール）が同型のパターンを示す事例を複数提供する。

| スケール | 個人獲得 | 歴史変化 | 共通パターン |
|---------|---------|---------|-------------|
| 構文 | 語彙特定→抽象構文（006） | 構文化 constructionalization（006） | 使用→パターン→構造 |
| 文法 | 語用論的推論の学習（007） | 文法化の駆動力（001） | 推論→慣習化 |
| 体系 | ILMの個体学習（010） | ILMの世代間伝達（010） | ボトルネック→組合せ構造 |

5段階モデルへの示唆: フラクタル性の主張は魅力的だが、「パターンの類似」と「メカニズムの同一性」を区別すべき。個人獲得と歴史変化が同じパターンを示すとしても、背景メカニズム（神経レベルの統計学習 vs 社会レベルの文化伝達）は異なる可能性がある。[UNCERTAIN]

## §B: 精度と限界

### 強い対応の条件

D17で5段階との対応が強いエントリ（005 NSL, 006 構文創発, 010 ILM）には以下の共通特徴がある:
1. **プロセスの全段階が観察可能**: 場→束の全移行が実証的に追跡できる
2. **創発のメカニズムが記述されている**: 単なる段階の列挙ではなく、なぜ次の段階に移行するかの因果連鎖がある
3. **意図なき（または半意図的な）構造生成**: 参加者の意図を超えた構造が出現する
4. **複数スケールでの観察**: 個人・共同体・歴史の少なくとも2つのスケールで対応が確認できる

### 破綻条件

5段階との対応が弱い（CA判定の）エントリ（003 クレオール, 008 言語相対性）には以下の特徴がある:
1. **プロセスの一部のみに対応**: 全5段階ではなく1-2段階との対応のみ
2. **状態記述（プロセス記述でない）**: 008は「束→場の制約」という静的関係のみ
3. **事例間多様性が高い**: 003は事例ごとの固有条件が大きく、単一パターンの抽出が困難
4. **理論的基盤の不安定性**: 003のBickerton仮説の後退、008の強い仮説の放棄

### 比較原則

D17言語学と5段階モデルの構造比較において守るべき原則:
1. 言語学理論を5段階に「翻訳」するのではなく、構造的類似を「指し示す」に留める
2. usage-basedの採用は前提の共有であり証拠ではないことを明示する
3. 「フラクタル性」の主張は「パターンの類似」として留め、「メカニズムの同一性」は主張しない
4. CAエントリの安易な解消をしない。弱い対応は正直に「弱い」と記述する

## §C: 盲点

### Blind-1: 言語の「死」と「消滅」——束の解体プロセスの不在

D17の10エントリは全て「構造の生成」を記述しており、「構造の解体」（言語の衰退・消滅）を扱うエントリがない。5段階モデルは場→束の方向（生成）を中心に記述しているが、束→解体の方向（少数言語の消滅、文法カテゴリの喪失等）も同様に5段階の逆向きプロセスとして記述できるかもしれない。あるいは、言語の「死」は5段階の螺旋的回帰（束→場'）の特殊ケース——場'に回帰せず完全に消滅する場合——として位置づけられるかもしれない。この盲点は、5段階モデルが「生成バイアス」を持つことの反映でもある。

### Blind-2: 書記言語と標準化——意図的な「束の形成」

D17のエントリは主に音声言語（または手話言語）の自然な変化を扱っている。書記言語の標準化（正書法、文法書、辞書の制定）は、意図的・制度的な「束の形成」プロセスであり、H-4（意図なき創造）の対極に位置する。「意図的に作られた束」と「意図なく創発した束」の質的差異は、5段階モデルにとって重要な問いを提起する。言語アカデミー（Academie francaise等）による規範化と、自然な言語変化の関係は、5段階の「束」が意図的に設計可能かという問いに直結する。

### Blind-3: 多言語使用と言語接触——複数の5段階プロセスの干渉

003クレオールは言語接触を扱うが、日常的な多言語使用（コードスイッチング、借用、言語シフト等）における複数言語の5段階プロセスの「干渉」は未カバー。個人の内部で複数の言語体系が共存し相互に影響する状況は、5段階の「束」が複数並行して存在し干渉するケースの言語学的具体例だが、現在のエントリ構成では扱えていない。

## §D: 保持論点の更新

### PT-1（更新）: 波→縁移行の二重メカニズム

Phase 6のPT-1を横断パターンPattern-1で精緻化。「統計的蓄積型」と「情報制約型」の二重メカニズムは、他のドメイン（D04: 変異→選択、D08: 予測誤差→モデル更新）との照合が次の課題。30領域の横断統合で「波→縁移行の一般理論」を構築できるかがプロジェクト全体の重要論点。

### PT-2（更新）: H-4の再定義

Phase 6のPT-2をPattern-2で精緻化。「意図なき創造が存在する」→「構造創発は意図を必要条件としない」への再定義を提案。pjdhiro判断事項。

### PT-3（維持）: CA判定の維持

003クレオールと008言語相対性のCA維持は妥当。ただし003の「場の強制的創出」と008の「束→場の制約」は保持論点として高い価値を持ち、5段階モデルの場・束概念の精緻化に貢献する。

### PT-5（新規）: 生成バイアス——5段階は「死」を記述できるか

Blind-1から浮上。5段階モデルが「生成」の方向のみを記述し「解体」を扱わないのは、モデルの限界か意図的な設計か。言語の消滅・衰退は5段階の「逆走」として記述可能か、それとも5段階とは異なるプロセスか。

### PT-6（新規）: 縁の分類学

Pattern-4から浮上。D17が提示する10種類の縁の型を、30領域全体で統合した「縁の分類学」を構築する可能性。内生的/外生的、蓄積型/制約型などの軸で整理できるか。

| 束（Bundle） | まとまりが安定し構造として残る段階 | 束の「残り方」に多様性がある。不可逆的定着（001文法化）、世代間伝播（010 ILM）、共同体規範（002, 005）。また束は次サイクルの場を制約する（008言語相対性）。束の「解体」プロセスは未記述（Blind-1） | 中。束の安定化メカニズムは多面的に記述されるが、解体の記述が欠落 |

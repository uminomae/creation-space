# Phase 6: structural-reread — D21 経済学（Economics）

## §A: Entry-by-entry reread

### EV-EC-001: Schumpeter 創造的破壊

| 軸 | 分析 |
|----|------|
| **正確な対応** | 「新結合」→渦（新しいまとまりの立ち上がり）は正確。「群生」(cluster)が渦の自己強化特性を経済的に記述する点も的確。「円環的流れ」(Kreislauf)→場（変化前の安定状態）も構造的に正確 |
| **怪しい対応** | 「創造的破壊」→束の対応がやや怪しい。創造的破壊は「構造の更新プロセス」であって「安定した形式の確立」ではない。DR一次ソースの「創造的破壊の定着＝束」という読みは、束を「更新パターンの構造化」と解釈すれば成立するが、束の本来の意味（安定した形式）からはずれる可能性がある |
| **破綻箇所** | 縁の記述が暗黙的である点は Phase 5 で指摘済み。Schumpeter 自身は「新結合が成功する条件」を体系化しておらず、縁の3条件（関係網・未決定性・渦接続）のうち「未決定性」が弱い。新結合の成否はSchumpeter理論内では事後的にしか判明しない |
| **見えていなかった構造** | DR一次ソースの「信用＝縁の媒介」は重要な発見。信用は「既存結合から生産手段を引き剥がして再配分する」機能であり、場（既存の循環）と渦（新結合）を接続する縁として読める。これは Schumpeter の縁が「暗黙的」ではなく「信用メカニズムとして制度化された縁」である可能性を示す |

### EV-EC-002: Hayek 自生的秩序

| 軸 | 分析 |
|----|------|
| **正確な対応** | 「分散知識の総体＝場」は構造的に正確。場の「漂う」特性（全体が見えない）と知識分散テーゼの対応は強い。「自生的秩序＝渦→束の遷移」も正確——意図せざる結果として秩序が立ち上がる |
| **怪しい対応** | 「相対価格の変動＝波」はやや薄い。波は「差異が感知される」ことだが、価格変動は差異の「結果」であって差異そのものではない。「価格＝差異の信号」と読めば対応するが、波の自律的ダイナミクス（増幅・減衰）が価格理論内で記述されているかは疑問 |
| **破綻箇所** | 「個々の市場取引＝縁」は微視的すぎる。個別取引を「縁」とすると、経済全体が無数の「縁」で構成されることになり、縁の分析的有用性が失われる。縁は「決定的な分岐点」であるべきで、日常的取引の全てが縁ではない |
| **見えていなかった構造** | Hayek の「競争＝発見手続き」は、5段階の「場→波→縁」全体の社会的実装として読める。競争プロセスは「潜在的知識（場）が顕在化し（波）、特定の発見として結実する（縁）」一連の流れ。個別取引ではなく「競争プロセス全体」を縁として読む方が構造的に適切 |

### EV-EC-003: Keynes 根本的不確実性

| 軸 | 分析 |
|----|------|
| **正確な対応** | 「根本的不確実性＝場の特性」は正確。場が「確率計算に還元できない」空間であることと、Knight(004)の不確実性概念との構造的共鳴がある。「アニマルスピリッツ＝縁の決断型」も的確——不確実性下で「動くか動かないか」の分岐 |
| **怪しい対応** | 「慣行(convention)」の5段階上の位置づけが曖昧。慣行は「場」（暗黙の前提）とも「束」（安定した行動パターン）とも読める。エントリでは明示的に位置づけられていない |
| **破綻箇所** | 渦と束の対応が欠落。エントリに[類似]セクションがなく、5段階対応が部分的にしか記述されていない。有効需要の乗数効果は渦（自己強化的ダイナミクス）の候補だが、エントリ内で接続されていない |
| **見えていなかった構造** | 「流動性選好＝withhold の経済的実装」という読みが可能。流動性選好は「不確実性下で貨幣を保持する」行為であり、D3（Withhold: 反射的に処理せず誤差を問いとして保持する機能）の経済的バージョン。「使わない」ことが合理的選択である状況は、5段階の「場→波」の遷移が保留される状態として読める |

### EV-EC-004: Knight リスクと不確実性

| 軸 | 分析 |
|----|------|
| **正確な対応** | 「不確実性の海＝場」は正確。「企業家的判断＝縁（引き受け型）」も構造的に強い。Knight の理論の核心が「誰がどの時点で不確実性を引き受けるか」であり、これは縁の「分岐」特性と直接対応 |
| **怪しい対応** | 「利潤の発生＝渦」は怪しい。利潤は渦（自己強化的ダイナミクス）というより結果・成果物。渦は「利潤を生み出すプロセスの自己強化」であるべきだが、Knight 理論内でそのダイナミクスは十分に記述されていない |
| **破綻箇所** | 「市場選択による判断の事後的検証＝束」は破綻に近い。市場選択は継続的プロセスであり、「安定した形式の確立」としての束とは異なる。Knight の理論は縁（判断の瞬間）に焦点があり、渦・束のプロセスは理論の射程外 |
| **見えていなかった構造** | 「リスク/不確実性」区分と「誤差の3運命」の構造的対応は既に指摘されているが、より精密には: リスク＝「棄却可能な誤差」（確率計算で処理）、不確実性＝「保持すべき誤差」（withhold が必要）、利潤＝「採用された誤差の結果」（不確実性を引き受けた報酬）。この3重構造は5段階モデルのコア定義D1-D3と直接的に対応する |

### EV-EC-005: Nelson & Winter 進化経済学

| 軸 | 分析 |
|----|------|
| **正確な対応** | 「探索はギャップによって駆動される＝波→縁の接続」は正確。「業績が満足水準を下回ると探索が起動する」は D1（欠損駆動思考: 棄却される誤差を問いとして拾う態度）の組織的実装として読める |
| **怪しい対応** | 「ルーティン」の5段階上の位置づけが二重的。既存ルーティン＝場（行動の前提）でもあり束（安定した形式）でもある。エントリ内ではこの二重性が整理されていない |
| **破綻箇所** | 特に破綻はない。ただし「選択環境」が5段階のどこに位置するかが曖昧。選択環境は場（行動の文脈）とも渦（淘汰の自己強化ダイナミクス）とも読める |
| **見えていなかった構造** | 「satisficing（満足化）＝withhold の組織的実装」という読み。Simon の satisficing は「最適ではなく満足水準で停止する」ことだが、これは「完全な情報処理を断念し、暫定的結論を保持する」点で D3（Withhold）と構造的に対応する。また「ルーティン＝組織の記憶」と「場＝潜在的知識空間」の対応は、ルーティンが「場の部分的結晶化」（場の一部が束として安定化したもの）として読めることを示す |

### EV-EC-006: Arthur 複雑系経済学・収穫逓増

| 軸 | 分析 |
|----|------|
| **正確な対応** | 全5段階が鮮明。特に「ティッピングポイント＝縁」の対応は D21 内で最強。縁の3条件（関係網＝エージェント間相互作用、未決定性＝複数均衡の並存、渦接続＝収穫逓増による自己強化）を全て満たす |
| **怪しい対応** | 「複数均衡が可能な潜在空間＝場」は正確だが、複数均衡の「存在」は場の特性のうち「潜在性」にのみ対応する。場の「漂う」特性（未分化、方向なし）が複数均衡モデルでどう表現されるかは明示されていない |
| **破綻箇所** | 特に破綻はない。D21 内で最も堅牢な5段階対応 |
| **見えていなかった構造** | 「ロックイン後の経路変更にはMinsky的な崩壊が必要」というエントリ内の指摘は、束→場の回帰条件として一般化可能。すなわち「束が十分に硬直化すると、場への回帰は漸進的（波的）ではなく破壊的（渦的崩壊）を経由する」。これは Minsky(009) との構造的共鳴であり、D21 内の横断パターンの候補 |

### EV-EC-007: North 制度経済学

| 軸 | 分析 |
|----|------|
| **正確な対応** | 「非公式的制約（文化・規範）＝場」は構造的に強い。場の「見えにくい」「変化しにくい」特性と文化的規範の慣性が対応。「経路依存的ロックイン＝渦→束」も正確 |
| **怪しい対応** | 「制度的イノベーション＝縁」がやや曖昧。「新ルールの試行が受容されるかの分岐」は縁の定義に合致するが、制度変化は通常「漸進的」であり、明確な「分岐点」として同定しにくい。DR一次ソースの「制度と組織の相互作用＝縁」という読みの方が適切か |
| **破綻箇所** | 「縁→渦の遷移メカニズムがアンダースペシファイド」はエントリ自身の認識通り。North 理論内で「制度変化がどのように自己強化的ダイナミクスに移行するか」は増加収穫メカニズムとして一般的に記述されるが、具体的プロセスは曖昧 |
| **見えていなかった構造** | North の「フォーマル/インフォーマル」の区分は、5段階の「場/束」の区分と構造的に対応する可能性。インフォーマル規範＝場（暗黙的、変化しにくい前提）、フォーマル規則＝束（明示的、変更可能な安定形式）。この対応を認めると、制度変化は「束の変更がフォーマルに可能でも、場（インフォーマル規範）が変わらなければ実質的に機能しない」という洞察に接続する |

### EV-EC-008: Sen ケイパビリティ・アプローチ

| 軸 | 分析 |
|----|------|
| **正確な対応** | 「変換要因＝縁の多条件的記述」は正確。資源と機能の間の変換が個人-社会-環境の交差点で決定されるという記述は、縁の「関係網」特性と対応 |
| **怪しい対応** | 「ケイパビリティ＝場」は怪しい。ケイパビリティは「達成しうる機能の組み合わせ」であり、「未分化な潜在空間」（場）よりも「構造化された可能性空間」に近い。場は「何が可能か」以前の状態であり、ケイパビリティは「何が可能か」の明示的評価 |
| **破綻箇所** | 波→渦→束の対応が不十分。「剥奪」が波（差異の感知）として読めるが、その後のプロセス（渦：自己強化的変化、束：安定した新状態）が Sen 理論内で記述されていない。Sen は「何が欠けているか」を診断するが「どう変わるか」のプロセスを記述しない |
| **見えていなかった構造** | 「ケイパビリティの剥奪＝欠損(D2)の社会的実装」という読みが可能。剥奪は「あるべき機能が欠けている」主観的経験であり、D2（予想と現実の誤差を意識が「欠け」として捉えた主観的経験）と構造的に対応する。ただしこの読みは Sen の問題意識（社会的正義の評価）を5段階モデル（創造のプロセス記述）に接続するものであり、「評価 vs 生成」の差異を橋渡しする可能性と、差異を不当に潰す危険の両方がある [UNCERTAIN] |

### EV-EC-009: Minsky 金融不安定性仮説

| 軸 | 分析 |
|----|------|
| **正確な対応** | 全5段階が鮮明。特に「ヘッジ→スペキュレーティブ→ポンツィ」の3類型が渦の自己強化プロセスの段階的記述として極めて正確。「場が自身の破壊を内包する」点は D21 内で唯一の構造 |
| **怪しい対応** | 「危機後の新金融秩序＝束」はやや楽観的。危機後の規制強化は「束」として安定するとは限らず、次の Minsky サイクルの「場」として機能する可能性がある。束と場の区別が時間軸依存になる |
| **破綻箇所** | 特に破綻はない。ただし「破壊的渦」が5段階の渦（まとまりの立ち上がり）の範囲内かは理論的に未解決 |
| **見えていなかった構造** | 「安定が不安定を生む」は5段階モデルの「束→場への回帰」の最も鮮明な記述。束（安定した秩序）が長期化すると、場の性質が変質する（リスク認知が低下する）。これは「束は場を変質させる」という一般命題の候補であり、5段階モデルの螺旋的反復の核心機制を Minsky が経済学的に記述している可能性がある |

### EV-EC-010: Penrose 企業成長の理論

| 軸 | 分析 |
|----|------|
| **正確な対応** | 「未利用の生産的サービス＝場の豊かさ」は正確で独自価値が高い。場が「空」ではなく「まだ顕在化していない可能性で満ちている」という記述は、場の「潜在性」特性の最も経済学的に具体的な記述 |
| **怪しい対応** | 「主観的生産機会＝波」は怪しい。主観的認知による機会の発見は波（差異が感知される）より縁（分岐点での判断）に近い可能性がある。しかし Penrose 理論では機会の「発見」は連続的であり、明確な分岐点がない |
| **破綻箇所** | 渦と束の対応がほぼ不在。企業成長は「連続的拡大」であり、渦の「自己強化的ダイナミクスが独自のまとまりとして立ち上がる」特性が弱い。Penrose 効果（マネジメント能力による成長の限界）は束の「安定化」とは異なる——成長の「天井」であって「形式の確立」ではない |
| **見えていなかった構造** | 「資源の多用途性(versatility)」は場の「未分化性」の経済学的表現として再読できる。同一資源が異なるサービスを提供しうるということは、資源が「まだ特定の用途に分化していない」（＝場の状態にある）ことを意味する。資源が特定用途にロックインされた状態が束、多用途性が残っている状態が場。この読みは Arthur(006) のロックイン概念と対照的に配置できる |

## §B: 再読から浮上した問い

### 問い1: 「束は場を変質させる」は一般命題か

Minsky(009)の「安定が不安定を生む」、Arthur(006)の「ロックイン後の経路変更には崩壊が必要」は、いずれも「束の長期化が場の性質を変える」ことを示唆する。5段階モデルにおいて「束→場」の回帰は単純な「元に戻る」ではなく「変質した場への移行」であることが、D21 の複数エントリから帰納的に支持される。これは5段階の螺旋性（循環ではなく螺旋）の経済学的根拠となりうる。

### 問い2: 「withhold の経済的実装」は存在するか

Keynes(003)の流動性選好、Knight(004)の不確実性下での判断保留、Nelson&Winter(005)の satisficing は、いずれも「反射的に処理せず保持する」(D3: Withhold)の経済的実装として読める。経済学は「行動する/しない」の二項対立で語られがちだが、「保持する」という第三の選択肢が複数エントリに埋め込まれている。これは D3 の領域横断的普遍性の証拠候補。

### 問い3: 「縁の不可逆性」はどこまで一般的か

Arthur(006)のロックイン、North(007)の経路依存は、縁を越えた後の不可逆性を示す。しかし Knight(004)の企業家的判断やKeynes(003)のアニマルスピリッツは可逆的な縁を示唆する。D21 内で「不可逆な縁」と「可逆な縁」の2タイプが共存しており、縁の分類軸として「可逆性」を追加する必要があるか。

### 問い4: 「破壊的渦」は渦の亜種か別概念か

Minsky(009)の信用収縮の連鎖は自己強化的だが破壊的。Schumpeter(001)の創造的破壊も破壊と創造が不可分。5段階の渦は「まとまりの立ち上がり」と定義されるが、「まとまりの崩壊」もまた自己強化的ダイナミクスである。渦を「方向を持たない自己強化的ダイナミクス」と再定義するか、「創造的渦」と「破壊的渦」を区別するか。

### 問い5: North の「フォーマル/インフォーマル」は「束/場」の社会的対応か

North(007)の「フォーマル規則＝束、インフォーマル規範＝場」という読みが構造的に成立するなら、「制度変化の困難さ」は「束を変えても場が変わらない」問題として一般化できる。これは組織変革、教育改革、文化変容などの領域横断的テーマに接続しうる。

## §C: 仮説と統合的知見

### 仮説1: 螺旋性の経済学的根拠 [SPECULATIVE]

D21 の複数エントリ（Minsky, Arthur, North）が独立に示す「束→場の回帰における変質」は、5段階モデルの螺旋性（同じ場に戻らない）の強力な経済学的根拠である。経済学は「均衡への回帰」ではなく「変質した場への移行」を記述する理論群を多く含み、これは5段階モデルの「循環ではなく螺旋」という主張を支持する。ただし、この根拠は「反均衡」の経済学（D21 に選ばれた系譜）に限定されており、均衡理論（新古典派）を含めた経済学全体からの支持とは言えない。

### 仮説2: Withhold の普遍性 [SPECULATIVE]

D3（Withhold）が Keynes（流動性選好）、Knight（判断保留）、Nelson&Winter（satisficing）に独立に対応することは、Withhold が経済的行動にも実装される普遍的機能である可能性を示す。「行動しない」ことの合理性を理論化した経済学者たちが、無意識のうちに Withhold の構造を記述していた。ただしこれは事後的な読み込みであり、各理論家が意図した概念とは異なる [UNCERTAIN]。

### 仮説3: 場の二重性——潜在性と慣性

D21 の場の記述は二つの方向に分裂する。Penrose(010)は場の「豊かさ」（未利用の可能性で満ちている）を、North(007)は場の「慣性」（文化的規範は変化しにくい）を記述する。場は同時に「可能性の源泉」でもあり「変化の抵抗」でもある。この二重性は場の概念を精緻化する手がかりであり、場を単に「潜在空間」と定義するだけでは不十分であることを示す。

## §D: 保持論点

1. **「評価 vs 生成」の差異**: Sen(008) の位置づけ。ケイパビリティの剥奪＝欠損(D2)の社会的実装という読みは魅力的だが、Sen の問題意識を歪める危険がある。この緊張を解消せず保持する

2. **「破壊的渦」の理論的位置づけ**: Minsky(009) の信用収縮は渦の構造（自己強化的ダイナミクス）を持つが方向が破壊的。渦の定義を拡張するか、破壊的プロセスを別概念として扱うか

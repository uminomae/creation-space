# Phase 7: cross-domain-synthesis — D27 建築・空間デザイン

## §A: 横断パターン

### パターン1: 「境界は帯域である」——D27内部の独立収束

D27の12エントリ中、10エントリ（Accept全10件）が独立に「境界は線ではなく帯域である」という知見に到達している。理論的系譜の異なる5つのアプローチが同一の構造に収束する:

| アプローチ | 理論家 | 「境界は帯域」の表現 |
|-----------|--------|-------------------|
| 構造保持変換 | Alexander | Boundaries = centerを強める厚みのある輪郭 |
| 物理的形態生成 | Otto | 境界条件 = 形態を規定する変数群 |
| 社会的媒介 | van Eyck | in-between = 二項対立を媒介する領域 |
| 勾配設計 | Hertzberger | threshold space = 公私のgradient |
| 時空間 | 間 | 縁側 = 可変的な内外調停装置 |

この収束は5段階の「縁」概念が建築理論の独立した系譜群から支持されることを意味する。D25人類学（Turner, Douglas等の「移行期は帯域」）との領域横断的一致が、この収束をさらに強化する。

### パターン2: 「生成の主体性スペクトラム」——主体なき生成から協働的生成へ

D27内部で、生成における主体性の度合いがスペクトラムとして分布する:

| 主体性の度合い | 理論 | 生成のメカニズム |
|--------------|------|----------------|
| 主体性ゼロ | Otto（form-finding） | 物理法則による自己組織化 |
| 主体性低 | Menges（computational morphogenesis） | 材料特性 + アルゴリズム |
| 主体性中 | Alexander（unfolding） | 設計者のdeep feeling + 構造保持変換 |
| 主体性高 | van Eyck / Hertzberger | 設計者の意図的な「縁」の設計 |
| 主体性分散 | Aravena（incremental） | 専門家 + 居住者の協働 |

5段階の構造がこのスペクトラムのすべてのポジションで保存されていることは、5段階が主体性に依存しない「構造そのもの」を記述していることの証拠。ただし「計算的最適化」（Menges）と「自発的生成」（Otto）の質的差異は保持論点として残る。

### パターン3: 「縁」の多面性——単一現象の10の顔

D27で確認された「縁」の10の顔は、5段階の「縁」が豊かな内部構造を持つことを示す:

| 類型 | 代表理論 | 「縁」の機能 |
|------|---------|------------|
| 構成型 | Alexander | centerを強める |
| 規定型 | Otto | 形態を決定する |
| 媒介型 | van Eyck | 対立を媒介する |
| 居場所型 | Hertzberger | 留まることを可能にする |
| 逆照射型 | Jacobs | 不在により本質を照らす |
| 時空間型 | 間 | 動的に可変である |
| 界面型 | Menges | 材料と環境の接触面である |
| 未完型 | Aravena | 不完全さから生成を誘発する |
| 物質型 | poché | 物理的に厚い |
| 認知型 | Lynch | 知覚され記憶される |

これらの顔は相互排他的ではなく、一つの「縁」が複数の顔を同時に持ちうる（例: 縁側は「時空間型」かつ「居場所型」かつ「物質型」）。この多面性は「縁」を単一の定義に還元できないことを示すと同時に、5段階の「縁」概念が十分な包含力を持つ必要があることを示す。

### パターン4: 「場→波」移行の建築的メカニズム——残余の資源化

Phase 6で浮上した「残余の資源化」パターンがD27内部の複数エントリに確認される:

- **poché**: 壁の厚み = 構造的残余 → 空間的資源（設計語彙への転化）
- **Jacobs**: 余白空間（残された路地・角） → 多様性の源泉（活力への転化）
- **間**: 柱間の空 = 構造的間隔 → 経験的余白（美学への転化）
- **Aravena**: 未完成空間 = 経済的制約の残余 → 増築の可能性（社会的資源への転化）

「まだ差異として認知されていない残余」が「差異」として意識に上るプロセスは、5段階の「場→波」移行の建築的メカニズムとして一般化可能か。他領域での確認が必要 [SPECULATIVE]。

### パターン5: 設計原理とプロセスモデルの構造的差異

D27のエントリ群は「設計原理（何をどう作るべきか）」と「プロセスモデル（何がどう生成されるか）」に分かれる:

| 類型 | エントリ | 5段階との接続の質 |
|------|---------|------------------|
| プロセスモデル | Alexander（unfolding）, Otto（form-finding）, Menges, Aravena | 段階的生成の記述として直接対応 |
| 設計原理 | van Eyck, Hertzberger, 間, Jacobs, poché, Lynch | 空間の性質・条件の記述として間接対応 |

5段階との構造対応は「プロセスモデル」群でより堅く、「設計原理」群ではプロセスへの読み替えが介在する。この区別を維持することは、5段階の適用範囲の明確化に資する。

## §B: 精度と限界

### 強い対応の条件

D27において5段階との対応が「強い」と判断される条件:

1. **段階的プロセスの記述を含む**: Alexander（unfolding）、Otto（form-findingの5段階）が典型。プロセスとして記述された理論は5段階との対応が直接的かつ検証可能
2. **「縁」への明示的な定義を持つ**: van Eyck（in-between）、Hertzberger（threshold space）、poché、Lynch（edge）。5段階の核心概念「縁」との定義的重なりが高い理論は対応が堅い
3. **物理的検証が可能**: Otto（石鹸膜の平衡形態）、Menges（材料の自己形状変化）。物理的に観察・測定可能なプロセスは対応の検証が容易
4. **逆照射（不在の記述）を含む**: Jacobs（border vacuum）、Schumacher（Reject=縁の消去の帰結）。「縁が不在のときに何が起こるか」の記述は「縁」の必要性を反証可能な形で支持

### 破綻条件

5段階との対応が「破綻」する条件:

1. **核心概念との構造的矛盾**: Schumacher（連続的差異化=境界の消去）は5段階の「縁」と矛盾する方向。「場」や「波」への部分的対応があっても、核心との矛盾が構造対応を無効化する
2. **プロセス記述の不在**: Pallasmaa（知覚の現象学的記述のみ）。「場」の状態記述は可能だが、「場→波→縁→渦→束」のプロセスへの対応が構造的に欠落
3. **表面的数値一致への依存**: Otto実験手法の5段階、Lynchの5要素と5段階モデルの段階数の一致は偶然的。数値の一致を構造対応の根拠にしない

### 比較原則

D27固有の比較原則:

- **設計原理の中にプロセスを読み込まない**: 静的な設計原理を動的な5段階のプロセスとして読み替える際には、[WEAK_MAPPING]タグを使用する
- **建築固有の設計語彙を5段階の一般語彙として転用しない**: Hertzbergerの3設計変数、Alexanderの15性質等は建築の文脈に固有
- **「縁=boundary」の等式化を避ける**: 建築の「boundary」と5段階の「縁」は重なりが大きいが射程が異なる

## §C: 盲点

### 盲点1: 建築の「失敗」「崩壊」「破壊」の構造的考察の不足

D27のevidence全体が「成功した建築」「生きた建築」を記述する理論に偏っている。Alexanderの「生（life）」、van Eyckの「人間化された空間」、Hertzbergerの「活動と滞留」——すべて生成の成功例。一方で、建築の崩壊（物理的崩壊、社会的崩壊、認知的無視）が5段階のどの段階の逆行に対応するかは未考察。Schumacher（Reject）とJacobs（border vacuum）が部分的にこの盲点をカバーするが、体系的な「失敗の5段階分析」は不在。

5段階が「生成」のプロセスを記述するモデルであるならば、「崩壊」は5段階の逆行（束→渦→縁→波→場への回帰）として記述可能か。それとも崩壊は5段階とは異なるプロセスか。この問いはD27建築が提起する重要な盲点。

### 盲点2: 非西洋建築理論の限定的カバレッジ

「間」（AD-006）が日本建築論の代表として入っているが、他の非西洋建築理論——イスラム建築の幾何学的秩序、中国風水の空間論、アフリカの集落構成論等——は未カバー。5段階の「普遍性」を主張するならば、西洋建築理論への偏りは盲点となる。ただしD27のスコープ（5段階との構造類似の評価）を考えると、カバレッジの拡大は優先度が低い——既存エントリで5段階との構造対応は十分に示されている。

### 盲点3: 建築の時間スケールの長さと5段階の適用

建築は物理的に長期間存続する（年〜世紀）。5段階のプロセスが完了した後、建築物は「束」として固定化される。しかし建築の使用、改修、再解釈は「束→場」への回帰のプロセスであり得る。Aravena（incremental）はこの循環の一部を記述するが、「束」から再び「場」に回帰するメカニズム（既存建築の用途変更、歴史的建造物の再解釈等）は体系的に考察されていない。

## §D: 保持論点の更新

### 解消された論点

なし（Phase 5-6の保持論点はすべてPhase 7でも未解消）

### 更新された論点

1. **structure-preserving transformation の位置づけ**: Phase 6で「unfoldingは波ではなく縁の操作記述かもしれない」という問いが浮上。Phase 7ではパターン2（生成の主体性スペクトラム）の中でAlexanderを「主体性中」に位置づけた。unfoldingが「波」の記述なのか「縁」の記述なのかは、5段階の段階間境界の問題として一般化可能

2. **「縁」の10の顔の統合的位置づけ**: パターン3で10の顔を整理。これらが5段階の「縁」の下位構造を示唆するか、それとも一つの「縁」の多面的記述に過ぎないかは、他領域（D25人類学、D29複雑系等）の「縁」の顔との統合後に判断

3. **「残余の資源化」メカニズム**: パターン4でD27内部の複数エントリに確認。他領域への一般化の可否は横断統合で検討

### 新規論点

4. **「崩壊」の5段階分析**: 盲点1。5段階の逆行として記述可能か、それとも別のプロセスか

5. **「束」からの回帰メカニズム**: 盲点3。建築の長期的使用・改修・再解釈は「束→場」の循環をどう実現するか

| 段階 | 現理解 | D27からの更新 | 確信度 |
|------|--------|-------------|--------|
| **場（Field）** | すべてが溶けている、分かれていない海のような状態 | 「場」は受動的な基盤ではなく、生成の潜在性を内包する能動的構造。Mengesの「材料が行動する」、「間」の「余白が何かである」がこの能動性を示す。「設計された場」（Aravena）と「自然な場」（Otto）の区別が生じるが、両者で5段階の構造が保存される | 中〜高 |
| **波（Wave）** | 場の中に差が生まれ、揺れとして立ち上がる | 「残余の資源化」が「場→波」移行の具体的メカニズム候補。pochéの壁厚=残余→資源、Jacobsの余白→多様性の源泉。「まだ差異として認知されていない残余が差異として意識に上る」プロセス。ただしこの仮説はD27固有であり他領域確認が必要 [SPECULATIVE] | 低〜中 |

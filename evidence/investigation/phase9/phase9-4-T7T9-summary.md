## 2. T7+T9（盲点と反例）再評価

### 2.1 Phase 8 での T7+T9 主張の要約

Phase 8 theme-blind-spots.md は以下を主張した:
1. 5段階は「秩序の生成」に特化しており、「秩序の解体」の理論を持たない
2. 解体は5段階の「逆」ではない
3. 「失敗モード」は5段階に内在する
4. 「計画的解体」は生成の一部である

### 2.3 T7+T9 の収束点ごとの再評価

#### 収束1「秩序の解体の理論を持たない」— 支持される [P]

Phase 9-1 で確認された破壊的過程の事例（D05 地震サイクル、D10 免疫逃避、D21 Minsky モーメント等）は全て verified。30ドメインが秩序生成を記述する一方、解体を5段階で一貫記述する試みは見られない。この指摘は事実として確認された。

#### 収束2「解体は逆順ではない」— 支持される [M]

D16 歴史学（文明崩壊）、D29 複雑系（エントロピー増大）の [P] 主張が verified であることから、解体プロセスが束→渦→縁→波→場の逆順をたどらないという観察は原典に支持される。ただし [M] タグ（比喩的解釈）は維持すべき。「逆順ではない」は観察であり、何であるかの理論は未構築。

#### 収束3「失敗モードは5段階に内在する」— 支持される [M]

失敗モード表（layer3-synthesis.md §1.3）の各事例が Phase 9-1 で verified:
- 渦不到達: D25 schism（verified）、D28 ブロック（7v/2p）
- 束の病理: D09 癌（verified）、D22 ロックイン（verified）
- 縁の誤判定: D10 自己免疫（verified）

失敗モードが「例外」ではなく「構造的可能性」であるという読みは [M] レベルの解釈だが、事実的基盤は十分。

#### 収束4「計画的解体は生成の一部」— 支持される [M]

D09 アポトーシス（verified）、D12 里山管理（全件 verified）が直接的証拠。束→場回帰の一形態として計画的解体を位置づける読みは、原典の記述と整合する。

## 3. Phase 8 5仮説の最終評価

layer3-synthesis.md §4 が提示した「5段階の姿の変容」5項目を、Phase 9 全体の結果に基づき評価する。

### 仮説1: 螺旋化（束→場の不可逆的回帰）

| 項目 | 評価 |
|------|------|
| **信頼度** | 高 |
| **根拠** | T5 が22ドメインで確認。Phase 9-1 で D02 超伝導（verified）、D04 種分化（verified）、D29 散逸構造（verified）等、不可逆的束→場回帰の事例が verified |
| **弱点** | 人文科学での「不可逆性」の定量的確認が薄い。D16 歴史学は周期性を示すが「同じ場所に戻らない」の厳密な検証は未完 |
| **判定** | 自然科学で強く支持、人文科学で定性的に支持。螺旋モデルの採用は妥当 |

### 仮説2: 縁の概念族化（多型的な概念族としての縁）

| 項目 | 評価 |

| **判定** | 縁を単一定義から概念族へ拡張する提案は、30ドメインの多様な事例が裏づける。優先度 A の提案として採用可能 |

### 仮説3: 帯域内閾値（縁は帯域、その中に閾値がある）

|------|------|

## 4. Phase 8 仮説「失敗モード内在」の妥当性

### 4.1 検証結果の整理

Phase 8 layer3-synthesis.md §1.3 が提示した失敗モード表を、Phase 9-1 の ref-check 結果と照合する。

| 段階 | 失敗モード | 代表例 | Phase 9-1 判定 |
|------|-----------|--------|---------------|
| 場 | 場の閉鎖・不在 | D08 自律神経シャットダウン | verified（基本機構）/ plausible（Porges 3段階） |
| 波 | 波の不発・過剰 | D12 撹乱不足、D05 暴走 | D12 全件 verified、D05 9v/1p |
| 縁 | 誤同定・固着 | D10 自己免疫、D14 固着 | D10 9v/1p、D14 全件 verified |
| 渦 | 不到達・暴走 | D25 schism、D08 てんかん | D25 全件 verified、D08 9v/2p |
| 束 | 過剰固定・不足 | D22 ロックイン、D09 癌 | D22 全件 verified、D09 9v/2p |

### 4.2 判定

失敗モード表の全6行について、少なくとも1つの代表例が verified。plausible は主張の誤りではなく書誌特定・議論中ステータスの反映。overstated は 0 件。

**結論**: 「失敗モード内在」仮説の事実的基盤は Phase 9-1 で確認された。5段階に失敗モード表を付記する提案は採用可能である。

## 5. plausible 32件の分析

### 5.1 plausible の性質分類

| 分類 | 件数 | 典型例 |
|------|------|--------|
| 書誌特定の不完全さ（原典は存在するが Web で数値・版を確認できず） | 12 | D06 Spitzer 1987、D30 本田安次、D28 Meyerhold |
| CA 判定エントリ（構造的類似の解釈が plausible） | 9 | D23 発達心理の CA 判定5件、D13 シェリング |
| 議論中の理論（学界で係争中） | 6 | D08 Porges、D09 mtCB1受容体 |
| 解釈的飛躍の認識（エントリ自身が [M] で自覚） | 5 | D15 日本美学、D01 臨界点の数学的原型 |

### 5.2 対応方針

- **書誌特定不完全（12件）**: Phase 9-2（RAG 検証）で原典照合を実施すれば verified に昇格可能
- **CA 判定（9件）**: 構造的類似の解釈は理論的判断であり、verified/overstated の二択ではない。plausible 維持が適切
- **議論中（6件）**: 学界の状況を正確に反映。plausible + [議論中] タグの維持が適切
- **解釈的飛躍（5件）**: [M] タグが自覚を示しており、品質管理として機能。plausible 維持

## 6. 今後の課題と Phase 10 への提言

### 6.1 Phase 9 で残された課題

1. **plausible 32件の RAG 検証**: 書誌特定不完全の12件は原典照合で解決可能。優先フォローアップ対象
2. **人文科学での閾値概念の補強**: 仮説3（帯域内閾値）の信頼度を「中→高」に上げるには、D16 歴史学・D18 社会学での閾値的遷移の具体的記述が必要
3. **螺旋の不可逆性の人文科学的検証**: 仮説1の弱点。「同じ場所に戻らない」の人文科学的な意味の精緻化が未了
4. **type-0 場の必要性判断**: 仮説5 の type-0/type-1 区分の理論的必然性は保持論点

### 6.2 Phase 10 への提言

| 提言 | 内容 | 優先度 |
|------|------|--------|
| 段階定義の改訂案作成 | 5仮説のうち信頼度「高」の3件（螺旋化、概念族化、失敗モード内在）を反映した改訂案を起草 | A |
| 閾値概念の領域限定 | 帯域内閾値を自然科学プロセスに限定し、人文科学では「漸進的遷移」を許容する記述に | B |

4. type-0 場の独立カテゴリとしての必要性
5. 循環は5段階の本質か偶有的特徴か

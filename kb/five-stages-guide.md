# 5段階モデル解説（Five Stages Guide）

**正本参照**: kb/schema/five-stages.md
**用途**: LLM および人間が5段階モデルの全体像を把握するための解説文書。スキーマ定義の補足として、各段階の読み方・遷移条件・よくある誤解を記述する。

---

## 1. モデルの性格

5段階モデルは、創造や変化の過程を「場→波→縁→渦→束」の5段階で記述する。このモデルには以下の性格がある。

- **現象記述モデルである**: 特定の理論から演繹されたものではなく、複数領域の現象に共通して見出される構造パターンを記述したもの。
- **循環モデルである**: 束（Stage 5）は終点ではなく、次のサイクルの場（Stage 1）を支える足場になる。直線的な進歩図ではない。
- **段階数の一致を求めない**: 各学術領域の理論が5段階と一対一で対応する必要はない。重視するのは、段階数ではなく移行のメカニズムと界面の性質。
- **証明を目的としない**: 5段階モデルが「正しい」ことの証明ではなく、各領域の現象がこの構造パターンで読めるかどうかを確かめる探索。

---

## 2. 各段階の定義と特徴

### Stage 1: 場（Field）

| 項目 | 内容 |
|------|------|
| 構造 | 無 |
| プロセス | 漂う |
| 一言 | まだ何も分かれていない海 |

場は、構造も方向もまだ存在しない状態を指す。「何もない」のではなく、すべてが溶けていて区別がつかない状態。前サイクルの束が背景として存在する場合もあるが、場そのものは未分化である。

**観察上の手がかり**: 課題や目的がまだ定まっていない状態。明確な問いが立つ前の漠然とした状態。

### Stage 2: 波（Wave）

| 項目 | 内容 |
|------|------|
| 構造 | ゆれ・対立 |
| プロセス | 分離 |
| 一言 | 差異が揺れとして立ち上がる |

場の中に差が生まれ、方向が揺れとして立ち上がる。まだ安定した形はなく、対立や分離が生じている段階。

**観察上の手がかり**: 違和感の感知、既存の枠組みとの不整合の認知、「何かがおかしい」という感覚。

### Stage 3: 縁（Relation）

| 項目 | 内容 |
|------|------|
| 構造 | 境界・関係 |
| プロセス | 繋がり |
| 一言 | 接し合い、関係が生まれる界面 |

複数の要素が接触し、影響し合い、関係や制約が生まれる場所。5段階モデルの中で最も重要かつ複雑な局面。縁は単なる通過点ではなく、関係の中で新しい秩序が生成される場所である。

**観察上の手がかり**: 異なる視点・要素が交差する場面。協働・対話・葛藤が同時に起きている状態。

**注意**: 縁の記述は領域によって形が異なる。二者関係として現れる場合（愛着理論）、三項関係として現れる場合（共同注意）、多要素システムとして現れる場合（生態学）がある。これらを同じ「縁」で括ることの妥当性は、未解決の問いとして保持されている。

### Stage 4: 渦（Vortex）

| 項目 | 内容 |
|------|------|
| 構造 | 個・立ち上がり |
| プロセス | 包摂・融合 |
| 一言 | まとまりとして立ち上がる |

ばらばらだった要素が一つのまとまりとして立ち上がる。個体化・自己組織化が起きる局面。

**観察上の手がかり**: 新しいアイデアや構造が「見えた」瞬間。散在していた要素に一貫性が生まれる場面。

### Stage 5: 束（Bundle）

| 項目 | 内容 |
|------|------|
| 構造 | 方向 |
| プロセス | 集合 |
| 一言 | 構造として残り、次の場を支える |

渦どうしが影響し合い、持ち運び可能な構造として残る集まり。束は成果物としての固定ではなく、次のサイクルの場を開く保持形式である。

**観察上の手がかり**: 再利用可能な知識・技法・制度として定着した状態。ただし束が固定化すると次の場が開けないため、束の自己言及性（自らを構造として認識すること）が重要になる。

## 3. 段階間の遷移

5段階の遷移は自動的に起きるものではない。以下に各遷移の条件と特徴を記述する。

### 場 → 波

- **条件**: 場の中に差異が生じること。外部からの刺激、内部の揺らぎ、予測誤差の検知などが契機になる。
- **特徴**: この遷移は意図的に起こせるとは限らない。場が十分に「溶けている」ことが前提。

### 波 → 縁

- **条件**: 揺れている要素どうしが接触し、相互作用が始まること。
- **特徴**: 波の状態が長引くと、対立が固定化して縁に至らない場合がある。Withhold（誤差を問いとして保持する機能）がこの遷移を支える。

### 縁 → 渦

- **条件**: 関係の中から新しいまとまりが立ち上がること。
- **特徴**: 縁で起きていることが十分に展開された後に渦が生じる。縁を早く通過しようとすると、表面的なまとまりにしかならない。

### 渦 → 束

- **条件**: まとまりが安定し、持ち運び可能な形式になること。
- **特徴**: 渦のすべてが束になるわけではない。まとまりが維持されない場合、波や場に戻ることがある。

### 束 → 場（循環）

- **条件**: 束が次の探索の背景として機能し、新しい未分化状態を開くこと。
- **特徴**: 束が固定的であるほど次の場が開きにくい。束の自己言及性（構造が自分自身を構造として認識すること）が循環を可能にする。

## 4. よくある誤読

| 誤読 | 修正 |
|------|------|
| 5段階は直線的な進歩を表す | 循環モデルであり、束は次の場に接続する |
| 各段階は明確に区切られている | 段階間にはグラデーションがあり、一対一の厳密な写像は前提としない |
| 5段階は特定の理論から演繹された | 複数領域の現象に共通するパターンの記述であり、演繹ではない |
| 束が最終目標である | 束は保持形式であり、目標ではない。固定化した束は次の場を閉じる |
| すべての現象が5段階で説明できる | 構造対応が弱い領域・理論もある。そのずれ自体が調査対象 |
| 縁は「関係する段階」という一般的な意味である | 縁は新しい秩序が生成される界面であり、単なる関わりを指さない |

## 5. スピノルとの類似（補足）

スピノルの「360度で符号反転、720度で復元」は、5段階モデルの変換構造を眺めるための比喩的着想として参照される。モデルの導出根拠ではなく、構造の視覚的理解を助ける補助線である。

- 1回転（360度）: 見かけ上は戻るが、位相が反転している
- 2回転（720度）: ようやく復元する

この性質は、束から場への回帰が単純な反復ではないことを示唆する。

## 6. この文書の使い方

- **レポート生成時**: §3（モデルの概要）を書く際に、この文書と kb/schema/five-stages.md を参照する。
- **構造対応の評価時**: 各段階の定義と遷移条件を基準にする。段階数の一致ではなく、移行メカニズムの同型性を見る。
- **用語の確認時**: kb/glossary.md と併用する。

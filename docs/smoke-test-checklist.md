# フロントエンド Smoke Test チェックリスト (cs#107)

UI 変更を含む Issue の close 前に確認する。

## 手動チェック項目

### 1. レポート一覧表示
- [ ] 30 ドメインのタイルが全て表示される
- [ ] 各タイルに領域名（日本語）が表示される
- [ ] 進捗レベルのバッジが表示される

### 2. モーダル表示
- [ ] タイルクリックでモーダルが開く
- [ ] モーダルタイトルに領域 ID と名前が表示される
- [ ] 「生成日」がソース .md の date と一致する
- [ ] 「モデル」が表示される（unknown 以外の場合）
- [ ] Markdown 本文がレンダリングされる
- [ ] PDF ボタンが機能する（published 状態の場合）

### 3. 分類フィルタ
- [ ] 進捗レベル別のフィルタが機能する
- [ ] フィルタ選択後、対象タイルのみ表示される
- [ ] 件数カウントが正しい

### 4. フッター
- [ ] 生成日時が表示される
- [ ] ガイドリンクが表示される

### 5. 言語切替
- [ ] EN 切替でラベルが英語になる
- [ ] EN モーダルで英語版 MD が表示される

### 6. トップページ i18n / bootstrap
- [ ] `?lang=ja` 初期表示でヒーロー、タイムライン、REPORTS 初期文言が日本語になる
- [ ] `?lang=en` 初期表示でヒーロー、タイムライン、REPORTS 初期文言が英語になる
- [ ] トグル後 `ja/en` の表示が初期表示 `ja/en` と一致する
- [ ] WebGL 初期化に失敗しても articles / reports / 言語切替が継続動作する
- [ ] 3D 失敗時はページ全体の startup error ではなく警告バナーで継続表示される

## 自動 smoke test

```bash
node scripts/smoke-test.js
```

domains.json のスキーマ・件数・分類データを自動検証する。

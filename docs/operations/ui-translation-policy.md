# UI 翻訳ポリシー

## 基本方針

- ナビゲーション、補助文言、aria は表示言語に完全追従する
- ブランド名や外部サイト名は原表記を維持してよい
- 専門用語は「主ラベル + 原語補助」の併記を許容する

## カテゴリ別ルール

### 1. ナビゲーション

- topbar 文言は表示言語に合わせる
- `PROJECT DESIGN` や `AWARENESS` のようなブランド表記は原表記維持可

### 2. 見出し・補助文言

- section heading、notice、CTA は表示言語に合わせる
- 英語表示で日本語が残る場合は仕様として説明できる状態にする

### 3. 専門用語・5段階モデル

- 英語表示では英語を主ラベルにする
- 必要に応じて日本語を補助ラベルとして併記する
- 日本語表示では日本語を主ラベルにし、英語を補助ラベルとして併記してよい

### 4. aria とアクセシビリティ文言

- 画面表示が英語なら aria も英語
- 画面表示が日本語なら aria も日本語
- 例外を作る場合はブランド名のみ

## トップページでの適用例

- hero / notice / reports 初期 CTA は表示言語に合わせる
- 5段階タイムラインは英語表示で `Field / Wave / Edge / Vortex / Bundle` を主表示とし、日本語は補助表示とする

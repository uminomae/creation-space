# CL-002: Agent subagent は完了処理を自発的に実行しない。プロンプトに明記必須

**日付**: 2026-03-15
**関連Issue**: cs#65-72

## 何が起きたか

cs#65-72 の全8件で Agent subagent が Issue コメントも close も実行しなかった。Main（投入側）もセッション中に検知しなかった。Codex 向けには `codex-dispatch` や `codex-post-check.sh` で構造的に補完していたが、Agent subagent には同等の仕組みがなかった。

## 原因分析

1. Agent subagent のプロンプトに完了処理（Issue コメント・DONE ファイル作成）の指示が含まれていなかった。Agent は与えられたタスクの実装に集中し、プロンプトに明記されていない操作は実行しない。
2. Main の完了チェックプロセスが未定義だった。Agent 完了報告を受けた後に「Issue コメント・close・backlog 更新」を確認するチェックリストが存在しなかった。

## 対策

1. Agent 起動時のプロンプトに完了処理（Issue コメント・DONE ファイル作成）を必須要素として含める
2. Main は Agent 完了後に Issue コメント・close・backlog 更新の漏れを確認するチェックリストを実行する

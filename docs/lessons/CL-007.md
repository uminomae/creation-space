# CL-007: Agent プロンプトに「影響範囲の検証」を明示しなければ Agent は自発的にやらない

**日付**: 2026-03-15
**関連Issue**: cs#74

## 何が起きたか

cs#74 子Issue 3 の Agent が `index.json` のフィールド名を変更した際、パイプラインの上流のみを変更し、下流（data.js のパース処理、フロントエンドの表示）への影響を検証しなかった。Agent は与えられたタスクの範囲内で最善を尽くすが、変更の下流影響を自発的に調査しない。

## 原因分析

Agent subagent に「自分のタスクを完了せよ」と指示すると、「自分のタスクの影響範囲を検証せよ」は含まれない。Agent はプロンプトに書かれた範囲のファイルしか見ない傾向がある。特にデータパイプラインのように複数ファイルが連鎖する構造では、上流の変更が下流を壊すリスクが高いが、Agent は自発的にその連鎖を追跡しない。

## 対策

1. Agent プロンプトに「変更対象ファイルの下流消費者」を明記する
2. 「変更後、下流消費者での動作に影響がないか検証すること」をプロンプトの完了処理に含める

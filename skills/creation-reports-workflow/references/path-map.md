# Creation Reports Path Map

All creation assets are served from the pjdhiro repository (GitHub Pages / raw).

## Canonical URLs
- **PDF (browser)**: `https://uminomae.github.io/pjdhiro/assets/creation/{survey,guides,domains}/{lang}/pdf/*.pdf`
- **MD (raw fetch)**: `https://raw.githubusercontent.com/uminomae/pjdhiro/main/assets/creation/{survey,guides,domains}/{lang}/md/*.md`
- **JSON (data)**: `https://raw.githubusercontent.com/uminomae/pjdhiro/main/assets/creation/manifests/domains.json`

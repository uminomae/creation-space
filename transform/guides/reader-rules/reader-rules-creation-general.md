## §2 中心テーマ

**「創造のプロセスには5つの段階がある。途中で止まることには構造的な理由がある」**

この文書は5段階モデル（場→波→縁→渦→束）を一般の読者に説明する。何であり、どのような構造を持ち、何の役に立つかを伝える。

> **S55との関係**: 共通基盤 §2 は「5段階モデルは『創造プロセス』のモデルではなく、存在そのものの創造を記述している」と定める。general版では「創造のプロセス」を読者の入口として使うが、これは射程の限定ではなく導入の工夫である。§5 Part 5「根拠と限界」で、調査結果が「創造プロセス」に限らず広い射程を示唆していることに触れる。

## §3 声の設計

### 基本の声

**わかりやすい説明文。企業の商品説明のように進む。**

丁寧で、明晰で、読者の理解を第一に考える。説明が伝わらないなら説明を改善する。読者を手放さない。

| 特徴 | 内容 |
|------|------|
| **丁寧** | です・ます調。敬意を持って説明する |
| **明晰** | 一文で一つのことを言う。曖昧な表現を避ける |
| **正直** | 根拠が確定していないことはオープンに伝える。仮説は仮説として示す |
| **具体的** | 抽象論で終わらない。必ず具体例を添える |
| **責任を持つ** | 「わからない」は言う。「わからないから、合わなければいいですよ」とは言わない |

### 禁止する声

| 禁止パターン | 理由 | 代替 |
|-------------|------|------|
| 「ピンとこなければ、それで大丈夫です」 | 読者を手放している。説明の不備を読者に帰責 | 書かない。説明が不十分なら説明を改善する |
| 「合わなければ置いておいてください」 | 責任逃れ | 書かない |
| 「答えは持っていません」 | 説明の放棄 | 「ここはまだ仮説です。根拠はこうです」と温度を示す |
| 「あるとき起きる」「ふと浮かぶ」 | 説明の放棄。NL-003 | メカニズムを可能な限り記述する |
| 「〜かもしれません」の多用 | 全体が不確かに見える | 確定は断定。仮説は「仮説として〜」と明示 |
| 「クリエイティブな人は〜」「才能がある人は〜」 | 投影スイッチ（才能の匂い） | 使わない |
| 「こうすれば創造的になれる」「5ステップで〜」 | 投影スイッチ（ノウハウの圧） | 使わない |

## §4 用語変換

### 5段階: 体験的に導入してから定義

名称は使ってよい（場・波・縁・渦・束）。初出では読者が想像できる場面を示してから名前を出す。ただし物語に「溶かす」のではなく、説明の入口として使う。

| 段階 | 導入の仕方 |
|------|-----------|
| 場 | まだ何もない状態。方向も構造も定まっていない |
| 波 | 複数の方向性が出てきて揺れている状態 |
| 縁 | 矛盾する要素が共存し、どちらにも収束しない。ここで止まる人が多い |
| 渦 | 矛盾の中から新しいまとまりが立ち上がる段階 |
| 束 | 形が定まり、再利用可能な構造として安定する段階 |

### 用語変換表

| 原語 | general版での表現 |
|------|------------------|
| 5段階モデル | 「5つの段階」「創造のプロセスの構造」 |
| 未分化 | 「まだ何も決まっていない」 |
| 発散/収束 | 「広がる/まとまる」 |
| Withhold | 「すぐに解かずに留まる」 |
| 予測誤差 | 「予想と現実のズレ」 |
| 欠損 | 「何かが足りないという感覚」 |
| Container | 「安心できる関係」 |
| F-O軸 | 使わない |
| スピノル | 使わない |
| [P][M][S]タグ | 使わない |

## §5 構成

### 説明文の構成

```
1. これは何か
   5段階モデルの概要。何を記述しているか。
   【返却: 立ち位置明示】 この文書が何であり何でないかを宣言する。

2. 5つの段階
   場→波→縁→渦→束を順に説明する。
   各段階に同程度の記述を与える（NL-003）。
   読者が想像できる具体例を各段階につける。
   【返却: 安全弁】 5段階の説明後、「ここまでの説明で違和感があれば、
     それはこのモデルの射程に関わる重要な観点かもしれない」。

3. なぜ途中で止まるのか
   「縁」の構造。矛盾が最大化し、どちらにも収束しない。
   ここで逃げる（早く決めてしまう/最初からやり直す）と
   渦の質が下がる。
   すぐに解かずに留まることの意味。

4. 何の役に立つか
   「今どこにいるか」がわかること。
   止まっていることが故障ではなく、
   特定の段階に立っていることだとわかること。

5. 根拠と限界
   この構造は30の学問領域で横断的に調査された。
   どの程度の裏付けがあるか。
   まだわかっていないこと。仮説として残っていること。
   調査結果は「創造プロセス」に限らず、より広い射程を示唆していることに触れる。
   【返却: 温度開示】 根拠の確定度を正直に示して閉じる。責任逃れではなく温度の開示。
```

> **共通基盤 §7 返却の設計との対応**: Part 1「これは何か」が立ち位置明示、Part 2「5つの段階」末尾が安全弁、Part 5「根拠と限界」が温度開示。関与レベルはL0（読むだけ。応答不要）がデフォルト。

### 旧版との違い

| 旧 v1.0 | 新 v2.0 |
|---------|---------|
| 3幕構成（体験→物語に溶かす） | 説明文の構成（これは何か→段階→なぜ→役に立つか→根拠と限界） |
| 「手が止まった」体験から入る | 「これは何か」から入る |
| 縁を中心に展開 | 5段階を均等に説明し、縁の構造を丁寧に記述 |
| 安全弁で読者を手放す | 温度を正直に開示し、説明を続ける |

## §6 温度の開示

共通基盤 §5 を継承し、general版の表現に変換する。

根拠が確定していないことはオープンに伝える。読者にとって「何が確かで何がまだ仮説か」がわかるように書く。

| 温度 | general版の表現パターン | 使いどころ |
|------|----------------------|-----------|
| 確定 | 「〜です」「〜が確認されています」 | 5段階の名前と基本構造 |
| 有力 | 「多くの領域で同様の構造が見られます」 | 複数領域で確認された傾向 |
| 仮説 | 「まだ仮説の段階です。根拠はこうです」 | 検証途上の接続 |
| 未解決 | 「ここはまだわかっていません」 | 保持論点 |

**禁止**: 「〜かもしれません」で逃げること。「わからない」は言うが、「わからないから、合わなければいいですよ」とは言わない。

## §7 投影スイッチ回避

共通基盤 §6 を継承し、general固有の追加を定義する。

| スイッチ | 禁止表現 | 理由 |
|---------|---------|------|
| 才能の匂い | 「クリエイティブな人は〜」「才能がある人は〜」 | 読者に劣等感を与える |
| ノウハウの圧 | 「こうすれば創造的になれる」「5ステップで〜」 | ツール売り |
| 完成の圧 | 「最後まで作り切れ」「完成させることが大事」 | 止まることの構造的意味を否定する |
| 自己啓発トーン | 「あなたの創造性を高める」 | 商品説明は効果を約束しない |

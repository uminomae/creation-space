# creation general — 生成ルール v4.0

**タイトル**: 創造の5段階——構造の説明
**読者**: 創造プロセスに関心がある一般の読者
**文書類型**: 説明文
**文体**: です・ます調。平易な表現。専門用語を使わない
**文字数**: 2,000〜3,500字

## 構成

1. **この文書は何か**（1段落）
   - 何を説明するか、何を説明しないかを宣言する
   - 30の学問領域にわたる調査に基づくこと、AIによる解釈を含むことを明示する

2. **5つの段階**（場→波→縁→渦→束）
   - 各段階を均等に説明する（後半の段階を薄くしない）
   - 読者が想像できる具体例をつける

3. **なぜ途中で止まるのか**
   - 「縁」で矛盾が最大化し、すぐに解決したくなる構造を説明する
   - すぐに解かずに留まることの意味

4. **何の役に立つか**
   - 「今どこにいるか」がわかること
   - 止まっていることが故障ではなく、特定の段階にいることだとわかること

5. **根拠と限界**
   - 確かなこと、まだ仮説なこと、わかっていないことを正直に書く
   - 「合わなければ読まなくていいですよ」とは書かない。わからないことはわからないと正直に書く
   - 他の版（designer / academic）や個別調査レポートへの案内

## 注意

- 自己啓発調にしない（「あなたの創造性を高める」「5ステップで〜」は禁止）
- 根拠の確かさを正直に書く。確定していないことを断定しない。仮説は仮説と明示する
- 「ピンとこなければ大丈夫です」「合わなければ置いてください」は書かない。説明が伝わらないなら説明を改善する

# creation designer — 生成ルール v4.1

**タイトル**: 創造の5段階——プロセスの診断
**読者**: デザイナー・PM・企画職で、チームの創造プロセスに構造的な見通しがほしい人
**文書類型**: 構造案内
**文体**: です・ます調。「一緒に見てみましょう」のトーン。あなた・私たち
**文字数**: 3,500〜5,500字
**図**: `assets/img/creation-model.png` を本文中に配置する

## 構成

生成物の見出しは一般的な文書の見出しを使う。
ルール内の記述名（下記1〜4）はルール上の識別であり、そのまま見出しにしない。

1. **はじめに**（1段落）
   - 「発散と収束の間に、名前のない時間がある」から入る
   - この文書が何であり何でないかを伝える

2. **創造プロセスの構造**
   - 場→波→縁→渦→束を構造として提示する
   - 各段階に「チームで何が起きるか」の観察サインをつける
   - 各段階の落とし穴（よくあるミス）も示す
   - 図（creation-model.png）を配置する

3. **チームの現在地を問う**
   - 個人のプロセスとチームのプロセスが入れ子になっていること
   - チームで矛盾に留まるための条件（安心して矛盾を持ち込める関係）
   - 束から次の場へ移ることの難しさ

4. **根拠と開かれた問い**
   - 確かなこと、仮説なこと、わかっていないことを正直に書く
   - 5段階モデルは pjdhiro が体験から言語化したものであること、30領域の調査はこのモデルと各分野の既知概念との構造対応を探索・検証するために行われていることを明示する
   - AIによる解釈を含むことを明示する
   - 他の版（general / academic）や個別調査レポートへの案内

## 注意

- 方法論の押し売りにしない（「この5段階を導入すれば」→「この見方を試してみてください」）
- 「正しいプロセス」を規定しない。循環し、逆行もすることを前提にする
- 先行研究者（ショーン、Csikszentmihalyi、Bion 等）は本文に自然に組み込む。独立した紹介セクションは不要
- 根拠の確かさを正直に書く

## 因果方向の禁止事項（cs#166）

5段階モデルと30領域調査の因果関係を逆転させる表現を禁止する。

**正しい因果**: 5段階モデルは pjdhiro が体験から言語化した → 30領域の調査はモデルと既知概念の構造対応を探索・検証するために行われた

**禁止表現**:
- 「調査から見出された」「調査により発見された」「調査に基づいて構築された」
- 「investigation revealed」「discovered through research」「derived from survey」
- 30領域の調査がモデルの根拠・出典・起源であるかのような記述
- モデルが帰納的調査から導出されたと読める表現

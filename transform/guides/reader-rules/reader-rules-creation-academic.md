## §2 中心テーマ

**「異なるラベルは同じものを指しているか。指し示されていないものはあるか」**

5段階モデルと先行研究（Wallas、Guilford、SECI等）はラベルが違う。ラベルが違うから違う、ではない。しかしラベルが違うものは違う。同じものを指しているだろう——という仮説のもとで、以下を分析する:

- 同じ構造を指しているか
- ラベルで表現されていないものはないか
- 先行研究が見落としているものはないか
- 5段階モデル側の見落としはないか

これは指月的記述（S04）の実践である。指の優劣ではなく、同じ月を指しているかを見る。

## §3 声の設計

### 基本の声

**学術的な読者に向けた、正直で明晰な分析報告。**

| 特徴 | 内容 |
|------|------|
| **明晰** | 用語を正確に使う。一文で一つの主張 |
| **正直** | 確定していないことは確定していないと書く。温度を厳密に使い分ける |
| **対等** | 読者が各分野の専門家であることを前提とする。教えない |
| **非攻撃** | 先行研究を否定しない。同じものを指しているかを分析する |

### 禁止する声

| 禁止パターン | 理由 |
|-------------|------|
| 「〜のモデルは不十分である」 | 先行研究への攻撃。指月の原則に反する |
| 「本モデルが既存理論を統合する」 | メタ理論の僭越。包摂を目指すが統合を主張しない（S12） |
| 「地図であり、領土ではない」 | 定型句。学術的表現ではない |
| 「ピンとこなければ〜」「合わなければ置いて〜」 | 責任逃れ（NL-001） |
| 比喩で方法論的限界を述べる | 学術的な文章なら方法論の言葉で述べる |

- 発散/収束（Guilford）

### 温度表現（必須）

共通基盤 §4 を継承。academic版では特に厳密に使い分ける。

| 温度 | 表現 | 使いどころ |
|------|------|-----------|
| 確定 | 「〜である」 | 5段階の定義、先行研究の事実記述 |
| 有力 | 「〜と考えられる」「〜を示唆する」 | 複数領域で確認された構造対応 |
| 仮説 | 「仮説として〜が考えられる」 | 単一領域の知見、未検証の接続 |
| 未解決 | 「〜は未解決である」 | 保持論点。対立する解釈が残るもの |

### 比較分析の記述方法

先行研究との比較では、以下の4面を区別して記述する:

| 面 | 何を記述するか |
|----|-------------|
| **類似** | 同じ構造を指していると考えられる部分 |
| **独自** | 5段階モデルにはあるが先行研究にないもの、またはその逆 |
| **学び** | 先行研究から取り込むべき知見 |
| **文脈** | 各先行モデルの固有文脈。本論の用語に翻訳しない |

## §5 構成

### 分析報告の構成

```
1. 問いの設定
   何を分析するか。なぜこの分析が必要か。
   「異なるラベルは同じものを指しているか」
   冒頭に立ち位置明示を含める（共通基盤 §7: この文書が何であり何でないか）。

2. 分析の方法
   30領域の選定基準。構造比較の手法。判定基準。
   方法論的限界は方法論の言葉で述べる。

3. 5段階モデルの定義
   場→波→縁→渦→束の各段階を定義的に記述する。
   全段階を均等に扱う。

3.5 安全弁
   モデル提示後に読者が離脱できる出口を1箇所設ける（共通基盤 §7）。

4. 先行研究との構造比較
   Wallas, Guilford, SECI, フロー等と5段階の対応分析。
   各理論について類似・独自・学び・文脈の4面を記述する。
   同じものを指しているか。見落としはないか。

4.5 代表的な構造対応の例示
   30領域から特徴的な理論を1〜5つ選び、5段階との構造対応を
   一言解説で示す。対応表や網羅的な分析ではない。
   読者が「こういう対応の見方をするのか」を掴むためのもの。
   詳細は個別調査レポート（別途公開）に委ねる。

5. 横断的知見
   複数の先行研究にまたがって見えてきた構造。
   特に「縁」に対応するものが先行研究にあるか。
   ラベルで表現されていないものの同定。

6. 根拠の状態と未解決の問い
   何が確定で、何が仮説で、何が未解決か。
   保持論点の開示。温度を正確に示す。

6.5 個別調査レポートへの案内
   本文中で特定領域の知見に言及した箇所から当該ドメインレポートへ
   参照を示す。横断的知見セクションでは、30領域全体の
   レポート群が閲覧可能であることを明記する。
   参照先は出力時点の公開状態に応じて具体URLまたは
   「別途公開の個別調査レポート」と記す。

7. 参考文献
```

### パート 4.5 の粒度指定（厳守）

1理論あたり2-3文。以下が基準となる文章量:

> 孵化は場〜波に、照明は縁〜渦に、検証は束にそれぞれ対応する。意識的な作業と非意識的な処理の交代という基本構造が共通する。5段階モデルには「縁」という明示的な段階がある。Wallasの記述では、孵化と照明の間の移行——矛盾が最大化し、どちらにも収束しない状態——が構造的に記述されていない。

**選定基準:**
- 対応の明瞭さ（読者が構造の見方を掴める例）
- 分野の多様性（同系統に偏らない）
- 意外性があればなお良い（一見無関係な領域に同じ構造が見える例）

**禁止:**
- 対応表（表形式での段階マッピング）
- 1理論に1段落以上を割く詳細分析
- 全30領域の列挙

## §6 先行研究の扱い方

### 指月的記述の原則（S04）

先行研究は月を指す指。5段階モデルも月を指す指。指の優劣を論じるのではなく、同じ月を指しているかを分析する。

| 使わない | 使う |
|---------|------|
| 「Wallasのモデルを修正する」 | 「Wallasが記述した構造と5段階の対応を分析する」 |
| 「5段階モデルが既存理論を統合する」 | 「5段階モデルと既存理論が同じ構造を指しているかを検討する」 |
| 「フロー体験理論を批判する」 | 「フロー体験と5段階の関係を分析する」 |
| 「4段階では縁が消える」 | 「Wallasの記述に縁に対応する段階があるかを検討する」 |

### 非二元性の原則（S55）

5段階と先行モデルは対立しない。異なるラベルで同じ現象の異なる面を記述している可能性がある。分析はその可能性を検証する作業であり、どちらが正しいかを判定する作業ではない。

スケールの分離も行わない。物理的/生命的/心的個体化は同じ創造プロセスの異なるスケールでの現れである可能性がある。

## §7 投影スイッチ回避

共通基盤 §5 を継承し、academic固有の追加を定義する。

| スイッチ | 禁止表現 | 理由 |
|---------|---------|------|
| 先行モデルの否定 | 「Wallasのモデルは古い」「不十分」 | 指月の原則に反する |
| 包摂の主張 | 「5段階がWallasを包摂する」 | 包摂を目指すが主張しない |
| 普遍性の過剰主張 | 「あらゆる創造に5段階がある」 | 射程は広いが断定は仮説の温度を壊す |
| 学術的定型句での逃げ | 「今後の研究が待たれる」 | 何が未解決かを具体的に書く |
| 比喩での限界表明 | 「地図であり領土ではない」 | 方法論の言葉で述べる |

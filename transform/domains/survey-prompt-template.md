# 領域調査プロンプトテンプレート v1.0

**用途**: D23水準の調査レポートを再現するための3Phase調査テンプレート
**根拠**: cs#78 D23品質分析から導出
**品質基準**: [quality-criteria.md](quality-criteria.md) の3軸で自己採点する
**更新日**: 2026-03-16

---

## Phase 1: 網羅収集

### 入力
- 領域名 / D番号

### プロンプト構造

```
対象領域: {領域名}（D{NN}）

以下の手順で網羅的に候補を収集せよ。

1. この領域の主要サブトピック群を 5-7 個に分解せよ
2. 各群から代表理論/概念を集め、合計 12-15 件の候補表を作れ
3. 各候補に対して以下を1行で記録せよ
   - 提唱者 / 時代 / 中心概念 / 5段階との接続見込み / 反例リスク
4. 候補を「強い対応 / 有力 / 条件付き / 監査枠」に仮分類せよ
5. 研究の根拠タイプを明示せよ
   - 実験、史料、定理、観察、調査、事例、メタ理論 など
```

### 出力物
- 理論マップ表（12-15件）
- サブトピック群一覧（5-7群）
- 収集漏れ候補（追加調査の余地があるもの）

### 品質チェック（Phase 1 終了時）
- [ ] 理論/概念数が 12 以上か
- [ ] 研究者/提唱者名が 10 以上か
- [ ] サブトピック群が 5 以上か
- [ ] 強弱判定が 3 段階以上に分かれているか

## Phase 2: 詳細分析

### 入力
- Phase 1 の理論マップ表

### プロンプト構造

```
Phase 1 の候補表をもとに、以下の手順で詳細分析を行え。

1. 代表 5 理論を選ぶ（サブトピック群の分散を考慮）
2. 各理論を以下の固定フォーマットで記述する:
   - **事実**: その理論が元々何を主張するか
   - **読み取り**: 5段階に照らすと何が骨格か
   - **写像**: 場/波/縁/渦/束のどこに何が対応するか
   - **含意**: この理論が5段階理解をどう更新するか
   - **限界**: どこが無理筋か、どこから牽強付会になるか
3. 1理論につき最低2個の具体根拠を添える
4. 「縁」の扱いを必ず明示する
5. [P]/[M]/[S] を混ぜない（事実と解釈を分離する）
```

### 出力物
- 深掘り各論 5 本（各4段落以上）
- 全候補の強弱一覧（更新版）
- 根拠メモ（理論ごとの具体根拠リスト）

### 品質チェック（Phase 2 終了時）
- [ ] 深掘り各論が 4 本以上か
- [ ] 各論に「事実/読み取り/写像/含意/限界」の5項目があるか
- [ ] 1理論につき具体根拠が 1 個以上あるか
- [ ] 5段階写像で `縁→渦→束` が明示されているか

---

## Phase 3: 洞察抽出と品質検証

### 入力
- Phase 1 の理論マップ表
- Phase 2 の深掘り各論

### プロンプト構造

```
Phase 1-2 の成果をもとに、以下の手順で洞察を抽出し品質を検証せよ。

1. 領域横断のパターンを 4 本以上抽出する
2. 独自解釈/構造比較を 6 本以上書く
3. 未解決論点を 4 本以上残す
4. 以下の QA を通す:
   - 調査範囲: 12/10/5 を超えているか
   - 深さ: 深掘り5本・各4段落を満たすか
   - 洞察: 事実/読み取り/解釈分離と横断パターン4本を満たすか
   - 牽強付会: 「似ている」だけで押していないか
   - 領域固有性: その領域でないと出ない語彙が残っているか
5. 最後に 3軸スコアを自己採点する（quality-criteria.md 参照）
```

### 出力物
- 最終 domain report（domain-report-template.md 準拠）
- 3軸スコア表（Range / Depth / Insight）
- 保留論点リスト

### 品質チェック（Phase 3 終了時 = 最終ゲート）
- [ ] 横断パターンが 3 本以上か
- [ ] 独自解釈/構造比較が 4 本以上か
- [ ] 未解決論点が 3 本以上か
- [ ] 事実/読み取り/解釈の分離が深掘り各論で実施されているか
- [ ] 牽強付会チェックが明示されているか
- [ ] 領域固有の語彙が残っているか
- [ ] 3軸スコアが最低合格ライン以上か

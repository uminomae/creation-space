# 領域間配置ルール — 一次配置と参照の判断基準 v1.0

**用途**: 複数の学問領域にまたがる知見（乱流カスケード、自己組織化、ベイズ推論等）を、どのドメインレポートに一次配置し、他のレポートからどう参照するかを定める
**根拠**: cs#105
**更新日**: 2026-03-16

---

## 一次配置の判断基準

| 基準 | 判断 |
|------|------|
| その現象が最初に定式化された領域 | 一次配置 |
| その現象の数学的・実験的定義がある領域 | 一次配置 |
| 上記が複数あって判断できない | pjdhiro に確認 |

**補足**: 一次配置は「その知見を最も深く扱う責任がある領域」を意味する。一次配置のドメインレポートでは、§5（主要な知見）で事実→読み取り→解釈の3層分析を完全に記述する。

---

## 参照の記述方法

一次配置以外のドメインレポートでは、同じ知見を §5 で詳述しない。代わりに §6（横断的パターン）で以下の形式で参照する:

```
D02 で詳述した乱流カスケードの構造は、本領域の〇〇にも通じる。
（→ D02 物理学 §5.N 参照）
```

**要点**:
- 参照先の D 番号を必ず明示する
- 参照先で述べた3層分析を繰り返さない
- 本領域固有の接続（なぜこの領域でも関連するか）だけを書く

---

## 住み分け

| 場所 | 書くこと |
|------|---------|
| 一次配置の D（§5） | その現象固有の事実→読み取り→解釈の3層分析 |
| 参照する D（§6） | 横断的パターンとしての言及 + 一次配置 D への参照 |
| §6 横断的パターン（全般） | 複数 D に共通するパターンの抽象化 |

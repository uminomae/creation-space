# ルール評価基準: テーマ検証レポート v1.0

**目的**: テーマ検証レポートの品質を「reader-rules のどこが足りないか」の観点でチェックする
**使用者**: pjdhiro（人間によるレビュー）および Claude Code（生成後自己チェック）
**判定**: ✅ PASS / ⚠️ WARN / ❌ FAIL
**再生成基準**: FAIL が1件でもあれば再生成。WARN は3件以上で再生成を検討。

---

## カテゴリ1: 主題の正確性（最優先）

### T1-1: テーマの定義が Phase 8 と一致しているか
theme-registry.md に記載されたテーマ定義と、レポート §1 の記述が一致しているか。
独自の拡大解釈や縮小解釈をしていないか。

### T1-2: 禁止語が混入していないか（NL-010 継承）
以下の語が本文に登場していないか（Colophon 除く）:
- 「欠損駆動思考」
- 「抱持」
- 「Kesson（欠損）」

```bash
grep -n "欠損駆動思考\|抱持\|欠損（Kesson）" {ファイルパス}
```

### T1-3: 内輪語が混入していないか
以下の語が本文に露出していないか（Colophon 除く）:
- 「保持論点」
- 「E-1」〜「E-8」
- 「CHK-A」〜「CHK-D」
- `/Users/uminomae/dev/` 等の内部パス
- 「pjdhiro」

```bash
grep -n "保持論点\|E-[0-9]\|CHK-\|/Users/uminomae\|pjdhiro" {ファイルパス}
```

### T1-4: AI帰属が適切か（NL-013 継承）
AI 由来の調査・分析結果が著者の一人称発言として記述されていないか。

---

## カテゴリ2: 4 Phase 均等性（テーマ検証固有）

### T2-1: 全 Phase が記述されているか
§2（9A）、§3（9B）、§4（9C）、§5（9D）の全てが記述されているか。
いずれかのセクションが空、または「データなし」で済まされていないか。

### T2-2: 反証結果が隠蔽されていないか
§3（堅牢性検証）に 9B の攻撃仮説・反例が具体的に記述されているか。
「特に問題なし」のような曖昧な記述で済まされていないか。
堅牢性スコアが 5 以下のテーマについて、脆弱性が明示されているか。

### T2-3: 総合判定が 4 Phase の結果から導かれているか
§6（総合判定）の確度が、§2-§5 の結果から論理的に導かれているか。
evidence と矛盾する楽観的/悲観的な判定をしていないか。

## カテゴリ3: 数値の正確性

### T3-1: 堅牢性スコアが evidence と一致しているか
§3.4 のスコアが `evidence/falsification/theme-*/robustness-score.md` の値と一致しているか。

```bash
# evidence のスコアを確認
grep "堅牢性スコア" evidence/falsification/theme-{NN}-{slug}/robustness-score.md
```

### T3-2: 的中率が evidence と一致しているか
§4.1 の的中率が `evidence/frontier/domain-*/prediction-audit.md` の値と一致しているか。

### T3-3: 命題判定の分布が evidence と一致しているか
§2.1 の判定（✅/⚠️/❌/🆕）の件数が `evidence/grounding/theme-*/alignment-report.md` と一致しているか。

### T3-4: 数式が evidence と一致しているか
§5 の数学的定義・定理が `evidence/formalization/theme-*/formal-definitions.md` および `theorems.md` と一致しているか。
独自に変形・簡略化していないか（読みやすさのための表記変更は許可）。

## カテゴリ4: 読者への配慮

### T4-1: 専門用語の初出に説明があるか
数学用語（圏論、分岐理論、リャプノフ指数等）、学術用語（リミナリティ、エコトーン等）が初出時に説明されているか。

### T4-2: 数式に自然言語の説明が付いているか
数式のみが提示され、何を意味するかの説明がないブロックがないか。

### T4-3: 調査報告書として読めるか
日記・作業メモ・教科書になっていないか。「検証結果を読んでいる」と読者が感じられるか。

### T4-4: 文体が統一されているか
です・ます調で統一されているか。

---

## カテゴリ5: 構造・形式

### T5-1: テンプレート構造に準拠しているか
theme-report-template.md の §1-§7 + Colophon の構造に従っているか。

### T5-2: Colophon に必須項目が含まれているか
type, theme_id, theme_slug, lang, generated_at, generator_model, evidence_flag,
source_9a, source_9b, source_9c, source_9d, robustness_score, overall_confidence が全て記載されているか。

### T5-3: 立ち位置明示・安全弁・方法論的開示が含まれているか
テンプレートで指定された3箇所の返却設計要素が全て存在するか。

## チェック実行手順

```bash
# 1. 禁止語チェック
grep -n "欠損駆動思考\|抱持\|欠損（Kesson）\|保持論点\|/Users/uminomae\|pjdhiro" {ファイルパス}

# 2. 一人称チェック（誤検出あり、目視と併用）
grep -n "私は\|筆者は\|筆者の\|私の見解" {ファイルパス}

# 3. セクション存在チェック
grep -c "## 2\. 学術的根拠\|## 3\. 堅牢性検証\|## 4\. 新領域\|## 5\. 数理形式化\|## 6\. 総合判定\|## 7\. 未解決" {ファイルパス}
# 結果が 6 であること

# 4. Colophon 必須項目チェック
grep -c "theme_id\|robustness_score\|overall_confidence\|source_9a\|source_9b\|source_9c\|source_9d" {ファイルパス}
# 結果が 7 であること
```

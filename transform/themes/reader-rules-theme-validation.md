**目的**: Phase 8 で抽出した横断的テーマが、学術的根拠・反証・予測・形式化の4視点でどの程度頑健かを報告する

## §0 ソース原則

共通基盤 §1 を継承し、テーマ検証固有のソース指定を追加する。

### 参照すべきソース（テーマ T{X} の場合）

| ソース | 何のために |
|--------|----------|
| `evidence/grounding/theme-{NN}-{slug}/` | 9A 実証接地: 先行研究突合・命題判定 |
| `evidence/falsification/theme-{NN}-{slug}/` | 9B 反証探索: 攻撃仮説・反例・堅牢性スコア |
| `evidence/frontier/domain-{NN}-{name}/` | 9C 未踏領域: ブラインド予測・的中率 |
| `evidence/formalization/theme-{NN}-{slug}/` | 9D 数理形式化: 定義・定理・限界 |
| `evidence/investigation/phase8/themes/` | Phase 8 テーマ詳細（入力の正本） |
| `transform/domains/publish/cross-domain-synthesis-ja.md` | 横断分析（文脈として参照） |

### ソース利用の原則

- **4 Phase を均等に扱う**: どの Phase の結果も省略・軽視しない。特に 9B（反証）の結果を隠さないこと
- **evidence に書いていないことを書かない**: 推論の飛躍を避ける
- **数式は evidence/formalization/ の定義をそのまま転記**: 独自に変形しない

## §1 4 Phase 統合の指針

テーマ検証レポートの核心は「4つの異なる視点の統合」にある。

### 統合の原則

| 視点 | 役割 | レポートでの位置づけ |
|------|------|-------------------|
| 9A 実証接地 | テーマの主張は学術的に支持されるか | 「何が知られているか」 |
| 9B 反証探索 | テーマの主張はどこが脆いか | 「何が危ういか」 |
| 9C 未踏領域 | テーマは新領域でも予測力を持つか | 「どこまで通用するか」 |
| 9D 数理形式化 | テーマは数学的に定式化できるか | 「どこまで精密にできるか」 |

### 総合判定の導出

4 Phase の結果を総合し、テーマの確度を以下の4段階で判定する:

| 確度 | 条件 |
|------|------|
| **確定** | 9A で学術的支持あり + 9B 堅牢性 7+ + 9C 的中率 80%+ + 9D 定義成功 |
| **有力** | 9A で部分的支持 + 9B 堅牢性 5+ + 9C/9D のいずれかが良好 |
| **仮説** | 9A で未踏が多い or 9B 堅牢性 4以下 or 9C 的中率 60%未満 |
| **未解決** | 4 Phase 間で矛盾がある or データ不足で判定不能 |

## §2 声と文体

共通基盤を継承。以下を追加:

- **です・ます調**で統一
- **検証結果は率直に**: 堅牢性が低いテーマについて、良く見せようとしない
- **数式は LaTeX 記法**: `$...$`（インライン）、`$$...$$`（ブロック）
- **判定記号**: ✅ 支持 / ⚠️ 部分一致 / ❌ 矛盾 / 🆕 未踏 を統一的に使用

---

## §3 禁止パターン

共通基盤 §4, §6 を継承。以下を追加:

- **堅牢性スコアの改竄**: evidence/falsification/ のスコアと異なる数値を記載しない
- **的中率の恣意的選択**: 都合の良い領域だけを取り上げない
- **形式化の過大評価**: 定義の試行段階のものを「定理」と呼ばない
- **反証結果の隠蔽**: 9B で発見された脆弱性を §3（堅牢性検証）から省かない

---

## §4 返却設計

共通基盤 §7 を継承。テーマ検証レポート固有の実装:

### 立ち位置明示（冒頭）
> 本稿は、30領域横断分析で抽出された構造テーマ「{テーマ名}」の検証結果を
> 報告するものである。学術的根拠・反証・予測・形式化の4視点から検証を行った。
> 検証結果には確度の高いものから未解決のものまで含まれる。

### 安全弁（§2 後）
> ここまでの概要で十分な場合、§3 以降の詳細分析は省略可能である。

### 方法論的開示（§1 内）
> 本検証はAI（Claude Opus 4.6）による調査・分析に基づく。学術文献の調査は
> Web 検索による二次情報であり、原著の精読に基づく確定的対応ではない。
> 数理形式化は試行段階であり、厳密な数学的証明を経ていない。

## テンプレート構造

```markdown
# {テーマ名} — 検証報告

> **立ち位置明示**
> 本稿は、30領域横断分析（Phase 8）で抽出された構造テーマ「{テーマ名}」の
> 検証結果を報告するものである。学術的根拠調査、敵対的反証探索、
> 新領域への予測検証、数理形式化の4つの視点から検証を行った。
> 検証結果には確度の高いものから未解決のものまで含まれる。

## 1. テーマの概要と主張

### 1.1 テーマの定義
Phase 8 で抽出されたテーマの主張を簡潔に記述する。

### 1.2 対象領域
テーマが確認された領域数と代表的な領域を列挙する。

### 1.3 主要な収束点
Phase 8 テーマ詳細の §B（収束点）から主要なものを要約する。

### 1.4 方法論的開示
> 本検証はAI（Claude Opus 4.6）による調査・分析に基づく。学術文献の調査は
> Web 検索による二次情報であり、原著の精読に基づく確定的対応ではない。
> 数理形式化は試行段階であり、厳密な数学的証明を経ていない。

## 2. 学術的根拠（Phase 9A: 実証接地）

### 2.1 検証した命題

| # | 命題 | 判定 |
|---|------|------|
| C-01 | ... | ✅ / ⚠️ / ❌ / 🆕 |

### 2.2 先行研究との主要な一致点
学術的に支持される主張を記述する。

### 2.3 先行研究との主要な不一致点
矛盾または部分一致にとどまる主張を記述する。

### 2.4 未踏の主張
先行研究が見当たらず、新規性がある可能性のある主張を記述する。

> **安全弁**
> ここまでの概要で十分な場合、以降の詳細分析は省略可能である。

## 3. 堅牢性検証（Phase 9B: 反証探索）

### 3.1 攻撃仮説
テーマの主張を否定するために立てた仮説を列挙する。

### 3.2 発見された反例
攻撃仮説を支持する反例を記述する。

### 3.3 ストレステスト結果
反例がテーマを「破壊」するか「限定」するかの判定。

### 3.4 堅牢性スコア

**総合スコア: {N}/10**

| 評価軸 | スコア | 理由 |
|--------|--------|------|
| 方法論的堅牢性 | /10 | ... |
| 概念的明確性 | /10 | ... |
| 横断的支持の質 | /10 | ... |
| 反証可能性 | /10 | ... |
| 非自明な内容 | /10 | ... |
| 文化的普遍性 | /10 | ... |

### 3.5 修正された適用範囲
反証探索の結果、テーマの適用範囲をどう修正すべきかを記述する。

## 4. 新領域での予測検証（Phase 9C: 未踏領域探索）

### 4.1 検証した領域

| 領域 | 予測的中率 | 注目点 |
|------|----------|--------|
| ... | ...% | ... |

### 4.2 予測が当たった箇所
モデルの汎用性を示す証拠を記述する。

### 4.3 予測が外れた箇所
モデルの適用限界を示す証拠を記述する。

### 4.4 モデル更新提案
予測検証から導かれるモデルの改善案を記述する。

## 5. 数理形式化（Phase 9D）

### 5.1 採用した数学的フレームワーク
選択した数学的道具とその選択理由を記述する。

### 5.2 主要な定義
テーマの中核概念の数学的定義を記述する。

### 5.3 導出された定理
定義から導かれた非自明な性質を記述する。

### 5.4 形式化から導かれた予測
数学的構造から演繹される、まだ検証されていない予測を記述する。

### 5.5 形式化の限界
形式化できなかった側面、失敗した試みを記述する。

## 6. 総合判定

### 6.1 テーマの確度

**確度: {確定 / 有力 / 仮説 / 未解決}**

| 視点 | 結果要約 | 確度への寄与 |
|------|---------|-------------|
| 9A 実証接地 | ... | ... |
| 9B 反証探索 | ... | ... |
| 9C 未踏領域 | ... | ... |
| 9D 数理形式化 | ... | ... |

### 6.2 修正すべき主張
4 Phase の結果を総合し、修正が必要な主張を列挙する。

### 6.3 新規性が確認された主張
先行研究に見当たらず、かつ堅牢性検証・予測検証を経た主張を列挙する。

## 7. 未解決の問い

検証を経ても解決しなかった問い、新たに生まれた問いを列挙する。
```
